# 从现成板派生 / 换件后重布（2026-10-24～25，原力手环 C06 焊线盘版、C06 八路版）

情形：板子不是从零布，而是从一块已布过的板改出来——局部换封装（ECO）、删掉一半电路（从 16 路板减成 8 路）、或跟随参考板的新版本。下面每条按 情形 → 规则 → 证据 → 置信。

## 1. 密集区换件：局部补不完就整板重布，关键网从参考板搬过来锁定

- **情形**：新封装压在别人的过孔场上（背面阵列打上来的一片过孔），删掉压住的线孔后要补线。
- **规则**：局部补线器补不完、或 Freerouting 拿已布好的板做增量也补不完时，不再试增量，改走全流程（摆件 → 布线 → 收尾）。验收过的关键链路（USB 等）从参考板原样搬入并锁定（DSN 里是 `type fix`，布线器不动），门禁里逐段比对线孔，并带一个挪 0.05 mm 的阳性对照。布线后补线器常在锁定线端点再拉一段到焊盘中心，属同网重复，删掉未锁定的那部分再比。
- **证据**：C06 焊线盘版，局部换件后补线器剩 20 处；从已布板导 DSN 做增量，Freerouting 结果更差（README K 节「20→39 未布」）；改全流程（40 轮 331→30，再收尾）后 0/0（提交 eb3fc4ee，`v12/c06-board-20261022/README.md` K 节）。USB 8 网 102 段搬入锁定，补线器在 CC1/CC2 上多拉了 4 段，删掉后逐段 0 差异。
- **置信**：低（单次）。

## 2. 全撤重布要保留扇出

- **情形**：撤掉旧走线让布线器从零布，板上有 aQFN / BGA。
- **规则**：撤线时保留「焊盘 → 一段短线（≤1.5 mm）→ 同网过孔」这类扇出结构，和关键链路一起锁定。全撤后布线器得自己从 0.5 mm 间距的 aQFN 往外拉线，外圈脚收不了尾。
- **证据**：C06 八路版 r1 全撤（含 C07 原板的狗骨扇出）重布，收尾后剩 19 处，其中约 10 个 nRF52840 aQFN 外圈焊盘连不出去（AD8/AD10/AD12/AD14/AD20/AC11/AC24/M2/K2/H2）；逐级补线 5 步跑了前 4 步都没改善。r3 起保留扇出 181 个线孔（连同 USB 共 810 段锁定），结果见原力手环分支 `claude/c06-8ch` 的 `v12/c06-8ch-20261024/README.md` C 节。
- **置信**：低（单次失败观测，保留扇出后的效果待 r3 结果）。C06 原有流程本来就是布线前先扇出（`fanout_chip.py`），这条是派生时漏了它。

## 3. 拆线补线必须「变差就撤回」

- **情形**：布线器剩几处到几十处，用允许拆线的补线器收尾。
- **规则**：拆线轮数从 0 起逐级试（网格 0.05/0.025 × 拆 0/1/2），每步和当前最好版比分（未连 × 10 + 非悬空违规 × 10 + 违规数），只留变好的；不要直接开拆 2 轮跑完了事。
- **证据**：三次：C06 10-22 第一版直接拆 2 轮，6 未连变 16（`c06-board-20261022/close.sh` 注释）；C06 八路版 10-25 对 19 未连直接拆 2 轮变 103（`c06-8ch-20261024/close.sh` 第 3 行注释）；保留 C07 原走线的版本允许拆线后从 38 变 181（同目录 README C 节）。参考实现：`c06-8ch-20261024/close.sh`（网格、轮数、打分公式是这块板用的值，不是通用参数）。
- **置信**：中（三次同向）。

## 4. 加载板子时工程文件要在同目录

- **情形**：脚本从 git、临时目录或另一目录取出 `.kicad_pcb` 用 pcbnew 加载、改完存到项目里。
- **规则**：凡是从 git、临时目录、`gate/` 之类子目录或改名副本加载 `.kicad_pcb`，先把同名 `.kicad_pro`（和 `.kicad_dru`）放到同目录，加载后断言一条规则值（如最小线宽）确实是工程里的值；导 DSN 后再断言 DSN 里的间距、线宽等于工程值。没有工程文件时 pcbnew 按默认规则加载，`Save` 会把默认规则写进 `.kicad_pro`，`ExportSpecctraDSN` 按默认 0.2 mm 出间距。
- **证据**：C06 八路版 `derive_board.py` 第一版只取了板文件，存盘后 `c06.kicad_pro` 的线宽、过孔、孔距下限都变成了默认值，DRC 冒出几百条假违规（当时的 DRC 结果被后来的运行覆盖，没留存；修法见 `derive_board.py` 取源处的注释和断言）。
- **补充（kicad-cli DRC 同理，2026-10-25 原力手环 C07）**：板子拷到 `/tmp` 等无工程文件的目录跑 `kicad-cli pcb drc`，同样按默认规则判；C54 试位在 `/tmp` 报 220 条违规，放回同目录 20 条（基线 9）。试验板放同目录、带同名工程文件，先对未改动拷贝跑一次，必须等于基线。
- **补充（导 DSN 同理，2026-10-25 原力手环 C06 八路版）**：`route_io.py` 从 `gate/c06-derived.kicad_pcb`（同目录没有工程文件）导 DSN，间距、线宽都成了 200 µm；锁定的 0.1 mm 扇出和 USB 在布线器眼里全违规（814 处，30 轮不变），布线卡在约 275 未布。同一块板从带工程文件的路径导出是 100 µm（修法见 `route_io.py` prep 段的注释和两条断言，分支 `claude/c06-8ch`）。
- **补充（文本层撤线后加载临时板同理，2026-10-25 原力手环 C07 r5）**：为避开 `Remove` 悬空对象，先在文本层删走线写到临时文件再 `LoadBoard`，临时目录没带工程文件 → `SaveBoard` 把默认规则写回 `main-r5.kicad_pro`，DSN 按 0.2/0.6 布线；Spark 8/12 轮未连 393/399 全部作废，白跑约 3 小时。修法：临时目录同时放同名 `.kicad_pro/.kicad_dru`，保存后断言输出工程规则与源板逐项相等（`watch-release/r5/build_r5.py`，分支 `claude/c07-r5-d1-stackup`）。
- **置信**：高（四次同因：保存、kicad-cli DRC、导 DSN、临时板撤线）。

## 5. pcbnew 的 `Models()` 返回副本；断言要读回结果，不数动作次数

- **情形**：用 pcbnew Python 改封装 3D 模型路径（或别的通过访问器拿到的子对象）。
- **规则**：改完存盘后重新读文件确认旧值已经不在；需要批量改路径时直接按文本替换 `.kicad_pcb`，再断言旧串计数为 0。只断言「改了 N 次」证明不了改动生效。
- **证据**：C06 八路版 `derive_board.py` 对 `f.Models()` 里的 `m_Filename` 赋值 5 次、断言 `nm == 5` 通过，但存盘后 5 个 `${KIPRJMOD}/../../` 路径原样未动；装壳检查碰巧因为读的板在子目录里抵消了一层 `../` 才没报。
- **置信**：低（单次）。

## 6. Freerouting 2.x 关掉使用数据上报

- **情形**：用 Freerouting 2.x（2.4.1 / 2.5.0）布板。
- **规则**：设环境变量 `FREEROUTING__USAGE_AND_DIAGNOSTIC_DATA__DISABLE_ANALYTICS=true`；Spark 上在容器里加 `--network none`（断网后日志里的 UnknownHostException 是查主机名失败，不影响布线）；Windows cmd 里写 `set 变量=true&& java …`。板子数据出机器属于隐私取舍，开跑前确认。
- **证据**：C07 会话 `full-reroute-spark-r4/run25.sh` 先这样做；C06 10-24 在 thursday-win 上几单 2.4.1 没关也没断网，已如实告知 Mako，10-25 起加上。
- **置信**：低（只有 C07 `run25.sh` 第 3 行注释一处来源；环境变量是否生效、上报内容都没核）。

## 7. 跟随参考板：来源写成一个文件

- **情形**：一块板从另一块正在迭代的板派生（例：C06 八路版跟随 C07）。
- **规则**：参考提交和板名写进一个文件（`c07_ref.json`），网表、派生、USB 比对、布线边界、装壳脚本都读它；参考更新时改这一处，重跑派生链。开工和交付前各 `git fetch` 看一次参考有没有新提交。
- **证据**：C06 八路版从 C07 947d50cc 派生、布了一夜；早上 C07 已到 94100246（换电池、挪件、改高度口径），旧基线上的布线和装壳结论全部作废，重派生只用了几分钟。
- **置信**：低（单次）。

## 8. 参考地验实际填铜和接地，不能只验分区外框

- **情形**：把内层局部改为电源面，或为背面信号新增地走廊；DRC和旧连接簇均通过，但需要证明参考地仍在。
- **规则**：原生重填并保存后，沿实际信号铜采样查询邻层填铜实体，分别统计GND、其它网、空隙；用同一组坐标对照旧版。每个覆盖信号的地岛还要证明接入已有地网，不能把整个ZONE当统一连通节点。缺地时检查穿越信号、过孔及岛移除；保留浮铜不算修好。采样通过仅说明采到的点，不替代连续几何、差分阻抗和实测。
- **证据**：原力手环P37，2026-10-26，PR150。新增地走廊的候选126未连、0其它错误、旧簇保全，但USB线下53点为0地/45电源/8空隙；显式扣电源区仍全空。独立定位为旧信号切开的左地岛无接地，被填铜器移除。补真实地孔后127恢复旧134/133的45地/8空隙；重绕两条跨越信号后，最终126保存重载为53地/0其它/0空隙。证据在项目`v12/c08-p37-a-double-route-20261026/design/independent-127/`与`independent-final126/REPORT.md`。
- **置信**：中（同一案例有错误区、扣洞、接地、重绕四阶段和原基线同点对照；不外推所有填铜器行为）。

## 9. 预置孔先定网：孤立孔落在旧铺铜里会被改成地

- **情形**：换件后先文本层放好扇出孔（还没连线），再导 DSN；板文件带着旧的内层地平面填充。
- **规则**：加孔后去掉 `(filled_polygon`，再加载。导 DSN 前断言每个预置孔的网名，DSN 里抽查 `(net …)`。旧填充没去掉时，DRC 的未连和间距都不可信。
- **证据**：原力手环 C08B 方案 B，2026-11-04：57 个预置孔全变 GND，布线器当成地孔绕开，该轮 18 未连；DRC 0 错误，未连少算 15 处（报 50，实为 65）。修好后同样的摆位 8 未连，还查出一个孔离 C59 地焊盘 0.014 mm。
- **置信**：中（单板，但根因和修法都实测）。

## 10. 同一颗孔位，布线器和手工要分工

- **情形**：两颗芯片背靠背，背面芯片的过孔只能落在正面芯片焊盘环外，Freerouting 反复收不了尾，每轮失败的网还不一样。
- **规则**：先算全板可落孔点，按脚序预置扇出孔，把焊盘到孔这段手工定死，布线器只接内层。余下几根用 `finish_bb.py`；`RIP=1` 会拆断别的网，每次都要再补一轮，来回挤时手工恢复孔位。清悬空只删 DRC 点名的，每批跑 DRC，自写判定会误删只靠铜皮相碰连通的线。
- **证据**：同上板，未连 28 → 18 → 8，A* 后 2，手工收尾 0。自写清理脚本三版都把未连从 0 改成 4，改由 DRC 把关后 0。Freerouting 2.4.1 同一输入 35 未连、295 违规。
- **置信**：低（单板）。

## 11. 布线器每轮卡同几根：先看同层交叉，再定手工线

- **情形**：换件后 Freerouting 几组参数都剩同样 3–5 根，A* 也 exhausted；手工先定这几根，别的网反而更堵。
- **规则**：画出每层的车道顺序，查两根线在同一层是否必然交叉（两端的南北顺序相反）。必然交叉的，一根换层或打孔跳过，别靠重布。手工线别在三层内层同一 x 上排成竖墙。上一轮结果当底：保留布线器的线，只拆和新手工线冲突的段，再 A* 和接续布线。
- **验收**：A* 或接续布线后比每网线长和最短连线，超 2 倍的重画；DRC 和 lint 都不报这种绕路。
- **证据**：原力手环 C08B L432 + 52840，2026-11-04：XIAO_SCLK、MCU_RST_N、XIAO_RESET 三轮不通，手工先定 8 未连，合并后 3，手工接完 0。VBAT_SENSE 接通但 65.8 mm，最短 19 mm，独立复核才查出，重走 24.3 mm。
- **置信**：低（单板）。
