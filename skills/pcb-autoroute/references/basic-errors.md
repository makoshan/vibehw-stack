# PCB基础错误门禁

适用于AI生成、自动布线和回导后的板。检查不修改设计；已下单板只读核查。

## 执行入口

```sh
python3 ~/.claude/skills/pcb-autoroute/scripts/basic_gate.py board.kicad_pcb --out /新的证据目录
python3 ~/.claude/skills/pcb-autoroute/scripts/test_basic_gate.py
```

入口要求同名.kicad_pro与.kicad_sch，层级子图也必须齐全，并先独立导出非空原理图网表；缺失、不可读或网表导出失败记未验证，避免空一致性结果放行。运行本次KiCad DRC、内存重新铺铜、核对原理图一致性，报告包含警告和排除项。源PCB/工程/规则/原理图及子图记录哈希，变化即作废；目录不可复用。退出0为`NATIVE_DRC_ONLY_PASS`，1为`BLOCKED`，2为`UNVERIFIED`；缺工具或报告不能通过。

## 三层判据

| 层 | 必查项 | 如何判定 |
|---|---|---|
| 基础硬错误 | 短路、断网、悬空线/过孔、孤立铜、间距、孔环、板框、阻焊桥、PCB与原理图不一致 | 原生报告必须无违规、无未连接、无一致性差异；关键检查被ignore也拦住 |
| 项目电气与制造约束 | 引脚脚序/封装、极性、耐压与有效容量、耗散与压差、上电时序、接口方向、允许工艺 | 按原厂手册与所选工厂参数写成项目断言；逐项带元件/网络/来源；缺依据记未验证 |
| 布局质量 | 地回流、开关电流环路、差分输入对称、RF净空、冗余过孔/绕路、锐角与分支 | 带坐标与网络的审图或项目几何检查；原生DRC不能替代这些检查 |

**禁止以“显而易见”替代判据。** 每条规则写清对象、阈值/依据、失败位置、修复方式和故意错误样本。规则可读取声明过的工艺参数，不能为了过检查悄悄放宽。

## 容易误写的三条

- 非45°方向不自动等于电气错误。新板可默认H/V/45作为布局约定；需强制时用项目角度规则，保留有来源的例外。不要将走线方向等同于相邻段的转角，也不要把45°/90°写成所有工厂的通用限制。
- 有过孔不自动等于错误。悬空过孔由原生门禁拦；冗余过孔要结合换层、回流和支路用途判断。Via-in-pad必须核填孔/盖铜工艺，不可凭DRC通过放行。
- 走线形成环路不自动等于错误。电源、地和信号的用途不同；高阻输入的多余支路、过长数字支路、电源大环路需要逐网审核。天线净空必须使用真实模块厂商的包络，不能从照片猜。

## 反例与证据

在独立临时副本中故意加入悬空线、悬空过孔、断线、短接、越界铜等；确认原生报告出现对应类型且门禁退出1。再拿正常板做阳性对照。报告单元测试只证明报告筛选逻辑，不能代替错误PCB验证。

报告中的其他ignore项必须列出并审查；即使门禁退出0，仍不能宣称引脚/噪声/RF/人体/制造验收完成。封装类型不匹配等被忽略项需要另行核查。

依据：KiCad原生DRC与自由角度模式说明 https://docs.kicad.org/9.0/en/pcbnew/pcbnew.html 。数值门槛由项目和当次工厂参数决定。

继续补布局/制造规则时，读[官方经验与适用边界](pcb-layout-sources.md)。已有带来源的网络/尺寸声明可运行[专项布局门禁](layout-gate.md)，检查敏感网避让、线长/铜路径、地覆盖、侵孔和铜净空。锐角、回流阻抗、去耦完整环路、实际模块RF/金属净空仍需另验，不能将文档条目当已实现检查。
