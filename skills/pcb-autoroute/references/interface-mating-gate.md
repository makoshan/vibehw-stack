# 接口配对检查

适用：FPC/FFC、板对板、模块底面焊盘、跨板线束和有极性的电源接口。仅审查任务涉及的接口，不扩展为无关整机重做。

## 出制造包前的证据
- 钉住实物批次、生产提交及当前候选文件哈希；文件名相同不等于版本相同。保留旧制造包，别拿新板解释旧板测量。
- 对手端用准确型号的厂家脚位/机械图，座子端用准确料号的推荐焊盘与剖面；记录图纸视角、Pin1、开口、上/下接触、FPC厚度。照片检查实物与料号是否一致，不能按线色/相似型号猜极性。
- 把“对手脚号→接触端子→PCB焊盘号→网络→功能”逐脚列出，供电/GND/复位/使能/NC/DNP都覆盖；接头旋转、翻面、线束同面/异面分别处理。机械转180度不等于网络倒序；不要把本例13-k推广到别的座子。
- 用独立原厂图纸或断电测试确认映射，再作为自动检查的期望值。原理图和PCB由同一错误表生成、Altium导入同一PCB、模型自测，均不是独立配对证据。
- 自动检查应让已知错误的历史版失败、修正版通过；缺少必须接口/脚位/料号/映射时报告未覆盖或阻塞，不能把SKIP汇总成制造通过。
- 1:1打印验证方向/干涉，不能验证电气连接。正常导通的证据与“CS对地低阻”等症状分开；多脚共地会掩盖针序，不用它证明完整映射。插入后不可访问的触点用引出治具，不让表笔硬插座子。
- DNP、连接器高度、排线折弯、背面模块落点、USB与电池供电切换、调试口可达性分别列门。局部检查有失败时不能汇报“全过”。
- 制造放行记录：接口设计已核/原生ERC及DRC/制造包哈希及BOM-CPL一致性/机械未决/实物未决。只出候选包不等于付款授权。

## 免焊约束
区分用户免焊与制造全过程无焊：预焊排针+工厂排母可让用户插装，但普通裸孔不等于可靠插座。模块抬高后，底面BAT/SWD/NFC等焊盘不会自动接通。弹簧针需行程、公差、镀层、电流、锁定及晃动测试；压入式端子必须按其指定孔径/镀层设计，不推荐直接硬塞旧板。
