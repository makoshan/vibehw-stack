# 补线救不了摆位：按信号流重摆、脚本直连 + 逐网 A* 重布（2026-11-02，C08B 采集板 D4 实测）

适用：派生板或旧板 DRC 能过，但走线乱到没法用（长网绕芯片、敏感链大量打孔、整层地被线切开），拉直和拆线重布都救不回来。证据在原力手环仓 `v12/c08b-afe-relayout-20261102/`（脚本、各阶段板，提交 `020e2c42`）和 `docs/c08b-afe-relayout-20261102/README.md`（带图的方案与结果）。脚本带本板常数，照抄前先改坐标和网名。

[量飞线判根因] → 按信号流手排 + 换脚 → 分层 → 骨架直连锁定 → 逐网 A* → 电源加宽 → 地缝合 → 收尾 → 两口径 DRC + 判据表 → 独立复核

## 1 先量飞线，再决定重摆

- **情形**：板子从别的板删件派生，或补过大量网格寻路线。
- **规则**：撤线后量每组网的飞线总长和最长网（飞线 = 各网焊盘最短连线树）。最长网远大于两端器件间距，就是摆位问题，拉直、拆线重布都不治。先撤线重摆，用飞线数字验收摆位（本板电极链最长网 52.8 → 9.1 mm），再布线。
- **证据**：158/167 件挤在西边 26 mm；正面芯片输入脚背对座子，16 根电极线绕芯片，最长网 142 mm、打 16 孔。重摆后 5965 段 / 470 孔 → 763 段 / 222 孔。C08C P52 只按线长自动摆件，未连 81 → 66，没救回来。
- **置信**：低（单板）。

## 2 按信号流手排，两面镜像

- **情形**：多路模拟输入（座子 → ESD → 串阻 → RC → AFE）。
- **规则**：照有成品的参考板（本板是供应商 v4）排成竖直直链，输入脚正对座子；双面各一颗芯片时两面镜像。芯片连同去耦、滤波整组转向或平移，组内相对位置不动；转完逐颗核去耦到电源脚的距离没变远。
- **证据**：正面 ADS 整组转 180°、东移 10.3、南移 1.45；复核去耦距离一颗没变远。
- **置信**：低。

## 3 芯片转向后换脚：数交叉，整段对调；通道映射谁吸收由用户定

- **情形**：芯片转 180° 后输入顺序反了，座子不换脚就全交叉。
- **规则**：按实际焊盘坐标数交叉，比较几种对调法；整段对调（含 BIAS/WCT 等辅助脚）常能到 0 交叉，还能让正反两个座子同序。换脚会改通道映射（本板 k ↔ 9−k、P/N 互换），由线缆/表带还是 App 固件吸收，必须问用户，写进方案和映射表（`d2/pinswap.json`）。换脚后原理图要跟着同步（见 pcb-design 原理图交接 C 节第 6 条）。
- **证据**：只对调 16 脚交叉 32（两根辅助线横穿电极链）；整段对调 0。示意图交叉数与实板差 1（辅助脚实板同列上下排），以实板坐标为准。
- **置信**：低。

## 4 纵向空间不够：ESD 成对两排，缝中共用正反地孔

- **情形**：ESD 一排放不下，或放下了地脚没处打孔。
- **规则**：每通道 P/N 成对走线（对内 0.5、对间 1.1），ESD 信号脚压在自己线上、地脚朝对与对之间的缝，分两排；缝中打地孔，正反两面同位共用。串阻各颗按动态规划左右微调（相邻间距下限、横挪上限），整组再南移一点。代价：共用孔离同网地焊盘只剩 0.05，几何定死，记进风险表，板厂阻焊桥做不到就得拉开两排重排。
- **置信**：低。

## 5 分层：敏感链正下方只留地

- **规则**：照参考板，第一内层整层地、不走线；第二内层只走电源和慢数字。电源铺铜区盖住敏感链或芯片的，改成绕开的 L 形；旧位置遗留的碎地岛删掉。模拟 / 电极信号只在表层。
- **证据**：原 3V3 区盖住电极链和芯片一排脚（复核抓出），改 L 形后链和芯片正下方只剩地；In1 走线 242 mm → 0，地铺铜占板面 92.9%。
- **置信**：低。

## 6 布线顺序：骨架直连锁定，其余逐网 A*

| 步 | 做法 |
|---|---|
| 1 | 规则清楚的段用脚本直连（座子 → ESD → 串阻、数字总线骨架），全部锁定 |
| 2 | 剩下的逐网 A*：电极链限本面、不许打孔；数字只补缺，不拆锁定骨架 |
| 3 | 电源先用 0.25 布通主干，再逐段加宽到 0.3，撞规则的段退回原宽 |
| 4 | 地：口袋和碎块打缝合孔或短线接主地；再在板边一圈、芯片四周、空地补缝合孔，到地孔占过孔 ≥ 70% |
| 5 | 收尾：清悬空、线头对孔心、斜角段拆成横竖 + 45° |

- 本板没用 Freerouting：逐网 A* + 锁定骨架已布通，线型可控，结果 0 个非 0/45/90° 段。
- **正反镜像的同名数字脚**：飞线在芯片底下打 X。把芯片本体框以外临时设成禁布（`add_body_box.py`，框外四块），只留本体底下给 A* 并线（F 短线 → 1 孔 → B 短线；8 根里 DIN_B 另有 3 段经 In2 短桥），布完删禁布；结果嵌套、不交叉。

## 7 自写 A* 加线模式的六个坑

| 坑 | 现象 | 改法 |
|---|---|---|
| 「只加不拆」模式仍按旧逻辑先删本网已有线和孔 | 本网已有孔没留在孔表里，后面的网不躲它 | 删自身对象、删孔表两处都受这个开关控制 |
| 部分连通模式下根焊盘被围死 | 整根布不出 | 换下一个焊盘当根 |
| 新网从未被采纳 | 跑完没加线 | 采纳条件：只加模式，或本网原来没线，或新解更好 |
| 新线沿用旧线宽 | 宽度不对 | 只加模式用参数线宽 |
| 宽线下小焊盘往里缩会变空 | 光栅化拿到空几何 | 遇空几何直接返回空 |
| 节点数到上限返回 None | 这根网整根作废，部分连通模式下已连上的也丢 | 改成 break，按「这一步找不到」处理，保住已连部分 |

## 8 地焊盘被信号线围死

- **规则**：先拆围住它的那几根线 → 先接地（缝合孔或短线）→ 再重布被拆的线。A* 为接地拉的长地线（本板 26 mm），等缝合孔把那块地接上后拆掉。
- **证据**：晶振、C34、C83 三处这样解决。
- **置信**：低。

## 9 缝合孔的几条硬条件

- 缝合孔离**同网**焊盘也要 ≥ 0.1（不是 0）；复核按此抓出一批离焊盘 < 0.05 的孔，拆了重打。ESD 缝中共用孔 0.05 是几何定死的例外，已记风险（第 4 节）。
- 孔在正反两面都要落在地铺铜里，不然表层悬空；缝合孔之间中心距 ≥ 1.0，不扎堆。
- 孤立碎块用「碎块里有没有地孔」判，DRC 报的碎块坐标是 (0,0)，不能用来定位。
- 脚本：`stitch_gnd.py`（碎块补孔，打不上的地焊盘列给 A* 接）、`stitch_ring.py`（板边/芯片四周/网格补到目标比例）、`tie_gnd.py`（本面直线接主铺铜）。

## 10 KiCad 10 Python 补两条（接 [C07 挪件与 Python 坑](kicad10-placement-pitfalls.md)）

- 同进程 `Remove` 之后再 `ZONE_FILLER.Fill` 或 `LoadBoard`，会段错误或 SWIG 类型表坏掉。删对象、重铺铜各开一个进程（`refill.py`；清理循环放 shell 里，一轮一进程）。
- `track.GetEnd()` 返回的是引用，先 `SetEnd` 再读旧端点会读到新值；先把坐标拷成元组再改。
- 清理只动 DRC 点名的对象（`track_not_centered_on_via` 点名那条线才挪线头）；全板吸附线头、按悬空删一圈会改几何、撞出新错误（`cleanup.py` 注释）；按悬空一圈圈删还会断连接，见 C07 坑文档第 4 条。

## 11 两口径 DRC 与完成判据

- 板文件里存的铺铜可能是旧的：本板直跑 DRC 660 错，`--refill-zones` 才 0。改完用脚本重铺后存盘，**直跑和 `--refill-zones` 两种都要 0/0**。
- 完成判据先写进方案，交付时逐条给数（本板）：

| 判据 | 要求 | D4 |
|---|---|---|
| 原生 DRC（直跑 / 重铺） | 0 / 0 | 0 / 0 |
| 电极链 | 每网 ≤ 10 mm、全表层、0 孔 | 74 网最长 9.0 |
| 第一内层走线 | 0 | 0 |
| 非 0/45/90° 段 | 0 | 0 |
| 地孔占过孔 | ≥ 70% | 72% |
| 电源线宽 | ≥ 0.3 | 按长度 84%，其余窄处列豁免 |
| 不同网近距平行 | 间距 < 0.2 且平行 > 1 mm 为 0 | 0（复核抓出 0.123 后重布） |
| 对插接口门 | 0 不合格 | 0（两块主控） |

- 实现者不自验：另一会话只读复核，用自写几何连通检查（带阴性对照）重算全部数字。
