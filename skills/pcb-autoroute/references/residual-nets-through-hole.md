# 收尾残余未连：只用普通通孔、不许盘中孔（2026-11-03，C08B BA 实测）

适用：板子已经布到只剩几根未连，Freerouting / 自写 A* 都补不上，工艺定死「全通孔、普通孔、不做盘中孔」。脚本在 `scripts/residual/`（KiCad 自带 python 跑；`region_plot.py` 要装了 matplotlib 的 python）。

## 1 盘中孔门（交付前必跑）

- **情形**：自写或外部布线器（`finish_bb.py`、Zap、开窗重布）报「补通了」，KiCad DRC 0 错误 0 未连。
- **规则**：再跑 `via_in_pad.py <板>`，有过孔盘压在焊盘上（同网也算）就退出 1，不许交付。布线器本身也要禁：障碍栅格里焊盘铜范围对过孔一律标禁，不按网放行。判定要看过孔真实穿过的层（`via.IsOnLayer`），否则盲埋孔在内层「压」表层焊盘会误报。
- **证据**：C08B BA thru3 被当成选定打样版合进主干、过了一轮独立复核，后来才查出 XIAO_RESET 的通孔压在 U2.9 上（同网，DRC 不报）——旧 `finish_bb.py` 只禁异网焊盘。去掉后这根线当场又布不通。开窗重布 18/19「连通」靠的是 7 个盘中孔（J400 B6/A6、U17 焊盘上）。门禁阳性：旧 thru3 退出 1；阴性：修正版退出 0。
- **置信**：高。

## 2 Freerouting 1.9.0 要真显示，用 WSLg

- **情形**：1.9.0 在容器里无头（`java.awt.headless=true`）或 `xvfb-run` 下对任意 DSN 都静默卡死、不写 SES（Spark 上两个容器挂了 12 小时没人发现）。
- **规则**：1.9.0 的主类是 `gui.MainApplication`，没有真无头模式。在 thursday-win 的 WSL 里用 WSLg 自带显示：`DISPLAY=:0 timeout 1200 java -Xmx6g -jar freerouting-1.9.0.jar -de in.dsn -do out.ses -mp 20 -mt 0 -da -dct 1 -l en`，用 `offload.sh --host win --detach` 派。先 `ls /mnt/wslg/.X11-unix/X0` 确认显示在；不需要 sudo 和 xvfb。容器里的单必须带 `timeout` 且用 `docker run --rm`，跑完 `docker ps` 查有没有残留。
- **证据**：同一份续布 DSN，Spark 容器卡死；WSLg 7.8 s 出 SES，后续 3 次都稳定。
- **置信**：高。

## 3 GND 扇出孔把相邻信号脚围死

- **情形**：`prep_route` 一类脚本给每个 GND 焊盘就近打一个锁定扇出孔；QFN/LGA 一排脚里某个信号脚出不来，A* 只摸到几百格就 `exhausted`。
- **规则**：先画分层图（`region_dump.py` + `region_plot.py`）看信号脚出口方向上是谁的孔。挨着散热焊盘 EP 的 GND 脚改用短线直连 EP（B.Cu 0.2 mm），拆掉那个扇出孔；相邻几个 GND 脚并成一个孔。拆完 DRC 确认 GND 仍连通。
- **证据**：U2.9（XIAO_RESET）正下方是 U2.8 的 GND 扇出孔 (5.30,24.42)；U2.8 改连 EP、拆孔后 XIAO_RESET 用 2 个普通通孔布通。U16（IMU）右列 3 个 GND 脚各一个孔，把 IMU_SCL 东出口围死（诊断，未修）。
- **置信**：中（修好一处，另一处只诊断）。

## 4 USB-C 单列交错脚 + 板边：先看底层有没有孔位

- **情形**：USB-C 封装单列 0.5 mm 间距，D+/D−/D+/D−（B6/A7/A6/B7）交错，一侧紧贴板边；只能用通孔。
- **规则**：两对不可能都在表层平面连通，中间那个焊盘必须在开放那头打孔，孔还要被另一对的表层环包住。摆件时就要给这个孔留位：表层焊盘开放端外 ≥0.75 mm 见方的空地，**底层同一位置不能压 ESD 或其它件的焊盘**，内层也不能有竖穿走线。板边那头算窗口：线心 ≥ 焊盘边+线距+半线宽，且 ≤ 板边−边距−半线宽，两式无解就没窗口。
- **证据**：J400 东侧焊盘边 38.21、板边 38.55、边距 0.20 → 线心需 ≥38.37 且 ≤38.29，无窗口；西头底层压着 U17（ESD），焊盘列缝 0.35 mm 放不下 0.4 孔，排间缝又和已有 D+ 孔孔距不够。全通孔无盘中孔下 USB_DM 布不通，需挪 U17。
- **置信**：中（几何算清，改法未实施）。

## 5 局部开窗重布

- **情形**：一小片区域里几根网互相把出口堵死，逐网拆线（RIP）会连锁回退。
- **规则**：`window_rip.py 源 目标 x0 x1 y0 y1` 只剪窗内那截未锁定走线和窗内未锁定孔（窗外原样保留，射频/CC/晶振/电源网不剪），再用 `finish_bb.py`（`THRU=1` 只用通孔）把窗里全部接回，短的先布。只在未连下降、0 错误、**盘中孔门绿**时接受。
- **证据**：J400 西头窗 (34.9–38.5, 17.3–22.3) 剪 43 段 11 网，A* 接回 18/19、0 错误；但连通全靠盘中孔，门禁加上后此法对 USB_DM 失效。窗外网线长基本不变（±0.2 mm），段数因网格台阶翻倍。
- **置信**：中（连通能力实测，禁盘中孔后的效果只在 XIAO_RESET 一处验证）。

## 6 A* 只证明「有路」，交付线要照走廊手工重画

- **情形**：网格 A*（40 µm）补出的线有 40 µm 小台阶、焊盘入口非 45° 斜接，Mako 要「走线好看、易懂」。
- **规则**：把 A* 走出的走廊当草图，用 `route_manual.py` 按坐标重画成 0/45/90° 的几段 + 必要的通孔，再 DRC + 盘中孔门。长绕路（线长 ÷ 焊盘八方向 MST > 2）不交付，回头找原因（孔阵竖缝、出口被围）。
- **证据**：XIAO_RESET A* 版 13 段含 2 个非 45°、多处 40 µm 台阶 → 手工 9 段全 0/45/90°，孔心互距 ≥0.626。IMU_SCL A* 只找到 47.8 mm（MST 约 16 mm）绕 U13 一圈的路，Zap 云端 43.4 mm：H2 的扇出孔埋在 aQFN 孔阵里，唯一竖缝（x≈37.43）每层都被占（In2 是 SDA 本身）。可改 GPIO 的网（I2C 等）就换到靠走廊的空脚。
- **置信**：中。

## 7 盲埋孔 A* 结果先对板厂工艺

- **情形**：允许盲埋孔后 A* 一口气补通，DRC 0。
- **规则**：逐个列过孔跨层对。嘉立创 HDI：盲孔只能激光 0.075–0.15 mm、只连相邻层，跨 2 层以上拆叠孔；埋孔机械钻、放内芯；不同网孔边距 ≥0.24。按 0.3/0.4 机械孔画的盲埋孔、互相交叠的埋孔层对都下不了单，要按合法结构重跑。报价量级（5 片 6 层 0.6 mm，2026-11-03 未登录计价页）：全通孔约 409 元，HDI 一阶约 814 元，二阶约 1620 元。
- **证据**：astar0 用 17 个机械盲埋孔（F→In2、In3→B、In4→B、In2→In3、In2→In4、In3→In4）到 0 未连，不合工艺；Mako 定回全通孔。
- **置信**：中（规则来自嘉立创页面，未向工程确认）。

## 8 小坑

- `tidy.py` 在 2001 段的 6 层板上单轮跑 26 分钟 CPU 不出结果；退路是安全共线合并（同网同层、端点相接、方向相同的两段并一段，几何不变），去掉冗余分段但治不了台阶。置信低（一次）。
- `prune_dangling.py` 判 0 而 DRC 报 track_dangling：按 DRC 给的网名、层、长度、位置四项对上再删；删前先快照全部走线（KiCad 10 删除后再遍历会拿到坏对象）。
- `finish_bb.py` 顶部 `PWR_NETS` / `RIP_PROTECT` 是 C08B 的网名，换板先改；`ONLY_NET=网1,网2` 只布指定网。
