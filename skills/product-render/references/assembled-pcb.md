# 黑色阻焊装配图和接口微距

## 先修源场景

1. 从同版装配 CAD、Gerber 和贴片位置表出发。白色 STEP 常只带几何。先检查是否有阻焊、器件和端子材质，再决定怎么上光。
2. 黑色阻焊按用户参考或制造资料选择。用工具分别输出外层铜、阻焊开窗、丝印的遮罩。Gerber 栅格化时指定共同原点、窗口和像素密度。用板框检查方向和尺寸，至少核对两个相隔较远的焊盘或安装孔，确认镜像、旋转、缩放和平移。只把这些图层映射到对应外层板面。
3. 用丝印遮罩画白字，用外层铜与阻焊开窗的交集表示露铜的表面处理。阻焊覆盖的铜走线只留很弱的明暗差。板边、芯片环氧、陶瓷、端子、金属外壳及排线设独立材质。样例的黑阻焊采用线性 RGB 约 0.004、粗糙度 0.41、Specular IOR Level 0.17。低机位如果板面泛灰，先调整柔光相对相机的位置或减环境反射。
4. 带多层遮罩节点的装配用整合好的 `.blend` 渲染副本。里面只放参与渲染的模型和定位层级。用 Blender 的 Pack Resources 或 `bpy.ops.file.pack_all()` 打包纹理，然后保存到可回读的位置。导入的几何、排线和安装关系沿用原装配，简化模型按实际来源标注。

## 同一模型切四个机位

| 镜头 | 找哪里 | 核对什么 |
|---|---|---|
| 三分之四开盖 | 主板中心，仰角 45–60° | 板框、接合处和主要丝印清楚，表带可沿对角线出画 |
| 接口低机位 | 接口口沿，仰角 25–35° | 能看到插口及后侧焊脚，金属轮廓连续 |
| 反侧壳体 | 壳体边缘和板边，仰角 25–40° | 能看到外壳厚度、板边和其他机位遮住的结构 |
| 表耳或排线微距 | 真实接合位置，仰角约 35–50° | 看清接合轮廓和排线路径，允许裁掉大部分板面 |

以下命令可重复换 `--name`、中心、宽度及方位角。从本次导入日志 `CONTENT_BOUNDS_MM` 和模型量测确定中心。示例数值只适用于相近尺幅，方位角按零件朝向填写。

```bash
blender -b --factory-startup --python-exit-code 1 --python studio.py -- \
    --layout assembled --bg dark --no-tray --lighting edge --views detail \
    --detail-target-mm=14,0,6 --detail-width-mm 46 \
    --detail-azimuth=-10 --detail-elevation 29 --detail-deep-focus \
    --samples 160 --no-denoise --width 3200 --height 2200 \
    --name usb-low out/ assembly.blend
```

构图先用 32 采样、35% 尺寸。正式出图用原生分辨率。需要保全丝印和焊脚时关闭景深，以 128–196 采样关闭降噪出一组对照。若仍有明显颗粒，提高采样后复查。每张图检查整体，再以 100% 检查板色、接口位置、针脚和丝印。全图过曝比例低也可能有局部泛灰，局部曝光在原图上核对。多角度预览可以缩小排版，保留各张原图。

已实跑黑色装配的四个机位，验证了同一带 Gerber 遮罩的材质从俯视到低角度可读。具体机位参数和材质数值是工作起点，随装配尺寸与表面处理调整。
