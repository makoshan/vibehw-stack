# PCB 外壳配合法则

## 0. 尺寸来源等级（硬序，不可跳级）

**EDA 源文件 > 卡尺实测 > 照片估测 > 渲染图**。
照片估测实战误差 ±2mm（曾把 HDMI 开孔错 2.4mm、把 USB-C 放错板端）。
拿到 EDA 工程（.epro2/epru 离线解析，或 easyeda-api skill 桥接实时读）后，
所有横向坐标一律以它为准；EDA 是 2D 的——**Z 向高度必须卡尺**（插座栈高、
连接器高、元件高）。epru 是 JSONL：DOCHEAD 分文档、`||` 分头/载荷、单位
mil×0.0254=mm；板框在 layer 11（含缺口圆弧），焊盘 PAD 的 hole 给钻径。
立创 EDA 导出的 **Protel ASCII `.pcbdoc`** 是文本，`|RECORD=Track/Arc/Pad/Component|…|X=…mil` 正则可解：
板框在 KEEPOUT 层 Track/Arc，安装孔是 HOLESIZE>3mm 的 Pad，`COMPONENT=n` 把焊盘/丝印线挂回元件求接口包络
（泰山派 45×70、4×M3 孔距 35.86×60.85 就是这么来的，和原厂钣金 STEP 的 60.85 分毫不差）。

## 1. 壳体接触四区规则（铁律）

壳体特征只允许接触 PCB 的四类区域，**绝不压有元件的板面**：

1. 边条焊盘区（屏蔽罩脚焊盘等，平面镀层）
2. 结构缺口（侧卡扣缺口、键槽——板体挖空处天然无件）
3. 裸露大地焊盘（如板边 GND 半月盘；孔径 <1.5 不做销，用兜边爪）
4. 板边缘本身

压肋、卡舌、挡条、兜爪全部落在这四区；每处接触留 0.1–0.2 面间隙。

## 2. 过墙缝/开孔三算

- **过板缝按"板+边缘元件"开，不按裸板**：金手指边 8mm 内常有高件
  （功率电感 ~3mm）。缝的截面 = 板厚 + 背面件净空(≥3.5) + 正面件净空(≥1.4)。
- **连接器开孔按线缆胶壳算，不按连接器壳算**：贴板边齐平的口，插头胶壳要
  穿完整壁厚才够得着。USB-C 过 3mm 壁至少 13×7.5。
  **写成公式，别只写在脑子里**：开孔 = 接口包络(+放量) **∪** 插头胶壳包络，两者都以接口中心对中，
  胶壳尺寸放参数表 `PLUG_ENVELOPE`（L3 默认：USB-C 13×7.5 / micro HDMI 11×7 / USB-A 17×8.5，量到线就换 L2）。
  接口凹进壁内的量 = 壁厚 + 内壁肋高 + 滑入间隙（aMac 例 3.7～4.4），凹越深胶壳越要伸进洞。
  实打教训：Y 向按接口加了放量、Z 向只按接口高 +2，C 口洞高 5.9，胶壳 6.5～7 卡在洞口——引了规则只做一半。
- **原厂壳内壁常有斜格加强肋**（aMac 后壳：1.59→3.17，间距 4～8）：矩形口的边必切到某根肋留 0.1～0.7 残根。
  对策：口四周先刮平一圈到皮（保留皮厚+0.15），再开通孔；相邻刮区间隔 <3 合并，否则夹在中间的横肋被切成两半。
  刮区边缘剩下的肋残根是站在整块皮上的凸起，不是薄壁（见 §6 分类）。
- **壁内空腔查交叠**：同一面墙里的槽榫、卡扣槽、风槽是三维共存的，改任何
  一个都要重查两两间残壁 ≥0.6。墙能容 1.1 宽槽的前提是 墙厚 ≥ 槽宽+2×0.65。

## 3. 装配路径自由度

- **带穿墙连接器的板不能四角全销**：销逼垂直落、凸出端口逼斜插，互斥死锁。
  留旋转自由度：端口侧立柱去销留平台，远端一对销（斜插端口→旋下→销入孔）。
  板与端口墙留 ≥0.5 斜插间隙。
- **滑入路径单独扫**：终点 0 穿插不代表路上不刮。预装单元（板+器件+支架）从开口沿装配方向每 4 mm
  一站对壳求交（aMac：USB-A 面离肋 0.12 时终点干净、11 站里 10 站在刮 1～7 mm³）。板↔侧壁肋滑入间隙 ≥0.4。
- **装配顺序只算一种**：板先上支架（螺丝在壳外拧），整单元从开口滑入。反过来从背板塞，螺丝刀会被后台阶挡住——
  探针要按这个顺序扫，README 要写死这个顺序。
- **板子姿态三选一要算**（转 90°/平放/竖装）再动手；原作者的 6° 倾斜是为了躲顶部风道——用"掏风道底板口袋"替代倾斜，
  接口就能正对壁。
- 卧式 SODIMM/锁扣座必须 20–30° 斜插压平（TE 114-115015），0° 水平推入
  物理不可能；卡带式直插只有立式座（ATTEND 124B-150A02 类，~25 次寿命）
  或定制连接。几何怼合 ≠ 电气可靠。

- **能装下不等于能接线或测量。** 情形：封装内预留测点、焊桥或维修接口，周围还有表带、线束、固定件。规则：从操作入口到目标建出完整探针/插头/地夹包络，所有遮挡件同时参与；闭合、拆盖、拆舱分别给结论和必要断开步骤。只检查指定工具姿态，不外推成整个拆装过程通过；负对照保留未开孔或少拆一个遮挡件。证据：原力手环C07五个背面测点拆顶盖仍不可达，单移CH12后仍撞织带/链节；拆舱检修孔候选的五条指定测量路径交体积0，原底板阳性各0.19635立方毫米（service-access-check.json，2026-10-22）。置信：低（名义CAD验证；工具尺寸假设，拆卸动作及实物未验）。

## 4. 对齐链单一参数源

两个要配合的打印件（壳↔卡、槽↔板面）共享的平面高度，必须从**同一组参数**
分别推导并断言相等（如 插座坐面 = 底壁+立柱+板厚+栈高 == cart_z0+板位）。
禁止两边各写各的字面量——版本一多必跑偏。

## 5. 实打配合经验值（FDM 0.4 喷嘴）

| 配合 | 设计值 |
|---|---|
| 板入槽横向 | 单边 +0.8~1.0（设计 71.5 实打需 73.2 的教训：预留 +1.7 总量） |
| 销入板孔 | 孔 −0.35~0.4（⌀3.18 孔配 ⌀2.8 销） |
| 卡扣凸点 | R0.8 入 R1.0~1.1 槽，PETG（PLA 断扣） |
| 盖插环 | 单边 0.15 |
| 面接触间隙 | 0.1~0.2 |
| 卡舌入结构缺口 | 单边 0.2，根部留 0.3 |
| 板滑过侧壁肋 | 单边 ≥0.4（0.12 一路刮） |
| 落地脚↔壳地面 | 0.1 面间隙（0 会报 36 mm³ 面接触噪音；地面实测 2.73 不是 2.70） |
| M3 自攻进打印件 | 底孔 Ø2.5，螺柱 Ø7×3 + 框板 3，穿 1.6 板后啮合 4.4（≥3 即可）；板孔 3.17 对 M3 只有 ±0.095，第 4 颗发紧扩到 2.7 |

## 6. 校验闭环（每次改动全跑）

1. `scripts/gen … --write` → `inspect validate`（实体健全）
2. `inspect interfere`（装配零穿插；注意容差 1mm³ 会放过小穿插）
3. 每个模型配一个 `check_*.py` 布尔探针脚本：槽通、孔通、间隙存在、
   薄壁完整——探针比目测快且可回归
4. `export --stl` → dfam_tool `measure` 看 min_wall：抓 0.1~0.5 的意外残壁
5. snapshot 双向视角人工过一遍

6. **探针的假阳性防线**：加载壳/件先核体积区间 + 水密，不在区间直接抛错。布尔炸成 0.3 cm³ 的残骸后，
   `check_fit` 对着它报过"全部通过"——这比任何几何错都贵。
7. **薄壁 vs 凸起要分开**：面心沿自身法线退 0.05 到空气，再往壁内打，第 1/2 交点差 = 背后皮厚；
   皮 ≥1.2 就只是凸起（肋残根），不判红。原厂树脂壳会有几千个"薄面"读数，全是棱角噪音——加"对面平行(dot<−0.9)"判据。
8. **孔位探针两法互证**：EDA 重新解析孔坐标 vs STEP 圆柱面轴心 vs STL 顶点拟合圆，Δ>0.05 红。
   轴心用 `BRepAdaptor_Surface(f.wrapped).Cylinder().Axis().Location()`；**`Face.center()` 对周期面给参数中点，
   落在面上，偏一个半径**（4 个底孔齐刷刷偏 1.25）。
9. `import check_x` 会把探针脚本整个跑一遍再 `sys.exit`——探针要么包 `main()`，要么复制函数别 import。
10. **元件包络（courtyard × 高度）报的碰壳，用 EDA 自己导出的整板 STEP 实体复核。** 情形：PCB 入壳检查用包络盒，报连接器之类碰侧壁。规则：先用 `scripts/step_export_check.py <板>.kicad_pcb <输出>.step [透传参数，不含 -o]` 导整板（内部调 `kicad-cli pcb export step`；kicad-cli 缺模型只打「Could not add 3D model for J2.」告警、退出码仍 0，脚本数出来，退出码 1 并列位号；2 = 导出失败或没出文件），列出的位号 STEP 里没有实体，碰壳结论记「未验证」，补模型重导前不许写「不碰」（封装没写 model、模型设了隐藏的件 kicad-cli 不报，也要自己核）；再按模型名找那颗件的实体量 bbox，换到装配坐标再比；自己按转角手算时两种转向都算一遍，以导出结果为准。证据：原力手环 C06 八路版（10-25）USB 座 TYPE-C-31-M-14 包络报碰壳 6.33 mm³；导出 STEP 实体最外 X 21.43，侧壁内面 21.8，余 0.37，是假冲突（八路版 README B 节）；手算的两种转向结果相反，所以以导出结果为准。置信：低（单次）。
11. **件高用厂家图纸最大值，不用 EDA 3D 模型。** 情形：电池、盖板压在元件上方，余量按件高算。规则：入壳检查的件高先取厂家封装图的 max，没有图纸才退回模型实测并标出来。证据：C07（10-24，`PROGRESS-20261024.md` I 节）ADS1298 nFBGA 的 KiCad 模型高 1.10，TI ZXG0064A 图纸「1.45 mm max height」，降板加挪高件的组合方案因此不成立；C06 八路版按 1.10 推演的 S1–S4 四组改法也随之作废。置信：低（单次）。

- **高度公差链里易漏项（翘曲/落座/电池单边公差）、板下障碍用高柱求交（`fitprobe.under_board_top_z`）、板下浮动件（表带/电极）要限位并做上移正反对照（`fitprobe.floating_stop_check`）、大件位置先全扫、USB 开口按插头与射频座按插合高**：见 `references/height-stack.md`（原力手环 C07，2026-10-25）。

通用探针已合并进 `ai-cad-pipeline/scripts/fitprobe.py`（自检 `test_fitprobe.py`）：`assert_healthy`（体积区间+单体防残骸假通过）、`clash`（静态两两求交）、`slide_path`（逐站滑入求交）、`plug_sweep`（插头胶壳扫掠+开孔余量）、`cylinder_axes` / `match_holes`（OCC 圆柱轴心与 EDA 孔位互证）、`under_board_top_z`（板下高柱求交）、`floating_stop_check`（浮动件限位正反对照）。历史样板：`~/go/202608/赛博 AI/amac1984-taishan/check_*.py`。

build123d 0.11 坑：`Pos * Compound` 包装体动而 `.children` 不动——对
Compound 逐叶变换再求交，否则探针报假干涉；圆角矩形轮廓禁 3D 倒角
（切线链会崩），倒角进草图或跳过。

build123d 0.13 坑（原力手环 P45，2026-10-27，同一天犯三次）：
- **`Compound(children=列表)` 会把列表里的形体从原来所属的 Compound 挪走。**事后为求交、取包围盒再包一次，原零件就静默少件，导出缺件、碰撞检查也跟着失真（XIAO 软板最高点 5.83 变 4.36，那次「干涉 0」不可信）。临时包装一律 `copy.copy()` 每个子件，或直接逐个取 `bounding_box()`。通用防护：登记零件时记 `len(shape.solids())`，导出前逐个核对，不一致直接报错。
- **厂家 STEP（如 XIAO 官方模型）整体布尔不可靠**：既会冒出外框以外的假体积，也会漏掉真压入。两边都拆成 `solids()` 逐对求交再相加，并配一条「把它放在第二个参数、下压」的反例。
- **外壳角上壁厚**：外圆角 = 内圆角 + 壁厚才均匀；先算内腔圆角能否让开板角（板离墙越近，内圆角上限越小），再定外圆角。只改内圆角会把角壁削到近零，碰撞检查查不出，要单独算最薄壁厚。

## 7. 同类作品拆解所得（OttoClaw/闪猫 Otto 2.0，2026-09）

- **板固定最小件数**：2 定位销（只管 XY）+ 1 螺柱（只管 Z 压紧）——
  一颗螺丝完成锁定，比四角全销/全螺更省且无装配死锁。
- **盖扣**：插沿四边做悬臂卡钩（带倒扣的 L 钩）比半圆凸点保持力强、
  弹性可设计；凸点适合低频开合，钩适合常开常合。
- **葫芦键孔**（keyhole slot）：螺丝头滑入即挂，免工具安装舵机/配件。
- **内腔顶角 45° 三角撑**：一物两用——侧开口打印自支撑 + 盖的落位面。
- 取舍原则（作者原话）：可以藏线但不好组装时，选好组装。
- 学结构不抄几何：MakerWorld Exclusive License 禁止平台外分发与商用。

## 8. 交付节奏

改参数 → 重生成 → 全校验 → 只重打受影响件。先打配合试片/局部切片
（背墙端口条、槽区 20mm）再打整件。每版打包 stl/step/src/README 快照。

- **试片长什么样**：端口条 + 支架上离它最近的两个螺柱 + 地脚，一块小件（aMac 14×78×28，7 g）。
  真板子拧两颗螺丝上去，一次验四件事：孔距、螺柱高/板离地间隙、端口位、插头够不够着。
  不要裁原厂网格做试片（斜肋 + 通风槽让封盖封不严）——按同一份参数**参数化重建**平壁 + 口 + 螺柱，
  再用"器件包络 ∩ 壁板 = 0"证明它和整壳的口一致。
- **打印朝向要量不要猜**：对每个候选贴床面算"法线朝该方向、贴外包络的面积与散布"（aMac 侧壁 4200 mm² / 0.28 平面度），
  端口做成贴床层的竖直通孔最干净；屋顶用内部支撑从开口掏；再算候选朝向下每层外伸量——2 mm/层（64°）的斜面朝向别选。
  原厂树脂件在 FDM 上先探真薄壁（对面平行 <0.8）有没有，aMac 后壳只有 0.1 mm²，1.6 壁 = 4 圈 0.4 能打。

## 9. 改原厂网格（trimesh + Blender 布尔）

- **多把刀先 `union` 成一个实体，再对壳做一次 `difference`**。刀具直接拼成一个网格是非流形（重叠），Blender 算出残骸；
  逐把顺序减会在刀面正好压在原网格某根肋的面上时出非水密。结果必须水密、单体、体积在原壳 90～100%，否则抛错。
- 刀具边界用 .13 这种零头，别落在 30.0 / 58.0 这类可能与原壳特征共面的整数上。
- `slice_plane(cap=True)` 封盖要 `mapbox_earcut`（cad venv 是 uv 管的没有 pip：`uv pip install --python <venv> …`），
  且对带肋壳封不严——能参数化重建就别裁。
- **zsh 下 `rm -f a/*` 无匹配会中止整条命令**：旧输出没删就被当成新结果。写死路径或 `setopt nullglob`。

## 配合校验用 fitprobe，不要临时手写

`~/.claude/skills/ai-cad-pipeline/scripts/fitprobe.py`（自检 `test_fitprobe.py`）把本法则里的检查做成了带类型的查询：
`assert_healthy`（加载壳/件先核体积区间+单体，防残骸假通过）、
`clash`（干涉量+重叠块 bbox）、`fits`/`envelope`（真元件尺寸的方块能否进、扫可行位）、
`wall_at`（斜壁/曲面壳在某高度的真实壁位——贴壁特征必须按它定位）、`solids`（一个打印件必须是一个实体）、
`outside`（肋/柱有没有捅出外表面，同一件内 interfere 查不到）、`sag`（曲面前脸弧垂，平面元件要 < 0.5）、
`plug_sweep`（沿插拔轴把 `PLUG_ENVELOPE` 线缆胶壳从壳外扫到插座面，同时核壳壁开孔四边余量）、
`slide_path`（预装单元沿滑入轴逐站平移求交，抓终点 `clash==0` 但中途被内肋刮住）、
`fpc_tail_length`（180° 折弯排线的闭合连续曲线长 vs 标量估算）、
`cylinder_axes`/`match_holes`（OCC `BRepAdaptor_Surface` 提取真实圆柱轴心与 EDA 孔位互证，避开 `Face.center()` 周期面偏一个半径的坑）、
`under_board_top_z`（用全高柱求板下最高障碍 Z，防薄片截断）、
`floating_stop_check`（板下浮动件上移小量全清、上移限位量碰限位条不碰 PCB 的正反对照）。

每个查询答不上来会抛错说缺哪个参数，不会静默返回 0——退化布尔返回空集导致探针假阳性，是这条流程上最贵的错误。
设计来源与完整拆解见 `ai-cad-pipeline/references/adam-plugin-lessons.md`。

- 全量扫描反例、试片与整机验收边界、不同电极布局不可直接拼接：见 [证据边界](references/evidence-boundaries.md)。

## 11. Web3D 装配体 GLB 轻量化与关节注入（SimReady 管线）

- **CAD / STEP / trimesh 导出的装配体 GLB 先剥辅助层、单色顶点转材质、实例去重加 Meshopt，再进仓库或网页预览。**
  - **情形**：从 `build123d` / `trimesh` 或 STEP 导出整机装配 `.glb`（含多颗同型号阻容包络盒、电极头、螺钉，或开盖/插拔/展开多姿态）。
  - **规则**：① 剥离 `STEP_topology` 与 `_CAD_EDGE_*` 辅助属性；② 将单色 `COLOR_0` 顶点数组归并为共享 PBR `materials`（禁止全顶点重复颜色数组）；③ 1 µm 焊接顶点后将局部包围盒归中、平移写回 `node.translation` 并合并相同几何实例（保留全部节点名，供拾取/位号对齐）；④ 网格走 `MeshoptEncoder.reorderMesh` + `encodeFilterExp(16-bit)` + `EXT_meshopt_compression`；⑤ 开盖、USB 插拔、扣环转动等检视行程写入节点 `extras.joints: [{ type, pivot, axis, min, max, unit }]`（Three.js `object.userData.joints`），前端用 12 行四元数/平移代码驱动；⑥ 门禁解码验包围盒时必须先 `geometry.boundingBox = null; geometry.computeBoundingBox()` 强制从解码后真实顶点重算（否则 `Box3.setFromObject` 只读 JSON `accessor.min/max` 缓存而漏检），且网格统一命名为 `mesh_${i}` 防止 `GLTFLoader` 在 `node.name` 丢失时拿 `mesh.name` 顶替造成假通过。
  - **证据**：借鉴 `codepawl/simready-glb`（2,595 个模型 228.1 GB → 3.19 GB，0 减面靠删 USD 实例原型 + Meshopt + 双轨关节）；原力手环 `scripts/simready_glb_opt.mjs`（`evidence/2026-11-02-simready-glb-opt.md`）实测：`v12/system-c7-f03/.system.step.glb` 从 **35.03 MB → 584.2 KB（-98.37%，843/843 节点）**，`r12-afe-ds-ba-n54/mode2-flat.glb` 从 **2.81 MB → 406.9 KB（-85.88%，网格 375→127，唯一三角面 -55.3%，36 关节）**，`mode2-wrapped.glb` 从 **3.86 MB → 764.9 KB（-80.64%）**，真实顶点包围盒最大偏差 `0.0003 mm`，两条必失败对照（偏移 +2 mm、抹除 1 个节点名）均判红。
  - **置信**：中（跨 `vibe-hw` PR #124 与原力手环 4 个不同来源 GLB 复现）。

## 12. 软板接背靠背座（C08B 2026-11）

- **两尾脚序按世界坐标排。**
  - **情形**：软板尾巴插两颗座，展开图要定脚序。
  - **规则**：从原板铜线端点读出每颗座脚 1、脚 N 的实际位置，check 断言每根尾巴的世界坐标单调，再喂「画成同向」反例。背靠背的两颗座脚序通常相反，以铜线读数为准。U 形折不改横向次序，只翻接触面。
  - **证据**：原力手环 11-06，30P 和 34P 两版候选都把两尾画成同向，D16 铜线证明两座反向；R3 起按世界 x 排，`v12/c08b-d16-fpc34-r7-20261106/REVIEW.md` 核过单调。
  - **置信**：中。同一错犯了两次，都有铜线端点证据。
- **两座 x 范围重合时，先比两片软板。**
  - **情形**：两根尾都从同一侧 U 形折进板两面的座，两座 x 范围重合，单片展开图放不下。
  - **规则**：铜线能按座分组就沿组切成两片。这种折法下上下次序反转：盒底下层走外圈，接板上方的座。座子开盖高度大于板下空间时，板在盒外先插好锁紧，再绕板边翻下。
  - **证据**：C08B R5–R7，两片网络交集为空，两片 DRC 0 错，`v12/c08b-d16-3d-r7-20261106/` 里两尾净距 0.03 mm。
  - **置信**：低。只有模型，纸样和实物未折。
- **尾长用闭合曲线算，不用标量估算。**
  - **情形**：要定折弯占位和尾长。
  - **规则**：标量公式只用来比方案。定长度前，用固定弧长、端点闭合的连续曲线在 3D 里解一遍，底面 Z 要算上底壳厚和触点凸出。
  - **证据**：C08B 标量估算尾 A 8.31 mm，闭合曲线要 8.73 mm，见 `v12/c08b-d16-3d-r7-20261106/checks.json` 的 `tail_length_back_to_R6`。
  - **置信**：低。只见过一次。
