# 正交参考图需求清单（给用户/AI 出图用，实测有效 2026-09-03）

统一风格要求（每张都写）：**纯正交投影、无透视、无阴影无反光、白底、平涂**，叠加 **10 mm 网格**，细线画外包尺寸框并标注；
同一张不要表情、配色、手机对比。渲染感美图没用，要的是能描轮廓、量半径的图。

| # | 视图 | 内容 | 用途 |
|---|---|---|---|
| 1 | 主体正视图 | 只画壳体（去附件），W×H 外框 | 前脸轮廓、屏黑区尺寸与圆角、边框宽 |
| 2 | 主体右视图 | 只画壳体，D×H 外框 | 前平后圆程度、顶部拱度、底部收腰、前脸后仰 |
| 3 | 主体俯视图 | 壳体 + 附件座位置，W×D 外框 | 四角半径、座坐标 |
| 4 | 主体背视图 | 格栅 + 端口排 | 槽数/长宽/端圆角，口形状与高度 |
| 5 | 主体仰视图 | 底板、轮、万向轮、触点 | 轮位、露出量 |
| 6 | 中央纵剖面（前→后） | 分模线、壁厚、屏板进出 | 分模高度（**AI 常编造，与原稿核对**） |
| 7 | 附件总成特写 | 正交侧 + 正交前，带网格 | 臂长、角度、分段 |
| 8 | 小件特写 | 触角/装饰盖等，带网格 | 直径、倾角、厚度 |

第 6 张 AI 通常画不好剖面，画不出改"三件分离的正交侧视爆炸图，件间距相等"。

## 读图纪律
- 每个面板读出的数字写进参数表并标 `# panel N`。
- AI 图内部结构（分模、板位）是编的：与原稿/硬件冲突时原稿与硬件赢，README 明写"未采用面板 6 分模"。
- 尺寸链要闭合：背面 10+24+6+12+14 = 66 之类先加一遍，不闭合的按边距推。
- 与已知硬件核对：2.8" 屏活性区 57.6×43.2 不可能是 64×37 → 黑面板 = 玻璃盖板，不是活性区。

## Codex 出图命令
```bash
mkdir -p ref && codex exec -C "$(pwd)" -s workspace-write --skip-git-repo-check \
  "请使用 image generation tool 生成：<上表某一行的完整描述 + 风格要求>，存成 ./ref/<name>.png"
```
1–7 分钟/张（Bash timeout ≥ 420000 ms）。多方案对比（如 4 种侧影 A/B/C/D 一排）一张搞定，让用户挑字母。
