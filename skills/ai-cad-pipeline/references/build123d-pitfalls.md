# build123d / OCP / cadgen 坑单（按遇到顺序累积）

## 定位与变换
- `Pos * Compound` 只动壳不动 children，用 `.moved()`/对每个 child 变换。
- `.located()` 会**覆盖**图元已带的位置；诊断/叠加位移用 `.moved()`。
- 侧装件 `Ry(±90)` 会把局部 X 映到世界 ∓Z：销轴、指节必须放在会映射到目标轴的局部轴（局部 Z）。
- `_side_cyl` 类辅助：圆柱轴向靠 `Location(rot)` 给，别用 `Pos` 后再 rotate 混用。

## 布尔与拓扑
- 球链融合会 BOP 自交 → 曲指用 `sweep(Circle, Spline)`。
- `offset()` 在 B 样条圆角面上退化成 2D → 内壳用解析内枕头或 Fusion 抽壳 STEP。
- OCC 变半径法则 `BRepFilletAPI_MakeFillet.Add(TColgp_Array1OfPnt2d, edge)` 只在小半径可用（13→11 修得回，14→9 天然合法，13.5→10 / 13→12 修不回；R16+ 在 inset 2.5 全灭）。两圈都变半径 → 拓扑失效。
- 中间体加 `.fix()`；`Solid.fuse(*sols)` 对**只差 0.1–0.15 间隙**的实体不会合并——共面才 fuse（焊接环取 inset=壁厚）。
- `a & b` 交集为空返回 `None`（不是空 Compound）——探针脚本要处理。

## cadgen CLI
- `refs --facts` / `interfere` 吃 render 缓存：改动后先 `scripts/artifact <step> --force`。
- 装配 `gen --write` 偶发不落盘：显式 `--write path.step --force`。
- 厂商 STEP 自带无实体/自交子件（Radxa o1.14.x）→ `interfere --refs` 排除。
- STL 三角化在变半径曲面四角接缝留开边（实体 validate/BOP 都合法）；`--3mf --mesh-tolerance 0.01` 水密。trimesh `fill_holes` 修不回。
- `CADGEN_WARM=1`；Bash 超时给足（装配 gen+interfere 5–10 min）。

## 结构性坑（几何合法但打不出/装不上）
- 多实体打印件：各自 valid、validate PASS，但 STL 不水密、腔内柱悬空。`_finish()` 融合成单实体 + 数 `len(part.solids())`。
- 插环 + 配合间隙 = 悬空环；焊接环接回壳壁。
- 腔内螺柱/立柱悬空 → 肋连壁；开口最后切。
- 特征贴圆角起点：卡扣凸点落在 |y| = 边长/2 − R 处与插环差 0.1 断连；屏窗宽 = 前脸平带宽时窗边成刀口 0.146；肩盘要在平带内。
- 屏模块（含 PCB）比窗大得多：70 宽模块在前壁后 5 处撞 R20 内角，退到 ≥8。
- 跨分模线的口排：只切在一件里 → 另一件挡住；两件一起探针。
- 盖插环实心板会堵死顶部风槽；探针加"槽穿透到腔"。
- 带穿墙连接器的板不能四角全销：斜插→旋下→前销，后排平台，间隙 0.5。
- 开孔按线缆胶壳算不按连接器（USB-C ≥13×7.5 过 3mm 壁）。
- 卧式锁扣插座必须斜插 20–30°，槽内直推不可靠。

## Shell 杂项
- macOS 无 `timeout`；`cp` 被 alias 成交互式 → 脚本里用 `\cp -f`。
- 大改参数用 python 正则批量替换 + `assert n == 1` + `ast.parse`，比逐条 sed 稳。

## 2026-09-03 v4.4 追加
- **OCC 也能放样钟形体**：`loft([RectangleRounded 底, RectangleRounded 顶(可偏移)])` + `BRepFilletAPI_MakeFillet` 两点法则 `TColgp_Array1OfPnt2d(1,2)`（(0,r0),(1,r1)），起点按 `edge.position_at(0)` 判方向；前 R14→后 R24 在 inset 0/2.5/2.65 合法，inset 4.25 用 R20。Fusion 只在此路失败时才必需。
- 两件重叠 0.01（`z1 + 0.01`）比共面更糟：fuse 留薄片 → 3MF 开边。要么共面（同一 inset），要么重叠 ≥0.2。
- 肋条/加强块用 `& _pillow(0.6)` 裁进壳内，否则从斜壁/圆角处伸出，interfere 查不到（同一件）。
- 倾斜壁上的附件用 `side_x(z)` 之类的高度函数定位，不要用 box_w/2。
- 顶部圆角坡上的座台要向下延伸到坡下（z60 起），否则悬空 1–2 mm。
- 假件（屏模块）要按"壳体能装什么"反推包络并写进 README，不要按想象的模块尺寸硬塞；扫描 (w,h,zc,back) 组合找零干涉。
- **参数列表里塞行尾注释再拼接 → SyntaxError**（第二次犯）：注释放上一行。
- 探针脚本里的尺寸必须引用参数（`c.ant_plug_d/2 - 0.1`），不能写死：改了插头直径后写死的 r2.3 探针报"座被堵"是假阳性（v4.5）。
- 同一件事渲染稿与 AI 尺寸图冲突时渲染稿赢：面板 8 的 ⌀12×6 触角座在渲染里是 ⌀8×2 的小座；先对整体形态，再用尺寸图补数字。

## 超椭圆/放样曲面壳体（2026-09-03 v5.0）
- **周期样条会在超椭圆的平直段外凸**：48 采样点时 x 方向超 2.2%、96 点 0.51%、128 点 0.28%。用 96 点 + 标定系数把外包拉回名义尺寸，别指望采样点落在名义面上。
- **放样的 B 样条也会越过端截面**（越平的 crown 越明显，只在那一端），端截面要内缩一点点；两端 crown 不同就用**非对称内缩**。
- **曲面壳体的"能装什么"必须扫参数求解，不能凭想象**：顶底内收会吃掉前脸可用面积，真 2.8" 屏模块 69×50 在最圆参数下整个内腔都放不进。扫 (w,h,zc,back) × 三个壳件求零干涉，再反推可用包络写进 README。
- **圆润度的硬约束是配合面的弧垂**：前脸超椭圆指数 n 与弧垂 sag = b·(1−(1−(x/a)^n)^(1/n))；平面屏要 sag < 0.5mm。先算 sag 定 n，再谈好不好看。
- 直壁改斜壁/曲面后，**所有贴壁特征都要重新定位**：螺柱要按最窄处（近地面）定 x；肩盘等用高度函数取真实半宽；`& _pillow(wall)` 把柱子裁进腔内。
- 环形插环挡住穿层零件时，**只切掉那一段弧**（先建环、单独减料、再并入），别去减整个壳。
