# FDM 切片决策

一句话：**摆放方向决定件能不能用，参数只决定它好不好看。先定朝向，再谈层高。**

`gcode` skill 负责调切片器 CLI，`bambu-labs` 负责传给打印机。**这个 skill 负责在那之前做判断**——那两个都不会告诉你这个件该躺着还是立着。

## 1. 摆放：唯一真正重要的决定

FDM 件的**弱面是层与层之间**。同一个几何，摆放不同，强度能差一个数量级。

规则：**让受力方向落在层平面内，不要穿过层。**

| 特征 | 受什么力 | 怎么摆 |
|---|---|---|
| 表耳 / 挂耳 / 吊环 | 拉 + 剪（表带、手腕甩动） | 受力方向必须在层平面内。主壳平放时表耳在侧面水平伸出 → 拉力在 XY 平面内 → **对** |
| 卡扣悬臂 | 反复弯曲，表面受拉 | 层线沿悬臂长度方向。悬臂竖着打＝层间受拉，掰几次就断 |
| 薄底壁 | 按压、硌 | 平放，让壁厚方向 = Z，靠层数扛。1.2mm ÷ 0.16 只有 7.5 层，一层没贴好就漏 |
| 螺丝柱 / 立柱 | 拧入时受环向拉 | 立着打最差（层间劈裂）。能平放就平放 |
| 横孔（生耳孔、轴孔） | — | 孔轴水平时孔顶要桥接；Ø<2mm 可自桥接但会下垂，孔会偏小偏扁 |

**先问这个件坏的时候会怎么坏，再决定怎么摆。** 不要按"哪个面最平"摆。

## 2. MAKO 手表的既有摆放规则（V3–V36 实践）

| 件 | 朝向 | 出处 |
|---|---|---|
| 主壳 / shell | **屏窗面朝下** | V8 / V9 / V14 |
| 后盖 / back / back_cradle | **外背面朝下，卡扣朝上** | V8 / V14 |
| 内部托架 / carrier | 平面（支脚）朝下；**悬空横梁必须查支撑** | V8 / V14 |
| 按钮推杆 / pusher / button | **大端朝下** | V3 / V8 / V9 |
| 屏幕支撑圈 / screen_ring | 平放 | V14 |
| 底壳（V3/V4 早期分件） | 底面朝下、开口朝上 | V3 / V4 |
| 上盖（V4） | 接合面朝下、弧面朝上 | V4 |

**所有导出的 STL 底面已归零，是起始摆放。** 但 V14 README 写明：「打印方向是起始摆放，**不是已验证的切片配置**」——切片器里仍要逐件确认。

## 3. 支撑：不是"要不要"，是"放哪不碍事"

MAKO 手表实践中需要局部支撑的位置：表耳、USB 开口、生耳横孔、顶部槽、carrier 的悬空横梁、收拢曲面的局部。

**两条硬规则（踩出来的）：**

- **卡槽 / 卡钩工作面不布置难以清除的支撑**（V8）。工作面上留支撑残渣 = 卡扣配合尺寸直接废掉。
- **按钮导向面和压盖接触面不留支撑残渣**（V22.1）。

装配前必须做：**去除毛刺、象脚（elephant foot）和卡槽内残余支撑**（V8 装配步骤 1）。象脚会让第一层外扩 0.1–0.3mm，正好吃掉配合间隙。

## 4. 参数：先解决版本矛盾

仓库里三套参数不一致，用之前先确认当前用哪套：

| 版本 | 材料 | 层高 | 墙 | 来源 |
|---|---|---|---|---|
| V3 | PLA | 0.2（顶杆建议 0.12） | 3 圈 | V3_README |
| V8 | PETG | **0.16** | 3 道 | V8_PRINT_README:45 |
| V22.1 | — | **0.2** | 按 3 条线设计壁厚 | v22_1/README:28 |
| 内部分享 PPT p21 | PETG | **0.16** | 3 道 | 最小层时间 8–10 s |

BambuStudio 里存的 process 是 **`0.20mm Standard @BBL A1M`**——和 PPT 写的 0.16 对不上。**0.16 那套是 GUI 里手调的，从未存成文件。**

选 PETG 不是随便选：V22 电池沉台底 1.5mm，最不利工况（后盖硌硬物集中 50N）安全系数 PLA 4.5 / PETG 4.0，PETG 韧、不脆断。**注意这个系数只对 1.5mm 成立**，V36 减到 1.2mm 后强度未实测。

其他已确认项：0.4 喷嘴；**卡扣保持实心**（不走稀疏填充）；最小层时间 8–10 s（小件散热，不然层间粘不牢又变形）。

## 5. 薄凸台开 brim

**`button.stl` 必须开 brim**——内侧保持腹板只有 0.5mm 厚，不开 brim 打印中会被喷头带倒（V22.1）。

判断：底面接触面积小 + 高径比大的凸台，一律开 brim。

## 6. 设计阶段就得按切片参数定尺寸

这是最容易漏的一条，也是 CAD 和切片真正耦合的地方：

> **定位凸台的壁厚全部按 3 条线（1.2mm）设计，不要用更粗的喷嘴。**（V22.1）

0.4 喷嘴 × 3 道墙 = 1.2mm。壁厚设成 1.2 就是刚好三条挤出线，切片器不会填出奇怪的空腔。设成 1.0 或 1.5 反而会出现"两条线 + 一条稀疏填充"。

**壁厚应当是「喷嘴宽度 × 整数」。** 改喷嘴口径就要回头改 CAD。

## 7. Bambu A1 mini 具体配置

本地已有（BambuStudio 用户 profile，`~/Library/Application Support/BambuStudio/user/<你的账号ID>/`，账号 ID 是纯数字目录，`ls` 一下就知道）：

- machine：`Bambu Lab A1 mini 0.4 nozzle`
- filament：`Generic PETG @BBL A1M`、`Bambu PETG Basic @BBL A1M 0.4 nozzle`、`Generic PETG-CF @BBL A1M`
- process：`0.20mm Standard @BBL A1M`

打印机 LAN 已配（`bambu-printers.json`，a1-mini）。A1 mini 打印尺寸 180×180×180。

`gcode` skill 要的 wrapper JSON 模板（**层高等参数以 native process profile 为准，先把 0.16 那套在 BambuStudio 里另存成 process profile**）：

```json
{
  "backend": "bambustudio",
  "native_config": "~/Library/Application Support/BambuStudio/user/<你的账号ID>/process/<存好的 process>.json",
  "machine": {
    "name": "Bambu Lab A1 mini",
    "bed_size_mm": [180, 180],
    "z_height_mm": 180
  },
  "filament": { "type": "PETG", "nozzle_temp_c": 255, "bed_temp_c": 70 }
}
```

## 8. 全链

```
build123d(.py) → STEP/STL → 【本 skill：定朝向/支撑/参数】
  → gcode skill（切片 CLI，先 --dry-run 再 --execute，然后 validate）
  → bambu-labs（LAN 上传，默认 dry-run，实打要 --execute --confirm-start-print）
```

外发树脂件走 `jlc-3dp`，那边摆放和支撑由工厂决定，但**材料精度 ±0.2mm 或 0.3% 同样会吃掉配合余量**。

## 最后一条

**网格闭合 ≠ 能打，能打 ≠ 能装。** 切片器不报错只说明几何合法，装不装得进去要靠实物。每次改朝向或层高后，配合面的实际尺寸都会变——卡尺量过再下结论。
