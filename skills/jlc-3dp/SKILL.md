# 嘉立创 3D 打印下单

一句话：**上传 STEP 即时出价，装配体必须先拆，材料决定一切，表面处理是另一笔账，停在提交前。**

## 0. 外发前的门（不过不发）

- **结构已冻结**。没冻之前外发是浪费：SLA 一次 2–5 天，FDM 自己打一小时。改一版外发件就废一件。
- 明确这一单要回答什么，写进 `evidence/<日期>-<主题>.md`。否则收货只剩「挺好看」，没有沉淀。
- **该外发的三种情况**：① 精度/表面自己达不到（要光滑、要透明）；② 材料自己打不了（尼龙、金属、高韧性、半透明）；③ 版本冻结要做几只像样的样机。
- 登录用用户的 Chrome（`claude-in-chrome`）。**Browser 面板打不开 3d.jlc.com**（导航被拒），直接用 `www.sanweihou.com`，会跳到 `www.jlc-3dp.cn`。

## 1. 入口

首页右上「在线报价」→ `https://www.jlc-3dp.cn/placeOrder`。
顶部工艺栏并列五个入口：**3D打印**（默认）、多零件/多工艺下单、机械/自动化零部件选购、CNC加工、钣金加工、手板复模。手表这类小型三维件只走 3D打印；**钣金做不了圆角小件，不要误入**。

## 2. 上传

- 支持 `stl/stp/step/obj/3mf`，单次 ≤20 个，单文件 <100M。
- **传 STEP 不传 STL**：STEP 带精确曲面，报价和 DFM 更准；STL 是三角面且动辄 7–9MB。
- `input[type=file]` 用 `find "file upload input"` 拿 ref，再 `file_upload`，不要点按钮（会开原生文件框）。
- 页面硬规则（写在上传区）：**壁厚大于 1.2mm，薄处不低于 0.8mm**。
  实测：V36 `back_cradle` 底壁正好 1.2mm，上传后**未触发任何壁厚告警**。是否为「≥」无书面确认。

## 3. 装配体必须拆（build123d 的坑）

build123d `AssemblyHelper` 生成的 STEP 会被判为装配体，报「模型检测为装配体，需进行拆分后才可下单」。

- 该行有「装配体在线拆图」按钮，能拆，**且正确读出 build123d 写入的零件 label**（`male_clip` / `female_pocket`）。
- 勾选全部零件 → 底部「下载拆图文件」拿 zip（落盘复用），或「一键下单」直接加进列表。
- **下载的路线更好**：文件进仓库，以后不依赖平台。文件名带括号，复制时改名。
- 拆完**删掉原装配体条目**（「删除文件」→ 确认弹窗），否则它占一行且不可下单。
- → 根治：要外发的件直接导出单实体 STEP，别走 AssemblyHelper。

## 4. 选材料（决定价格和一切）

侧栏五类：**树脂**（全部 SLA 立体光固化）、尼龙（MJF/SLS）、金属（SLM）、工程塑料、定制化材料。

### 树脂（SLA）常用对照，2026-09-16

| 材料 | 颜色 | 热变形 | 备注 |
|---|---|---|---|
| 9600 | 哑光白 | 59°C | 默认、最便宜；韧性一般、高温强光易变形发黄 |
| **8001** | **半透明 / 透明** | **53°C** | **唯一半透明**。标注「高透明度、韧性好」 |
| Grey | 灰色 | 59°C | 不透 |
| JLC Black | 黑色 | 65°C | |
| Imagine Black | 黑色 | 46°C | |
| JLC Temp | 淡黄 | 101°C | 耐温最高 |
| CBY | 淡黄 | 80°C | |
| 8228 | 浅绿 | 56.4°C | |
| X树脂 | 随机 | — | 最便宜，材料不能指定 |
| JLC全彩 / 全彩韧性 | 彩色 | 55°C | 贵一个数量级 |

材料精度统一标 **±0.2 mm 或 0.3% 以内**。这会直接吃掉 0.2mm 级的配合余量——**外发前先自己打一版试片对一次**。

### 8001 的两个颜色不是两种材料

- **半透明** = 材料原始表面。缺点原文：「不打磨不喷砂，有**明显层纹、支撑麻点、划痕**」
- **透明** = 半透明基材 + **喷透明漆**。选它之后喷油项被强制锁定，**+¥10.00 表处费取消不掉**

8001 其余缺点：不能完全消除尘点、气泡；复杂结构内部透光不均；不适宜高温及强太阳光环境（53°C 是树脂里最低档之一）。

**没有烟灰色**。要「烟灰磨砂半透明」只能：8001 半透明 → 分散染料染色 → 喷透明哑光漆。平台的「细磨」方向相反（往光滑透亮走）。
注塑 PC 半透 + 模内蚀纹（如 DJI Mic 外壳）那种均匀磨砂，SLA 直出到不了。

## 5. 表面处理与价格结构

| 项 | 规则 |
|---|---|
| 细磨 | `shell` 尺度固定 **+¥5.00**；**包围盒 < 1000 mm³ 不支持打磨** |
| 喷油 | +¥10.00；选 8001「透明」时强制开启且不可关 |
| 镶嵌螺母 / 渗色 | 按需 |
| 小件材料价 | **触底 ¥1.77 起步价** —— 该尺度下换材料不加钱 |
| 加急 | 48h ≈ 72h 的 **3 倍**；120h 只比 72h 便宜几毛，不值得等 |

**第一单不要加细磨**——要看的是材料原始表面长什么样。后处理随时能补，也能自己喷。

## 7. 停在哪

配好件、材料、时效后**停在提交前**。付款、发票、收货地址由用户自己点。
订单参数、报价、DFM 告警、停在哪一步写进项目 `evidence/`；未付款的单写明「未下单、未付款」。

## 薄壁：上传前自己查，别等人工审图退回来

平台写在上传区的硬规则是**壁厚 >1.2mm、薄处不低于 0.8mm**，材料精度**±0.2mm 或 0.3%**——
这两条要一起看：0.8 的名义壁厚打出来可能只有 0.6，所以自己收在 **≥1.0** 才有余量。

**自动报价不查壁厚，人工审图查。** 2026-09-16 MAKO 手表 1.0 下单后收到客服（周泽平）退回，
附红色区域截图并标 `A ⌀0.13` / `B ⌀0.23`，要求"自行修改文件或接受风险"，给的话术是
「多个文件的可单独取消问题工件，再重新下单合并支付即可」。也就是说：**报价通过 ≠ 能打**，
薄壁问题会在付款之后才冒出来，返工一轮就是 2–5 天。

复核标注时注意截图只给直径和大致位置，对应到模型哪个特征要自己反推，**反推结果要写成"大概率
对应"而不是确认**。MAKO 那次 A ⌀0.13 实测对上底盖四角沉孔外围的 0.28mm（工具体素有正偏置，
实测更薄），B ⌀0.23 只能推测是上壳 0.20mm 残膜。

**上传前跑一遍壁厚自检**，判据别选错（射线采样和球开运算都会被圆角/外棱骗出大量假阳性，
要用中轴脊 + 法向探针定值）——方法和可复用脚本见 `$mako-cad-fit` 的「量壁厚」一节。
典型病灶是**孔或槽差一点没打穿留下的膜**：0.1–0.7mm，报价照过，打出来要么塌要么断在壳里。

## 已知坑

- `3d.jlc.com` 在 Browser 面板被拒；走 `www.sanweihou.com`（跳 `www.jlc-3dp.cn`）+ `claude-in-chrome`。
- 材料弹窗打开时滚动位置不固定，有时直接落在「表面处理」段，要往上滚 6 格才看到材料表。
- 颜色下拉展开后选项很小，先 `zoom` 确认再点——**点偏一格会选中「透明」并静默加上 ¥10 喷油**。
- 每改一件材料都要点「确认」，否则不生效。
- 改完务必回列表核对总价和件数，别只信弹窗里的「预估总价」。

## 别外发的判断

只有外露件的质感和受力件的强度需要真材料验证。**纯内部结构件旧件能用就别重打**——尤其结构尚未实物验收时，装完可能要改，多打的件一起废。补打一个小件 ¥1.77、72 小时的事。
