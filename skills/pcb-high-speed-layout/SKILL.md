# 高速 PCB 布局与布线

> **未完成草稿**：尚未逐集学习课程视频；内容仅依据公开课程目录及补充文档整理，不应视为该课程的学习成果。

适用于高速接口、密集 FPGA/BGA 或需要时序预算的板。先用 `pcb-design` 处理整板电气与制造验收；KiCad 自动布线交给 `pcb-autoroute`。课程目录与官方文档的证据范围及工具限制见 [来源和操作边界](references/source-notes.md)。本流程不要求所有板做六层，也不把案例参数当设计规则。

1. **冻结输入和约束。** 核对原理图、网表、板框、接口方向、器件数据手册与目标制造工艺。列电源树、峰值负载及回流路径；对高速网络列端点、拓扑、目标阻抗及容差、参考层、长度/时延与偏斜预算、终端和来源。没有数字就记为待确认，不能拿案例数字充当规格。
2. **布局与叠层一起决定。** 固定连接器和结构件，按功能块预布局，估算最密 BGA 扇出通道；对比层数、信号层参考面、介质厚度、铜厚、过孔工艺与成本。与板厂确认可制造叠层和阻抗计算结果；避免高速线跨参考面分割，换层时检查回流如何跨层。电源热回路、去耦和敏感模拟区按器件手册审查。
3. **先定规则再扇出。** 按实际网络建立网络类、差分对和等长组；它们不是同一概念。用厂商确认的叠层和阻抗值设置各层线宽、间距，核可制造孔径及盘中孔工艺。BGA 扇出、去耦和路由通道反复协调，必要时返回布局，不为消除 DRC 随意缩焊盘或放宽规则。
4. **先关键链路再补全。** 按接口手册和拓扑规划 DDR 数据、选通、地址/命令与时钟，以及 HDMI 等差分对；按真实端点及预算定义组内、对内或组间约束，不默认所有线彼此等长。检查参考面、换层回流、过孔、间距、端接、供电连通性和可布通性，再处理普通信号与电源。先优化最长路径、再按需要补偿；等物理长度不一定等时延。
5. **同版验收与交付。** 重新铺铜，保存原生 DRC 报告及未连通数；复核规则覆盖、阻抗/时序预算、参考面、回流、电源、丝印与装配。交付同一版本的源工程、约束与来源表、关键布局/布线决策、DRC 原报告、未解决项及适用的 Gerber、钻孔、BOM、坐标与装配检查。DRC 通过不等于信号/电源完整性达标或板厂放行；按项目需要安排仿真、板厂确认和实测。

肌电等混合信号板只迁移分区、叠层与回流等适用方法；以模拟前端、人体接口安全及实际接口约束为准，不机械套 DDR、BGA 或六层。
