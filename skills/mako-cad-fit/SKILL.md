# 实物反馈驱动的 CAD 小改

这是配合现有 CAD 工具的经验技能，不替代生成器或赋予操作设备的权限。

## 先守住已确认的结构

- 修改前写清当前基线、用户接受的尺寸、允许变化的部位。圆润一点、底面不平、转动卡顿通常是局部修改，不能直接改分件、把结构搬到另一件或要求整套重印。
- MAKO 手表特定约束：表耳必须留在上壳，不能与底座一体。V37底座一体表耳方案已被否决；2026-09-16撤销时恢复V36作基线。版本号是历史记录，开工仍须核对当前文件及最新用户决定，不永远锁死V36。
- 两耳松紧已被实物接受时保留内间距和销孔定位；优先只修外轮廓、毛刺、圆角或局部运动让位。不得用无依据地加大销距解决卡顿，否则会改变佩戴松紧。
- 若局部方案确实不可行，先用剖面/尺寸说明限制，再给分件或布局替代方案；在用户选定前不把结构大改变成默认交付。技术检查通过不代表设计方向被接受。

## 区分“不平”和“容易坏”的对象

- 核对截图显示的是整机、单件、装配姿态还是切片摆放；测实际大底面与表耳最低面，不能只凭透视图认同高低判断。
- 装好齐平不代表单件可平放打印。分别记录装配基准Z、单件最低Z、STL打印变换、首层接触和悬空区。
- “打坏”可能指打印塌陷、拆支撑破损或拧螺丝断柱；先用照片/上下文判断，影响修法时问一个明确问题。未确认前先做不依赖答案的测量，不以猜测扩成结构重设计。
- 壁高和壁厚一起考虑；抬高单线薄壁不能证明强度。螺丝柱要核螺丝制式、孔径、有效啮合和底孔深度，根部圆角及承托；未知值可标试印假设，不能声称抗断验收。

## 验实际运动，不验理想替身

- 记录零件来源：实测、厂家图、型号名义尺寸、照片估计或假设。型号名不是包络图；电池要包括保护板、胶带与引线，按钮要有固定座、行程和限位，USB要考虑插头外壳及焊点。
- 表带头用接近实物的平板/外形包络，包含快拆杆等会碰撞的部分。内端距轴a、厚t的角点半径可用sqrt(a*a+(t/2)*(t/2))作局部预筛；它不是全运动无干涉的充分条件。
- 从已知可装姿态沿实际转动方向逐步扫，记录范围、步长和余量。碰撞通常非单调，不用二分查“最大角度”；远端姿态无碰撞不代表途中可达。
- 同时检查最终位置和装入/合壳路径、两端镜像、邻近电池/PCB/螺丝与改动后的接缝。假设包络通过只叫模拟通过。
- 回归检查要喂一个已知失败案例：如旧版确实会卡的表带位姿必须检出碰撞；检查自身全绿不证明判据有效。

## 量壁厚：判据选错就等于没查

厂家 DFM 说"红色区域壁厚太薄"时，先确认自己用的判据能不能查出来。两种直觉做法都会骗人：

- **射线采样**：从表面往里射线，在圆角和外棱处会斜着射进棱边、从旁边那个面出来，报出很短的
  "厚度"，其实那里材料很厚。假阳性多到没法定位，只能写出"某某区域仍需复核"这种没用的结论。
- **球开运算**：反方向错——开运算把外棱磨圆，于是零件每条外棱都留残渣、彼此连通成一张网。
  MAKO 手表上壳实测这样造出 16 mm³ 全假的"薄壁"，聚成一坨横跨整个零件。

**用中轴脊**：体素化后 d = 内部体素到外表面的距离（`scipy.ndimage.distance_transform_edt`），
真薄壁的中面是 d 的局部极大值脊（`maximum_filter(size=3)` 取脊），厚度 = 2d；外凸尖角里 d
单调递增、不存在局部极大值，所以尖角冒充不了薄壁。0.1mm 体素、单个零件 2–4 分钟。
脚本：`scripts/wall_thickness.py new.stl old.stl`（第二个文件就是阴性对照）。

三条边界，写进结论里别含糊：

- **扫描定位，探针定值。** 体素有正偏置，实测普遍比扫描值薄 0.15–0.2mm。报数给厂家前要沿
  薄壁法向 0.005mm 步进实测两个面，别拿扫描值当实测值。
- **中轴脊查不出羽状边。** 两面以小角度相交收成刀刃时 d 单调递增、没有脊，判据按定义报不出
  来。羽状边同样是 DFM 会红的东西，要另外查（沿法向量 X/Y/Z 三向 run，看哪里收口）。
- **每次都跑阴性对照**：拿修改前的版本用同一把尺子量一遍。才说得清哪几处修好了、哪几处原来
  就有、哪几处是这次新引入的回归。MAKO 手表上就是靠这个抓到自己多切 1mm 把外壁掏空。

## 薄壁补不上时，先问是不是被别的检查占死了

薄壁往往不是"忘了加料"，而是两侧都被功能占满。补料前后都跑装配检查，让检查来裁：MAKO 手表
开关腔壁端部 0.695mm，+x 是端子走线包络、−x 是 PCB 装入扫掠，两个方向的补料都建出来、都被
对应检查挡回——这说明它是设计约束，要动走线或板位才能解，不该硬塞进"局部修订"里。

检查挡回来是信息不是障碍：按它给的面（配件顶面、腔底、包络边界）改尺寸，不要放宽检查。

## build123d / OCC 布尔：相切会静默算错

- **build123d / OCC 的布尔在相切、贴得很近时会算错，而且不报错。** 情形：两个实体面重合或相切、间隙小于约 0.15 mm（0.105 也出过错），或一条扫掠管拐得急。规则：①建模时别让槽底、贴合面正好相切，留 ≥0.05 mm 的料或间隙；②求交结果要配一个探针：远离管子的小盒必须不相交、管上的小盒必须相交；③布尔抛异常时改用网格取点估算重叠，不能当 0；④靠构造保证的间隙（比如"中心 = 内表面 + 0.10 + 半径"），沿路径逐点算出来检查，不信 OCC 的求交；⑤两段扫掠要熔成一个实体，搭接要扫一遍取稳的值，熔完检查实体数是 1。证据：原力手环 c05-strap 2026-10-21/22：让位槽底与软板顶面相切，平放形态 Null TopoDS_Shape；槽底只留 0.01，戴上形态护套变坏实体；离带 0.105 的线束管，求交返回整根管 22.2 mm³；扁线段与圆束段搭接 0.3 时熔成两块，导出镜像也跟着错，扫 0.5/0.8/1.0/1.5 后取 0.8。置信：中（同一会话里四种表现，都已复现）。

- **STEP 读回别按索引对名字。** 情形：独立读回 STEP，要按清单量某个零件。规则：一件可能拆成多个实体，实体数和清单数不同时，按形状和包围盒筛，再核一次分组；距离得 0 先查分组，别先判碰撞。证据：C08B 3D 第三轮实体数多于清单条数，按索引量错件；两尾距离 0 是分组错，修后 0.03 mm，见 `v12/c08b-d16-3d-r7-20261106/step_check.py`。置信：低，只见过一次。

## 交付与撤销

- 改源文件，另存版本；用几何比较确认未改配件及定位基准，不用“体积相同”代替形状相同。
- 重读导出的STEP，检查有效实体/间隙/路径；查看正交侧视和底视；由同一几何导出闭合STL并列明打印姿态、支撑限制、要重印的零件。不得把需合壳参考的整机当成可一体打印零件。
- 生成工具报错时，分别记录写出、后处理、重读、检查和快照结果；文件存在或独立检查通过都不能抹掉工具报错。
- 结论区分未实现、已实现未验收、已实测通过、阻塞。CAD干涉通过不等于打印强度、手感、电气或装配验收。
- 用户撤销：恢复未覆盖的旧基线，把拒绝方案从当前打印入口撤下并标明勿打印，保留可追溯存档。把被否决的结构方向记录到项目约定；不要悄悄换名重新交付。
