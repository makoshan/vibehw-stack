# KiCad 板布完后的收尾：丝印 → 泪滴 → 证明铜没坏 → 装配图 → 嘉立创工程 → 评估别人的工程（2026-11-03，C08B 采集板 D5 / R3.1 实测）

脚本在 `scripts/handoff/` 和 `scripts/epro_review/`。都是从原力手环仓原样搬来的，不是通用库：C08B 的取值写死在里面，每个脚本开头的「换板要改」列了要动的地方。KiCad 脚本用 KiCad 自带的 python 跑（`/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3`，下文记作 `KPY`）。

[布完的板 D4] → 走线整洁度 `route_lint.py` / `route_tidy.py` / `route_tiles.py`（6c）→ 丝印 `silk.py` → 泪滴 `teardrops.py` → 证明铜没坏 `copper_hash.py --teardrops` → 两口径 DRC → 装配图 `asm_pdf.py` → 嘉立创（拍平泪滴 → 转 9 → 合工程 → `apply_rules.js` → 读回 → epro2 / .epro）→ 独立复核

## 1 丝印

`KPY silk.py D4.kicad_pcb D5.kicad_pcb [位号字高] [板名]`。规则和证据见 [密板丝印](silkscreen-dense-board.md)。

- 判据：
  - DRC 丝印类警告 0。
  - 阳性对照：把一个位号字高改 0.5、挪到焊盘上，必须报 text_height、text_thickness、silk_over_copper。
  - 笔画按工厂门槛二分：在副本的 `.kicad_pro` 里把 `min_text_thickness` 设成 0.15 和 0.10 各跑一次。
- 字号先出效果图给用户定，不只按安全值推：
  - 1.25 位号笔画 ≥ 0.15，但在 43 mm 的板上像标题，Mako 嫌太大。
  - 最后定位号 0.89（字形 0.8，笔画 ≥ 0.10，高精度工艺），板名 1.4。

## 2 泪滴

`KPY teardrops.py D5.kicad_pcb`（就地改）。KiCad 10 python 不开放泪滴工具：脚本先给所有焊盘、过孔开 `SetTeardropsEnabled(True)`，再跑 `kicad-cli pcb drc --refill-zones --save-board`，重铺时按板级默认参数生成。C08B 一次出 708 个；正反面 GND 铺铜各少约 5 mm²，是给泪滴让的间距。

## 3 证明铜没坏

`KPY copper_hash.py [--teardrops] 旧板 新板` 比三组，退出码 0 = 全同：
- 走线/过孔：含孔径。
- 焊盘：含尺寸、形状、层、孔。
- 铺铜：不加开关比填充面积；加 `--teardrops` 只比外形，泪滴单独计数。

反例必须报不同：改一个过孔孔径 0.35、加宽一个焊盘 0.1。

盲区：铺铜不比形状；焊盘不比圆角和多边形。要更细就另写逐点比对（C08B 复核时写过，结果一致）。

DRC 两口径都要跑：`kicad-cli pcb drc --severity-all` 直跑一次，加 `--refill-zones` 再跑一次。

## 4 装配图

`python3 asm_pdf.py 板 输出.pdf 临时目录`：
- 内容：正面 F.Fab + F.Courtyard + 板框，背面镜像。
- 不叠丝印：位号会重影。
- 不加 `--sketch-pads-on-fab-layers`：小件位号会被脚号盖住。

## 5 嘉立创工程

完整步骤（转 9 写法、补叠层、`importOption`、按 LCSC 挂 3D、规则写入、epro2 / .epro 导出、开着窗口的目录别重建）见 [嘉立创原生重画与交付](easyeda-native-redraw.md) §6。串起来的顺序：

1. `KPY flatten_teardrops.py D5 副本`：把泪滴外形换成 KiCad 已裁好的填充。
   - 不换的后果：嘉立创把没裁的外形当实心铜，C08B 报 18 条间距错误，其中 1 处 0 mil 碰到异网过孔。
   - 只能当导出前最后一步：拍平的副本再重铺，泪滴会长回原外形。
2. 转 KiCad 9 写法、补叠层 → 建原理图工程 → `combine.py` 导入。这几个脚本在原力手环仓 `v12/c08-eprj3-20261102/`。
3. `apply_rules.js`（数值先按板改）：
   - 写安全间距、过孔下限。过孔表单里 Inner = 孔、Outer = 外径，两个都写。
   - 槽区、文字、线三行跳过。
   - 设字体，重铺，跑 DRC，存盘。
   - 阳性对照：在工程副本里把一个过孔外径改 0.35、另一个孔改 0.25，必须多报 2 条 Via Size。
4. 读回检查：
   - 页数、元件、3D、飞线、网数。
   - 原生网表逐脚对板。
   - 几何重建网表；阳性对照对调两脚，必须报出不符。
5. `getProjectFile(…,'epro2' | 'epro')` 导出。
   - 两种都给：别人的嘉立创版本可能只认 .epro。
   - 泪滴进嘉立创后是静态填充（.epro 里是 FILL 记录）。
   - 导出的 .epro 用第 6 步的脚本再读一遍，确认全连通。

## 6 评估别人的嘉立创工程

`.epro` 打不开时（命令行无头、窗口模式都读不到，`importProjectByProjectFile` 也返回 null），解包后用 `scripts/epro_review/`：

```sh
unzip x.epro -d /tmp/x
EPRO_X=/tmp/x python3 ana.py         # 输出：连通（并查集，含铺铜）、悬空、同层异网间距、分层长度 → ana.json
EPRO_X=/tmp/x python3 plot.py out.png
```

字段约定（每条都用反证定下来的，见 easyeda §6 那一行）：
- VIA 记录：字段 7 = 孔、8 = 外径。
- 背面元件焊盘：y 镜像。
- 焊盘第 14 字段：不是转角。
- POURED 坐标：单位 10 mil。

已知误报：焊盘一律按矩形算，长圆形（QFP 引脚）、多边形（散热焊盘）附近的间距会报小。下结论前拿 KiCad 原板对照。

比较质量时三方同一口径：对方板、我方上一版、我方现行版。量这几项：
- 电极座脚网的最长、中位长度，有几根打孔、几根走内层。
- In1 上有没有信号线。
- 最小间距。
- 泪滴。

C08B 的例子：对方 56 mm、全部打孔；我方 D5 是 9 mm、0 孔。见原力手环仓 `docs/c08b-afe-r2-ext-review-20261103/`。

## 6b 交给别人前：只靠铺铜连网的焊盘要补明线（2026-11-03 C08B R3.1 → R3.2）

外包用嘉立创 V3 打开 R3.1 报 684 条。本机 V4 复现出两层问题：
- **规则导不全**：源工程把铺铜间距写成 0.1，epro2 打开后这一行回到默认 0.254，填充却是按 0.1 铺的，不重铺就报 2291 条。
- **靠铺铜连地**：按 0.254 重铺后，15 个地焊盘、2 个地孔断开。这 17 个在 KiCad 里没有一条走线，只靠铺铜从窄缝里连过去。

做法（原力手环仓）：
- KiCad 铺铜间距和嘉立创规则都定成嘉立创默认 0.254。源和规则一致，谁重铺都一样。
- `v12/c08b-afe-relayout-20261102/add_stubs.py` 补线：输入是嘉立创重铺后 DRC 报的「断开连接」对象。
  - 焊盘：先直连 3 mm 内已有的同网过孔；不行就在旁边新打孔；再不行沿引脚长轴先出线再打孔；最后直连同网铜。
  - 过孔：直线连同网铜。
  - 自带间距检查：铜 0.1、线到异网孔 0.2、孔到孔 0.2、板边 0.3、禁布区；孔不进任何焊盘，同网也不行，否则成盘中孔。第一版漏了「线到异网孔」和「孔进同网焊盘」，是 KiCad DRC 和制造包的盘中孔统计查出来的。
  - 引脚被邻线夹死的，补线前要先挪邻线或过孔腾位（C08B 用 `d6_prep.py` 做了三处），改完重跑两口径 DRC。

**验收量导出的文件，不量源工程**：
- R3.1 的源工程 DRC 干净，导出的文件打开就报 2291 条。
- 离线可以量：`v12/c08-eprj3-20261102/pour_clear.py` 量 .epro 里的铺铜填充到异网钻孔和走线的最小距离，圆弧按真实弧线细分（`load.poly_pts` 只取端点，会量出负数）；拿旧版当阳性对照，R3.1 能量出 7.7 mil。
- 在嘉立创里重新导入再跑 DRC：`importProjectByProjectFile` 要在设置里开「扩展和独立脚本的外部交互权限」，没开就只能走界面导入。

**版本兼容**：嘉立创 V4 没有「存成 V3」的导出。对方是 V3 时，让他用网页版 pro.lceda.cn 打开 epro2，或者给 `export_altium.py` 出的 Altium 包（`getAltiumDesignerFile`）。

## 6c 走线整洁度：DRC 不管、工程师一眼看得出的毛病（2026-11-03 C08B D7 → D8）

外包工程师看 D7 指出四类毛病：尖角 / 90° 拐角、怪角度走线、从焊盘侧面斜着出线、同一根线中途变宽。KiCad DRC 0 错 0 未连，一条都不报。

Mako 定的规矩：
- 线段只走 0/45/90°，拐角只许 135°：不许 90°，不许锐角。
- 长方形焊盘先沿长轴从端头出，伸出焊盘再拐。
- 线宽只在焊盘或过孔上变，一串线一个宽度；电源线尽量别为统一线宽收窄。
- 不留悬空线头。

三个脚本在 `scripts/handoff/`，原样来自原力手环仓 `v12/c08b-afe-relayout-20261102/`：

| 脚本 | 做什么 |
|---|---|
| `route_lint.py 板 [out.json]` | 报怪角度、尖角、锐角 T 接、线宽突变、悬空线头、斜出焊盘，有问题退出码 1。另外报告 90° T 接、多线宽、转了非 45° 整数倍的封装 |
| `route_tidy.py 源 出 [报告]` | 顺序固定，见下文。每处改动先查间距（铜 0.1、线到异网孔 0.2），过不了就跳过并记原因 |
| `route_tiles.py 板 lint.json 目录 [块边长]` | 把 lint 点画成 8 mm 分块 SVG 加全板总览，用 `qlmanage -t -s 1200` 转 PNG 看 |

`route_tidy.py` 的处理顺序：
1. 拆 T 接（线头接在另一段线中间的，在接点处断开）。
2. 两段线头没对上的，各自伸缩到两条线的交点。
3. 统一线宽：从串里最宽的往下试，放得下就用。
4. 斜出焊盘改成「沿长轴 → 45°」。
5. Z 形小台阶改成 45°。
6. 90° 拐角切一个 45° 角。

**踩过的坑**：
- **端点返回的是引用**：KiCad Python 的 `GetStart()/GetEnd()` 返回线段内部坐标的引用，不是副本。改线前要先 `VECTOR2I(P.x, P.y)` 复制。不复制的话，改了 t 的端点，手里存的 Q 跟着变，新线会折回自己，DRC 冒出 tracks_crossing 和未连。
- **T 接要先拆**：线头接在另一段线中间的，要先拆成端点。不拆的话整理和检查都看不到这个接点。复核在 D8 第一版查出 4 处线宽突变和 1 处 45° 交叉，都在 T 接点上。
- **悬空线头 DRC 不报**：线头差一点没对上、只靠铜皮重叠连着，KiCad DRC 不报 dangling。V4 参考走线里有 3 处。lint 单独查这一项，tidy 把它们补到交点。
- **出线修正要看整条折线**：整条折线上只要有点落进别的长方形焊盘，那里也得正着进。否则只是把斜出挪到了对面焊盘，复核查出 4 处。
- **补线 45° 段最短试到 0.1 mm**：C08B 的 U2.60 只有「沿轴出 → 斜走 0.1」这一个位置放得下 0.3 孔的过孔。
- **剩下的斜出多是参考设计扇出**：参考设计里 QFP 管脚端头直接 45° 扇出的，整理脚本挨个试「沿轴伸出 0.1 再 45°」，间距不够就跳过。要清零只能重布扇出，先问人。
- **局部修补到不了 0 时整段重画**（C08B 主控 thru3，11-04）：`route_tidy` 只把怪角度 188 压到 179。`octi_retrace.py 板.json 出.json 跳过网` 把焊盘/过孔/分叉之间的每串线沿原路重写成 0/45/90°，动态规划只许转 45°；卡住的小段保留原样；之后 `apply_retrace.py 源板 出.json 输出板`（`extract.py` 导 JSON）。实测 2407 → 1642 段，怪角度 179 → 0、尖角 57 → 0、线宽突变 71 → 0、DRC 0/0，约 2 分钟。线宽取串内最宽，放不下才按原宽分段，所以电源只宽不窄；电源和地不用整网跳过，用 `check_power_width.py` 式按位置比。线段不是严格走原线：放大倒角和去错位会偏离，C08B 最大 1.6 mm，文档别写「走廊不变」。
- **route_lint 全 0 也可能有 90°**（同上，独立复核查出）：两个同向 45° 夹一段短于约 0.414×线宽的线，中心线每处 135°，铜皮内角纯 90°，都是整段重画新造的。已加 `hidden_90` 检查（阳性对照 C08B r8 报 6 处）和 `widen()`；在分叉点上的 hidden_90 查不到，要目检。7 µm 这类短段还能把 T 接的锐角拆开骗过 `tee_acute`，T 接点要离拐点 ≥ 0.1 mm。
- **重画后常见新问题**：拐点落在焊盘里（看上去还是斜出，要移到焊盘外）；线头离孔不足半线宽算「相碰」时，只放宽真线头，路过的线不算，否则删出未连；放宽时先认真正落在里面的，否则焊盘端被认成旁边的孔，线段塌成一点；删重复线后查有没有焊盘只靠擦边。
- **自动整理不分轻重，指标变好不等于对**（C08B 主控 thru3，独立验收查出）：`route_tidy` 的统一线宽把 83 段电源线从 0.15 收窄到 0.127，「线宽突变 71 → 3」主要是这么换来的；同时动了 ANT_FEED、RF_ANT、晶振，MCU_DEC5 绕长 20.8%。整理后跑 `restore_sensitive.py`：电源、地、射频、晶振、去耦和 DCDC 全部整网退回整理前，整理只留在信号线上。第一版只按同端点逐段退电源线，第二轮验收又查出端点微动过的 13 段约 7 mm 仍被收窄，还有 0.096 mm 偏心的过孔连接，地线也被拉长（射频匹配 C60.2、DCDC C46.1–L5.2 +26%）；改成整网退后 DRC 一次过，这些网与整理前逐段差异 0，代价是线宽突变留在 71。验收要逐网比线宽和长度，别只看 lint 总数；比线宽按位置比，不按端点比。
- **`route_tidy` 原来不查板边**：线被推到板边内（3 条 copper_edge_clearance）。已加，`EDGE=0.21` 指定，默认 0.3。
- **`fix_loop` 只看 lint、不看 DRC**：跑完必须再跑 DRC。断线常因老线中段压着一颗过孔、线被重走后孔没了连接（`fix_exits` 看不到这种接点）。把涉事焊盘放进 `DENY=C30.1,R703.1` 重跑。
- **数字全 0 不等于好看**：交付前按 lint 点出分块图，新旧版对着看。

**斜出焊盘局部重布（2026-11-04 C08B D8 → D9，103 → 75）**：

| 脚本 | 做什么 |
|---|---|
| `fix_exits.py 板.json lint.json 出.json`（uv：numpy + shapely） | 只拆「焊盘 → 第一个锚点（过孔 / 焊盘 / 分叉点）」那一小段，同层重走：沿长轴伸出焊盘再拐，每拐只转 45°，终点是长方形焊盘也沿轴进。网格（0.025、8 方向、带朝向 A*）定走向，再让最后两段不平行的线吸收误差，严格 0/45/90。走不通先整段收窄（只限终点是焊盘/过孔的），再连带拆最多 4 段邻线、按几种顺序重走，全通才收，否则退回 |
| `fix_loop.py 源板 出板 [轮数]`（KiCad Python） | 多轮跑 fix_exits；除斜出外任何一项变多，就把造成它的改动拉进不改名单，从本轮起点重跑 |
| `fp_lib.py 源板 出板` | 板上封装原样导成工程库（摆正、背面翻正、放原点）+ 工程 `fp-lib-table`；没外框的件按焊盘外缘 + 0.25 补一圈。消 `lib_footprint_issues`、`missing_courtyard` |

另需 `extract.py`、`apply2.py`（同目录）。坑：
- **V4 这类参考扇出是按最小间距 0.1 排的**，栅格余量 0.004 就把老线自己的通道算成堵；余量用 0.001，以精确检查为准。
- **同网的别的线也要当障碍**，只在起点焊盘和终点附近放开；否则新线叠在老线上走，夹角 0°（lint 的 tee_acute 能抓到）。
- **同一个焊盘点上挂好几段线**，只挑斜着出去的那段；挑错了会去重走本来就正的线，斜出数不降。
- **终点焊盘里只留沿它长轴的一条通道**，否则拐角落在焊盘里，新造斜出。
- **中间板旁边没有 `.kicad_pro` 时**，KiCad 按默认规则加载（孔到铜 0.25），存盘还会把默认值写回工程文件；后面跑 DRC 冒出 123 条假的孔间距错误。中间板一律带上源板的 `.kicad_pro` / `.kicad_dru`。
- **沿轴往哪头出要两头都试、取短的**：只按起点在焊盘中心哪一侧定方向，终点在反方向时线会绕着焊盘掉头（D9 第三轮复核查出 C85.1、C35.1）。
- **加质量门**：新线长超过「只走 0/45/90 的最短长度」的 1.35 倍加 0.15 mm 或超过 5 段，就保留原线（余量用过 0.35 mm，短线照样鼓包过门：C35.1 1.82 倍、LM27762 1.68 倍）。质量门上线后要自己从板上量一遍每串新线的绕远比，不信日志。终点在焊盘侧边时，沿轴出去必然要折回来，钩子比一段斜线更难看。
- **长边垂直出要分件看**：两脚件（阻容、ESD）沿元件轴向出，常常正好是从焊盘长边出，这是标准出法，lint 的 `pad_exit_side` 只报告；多脚芯片和座子的管脚从长边侧着出才要改。
- **局部重布的上限**：剩下的都是挡路的是过孔、焊盘或别网的固定线，要挪孔、挪去耦电容、按新规矩重排这一片。这是改布局，先问人。
- **一个 0 要用另一种写法再扫一遍**：`route_lint` 原来只看线头命中的第一个焊盘，同网焊盘互相重叠时，近方形邻盘（C74.2）把旁边的长方形焊盘（C60.2）盖掉，报 0 其实有 4 段斜出；另写脚本扫全部出线才查到，无人值守代理的「出线沿轴向」也是错的。现在每个命中焊盘都查，修后 D9 的转角斜出从 56 变 77。

**改布局清斜出（2026-11-04 C08B D9 → D10，斜出 76 → 0，转角斜出 77 → 0，代价：长边侧出 103 → 117）**：

`fix_exits.py` 加了 `CAPS=1`（转角电容转正，外移 0–0.25 mm 让通道）和 `MOVES=1`（改接旁边同网点、挪过孔、挪两脚件）。自动部分到 47 后就走不动了，剩下靠手写步骤（`d10/mkstep.py` + `steps/*.mm.json` + `replay.sh`，mm 写、从恢复点回放）。
- **转正后信号线从重叠的同网焊盘直穿**：两颗电容焊盘同网相碰时，用一段顺长轴的竖直短线穿过重叠区，代替绕过去的 V 形线，往往线更短、T 接也少一个。
- **挡住转正的多半是 GND 焊盘离邻线太近**：平移 0.05–0.1 mm 就够，算清楚再挪，别整片重排。
- **删地孔先看 B 面铺铜**：焊盘带一小块铺铜时删孔会成孤岛（D10 s19 失败），改从焊盘端头走线进别处新地孔才行；回流路径变了要写下来给复核者。
- **删支线先看是不是唯一通路**：去耦电容之间的链常是一段电源的唯一连接，删了 DRC 报未连（s21、s32）；进度表里「未连」要和斜出一起看，别只盯斜出数。
- **斜出清零会换来侧出**：多出来的都是两脚电容从侧面出，质量门挡不住；交付前按分类逐条写原因，让人定接受不接受。
- **无人值守交付改动步骤，不交板文件**：Spark 的 KiCad 10.0.7 存盘格式和 Mac 10.0.6 不同，提交步骤 JSON + 回放脚本，Mac 回放后计数必须一致。

- **0 警告也要阳性对照**：拿掉 `fp-lib-table` 应报找不到库；把库里一个焊盘加宽，应报「与库中副本不匹配」（改到文字字号不报，要改焊盘）。

## 6d 嘉立创原理图 DRC 警告（2026-11-03 C08B R3.3 → R3.4）

| 警告 | 原因 | 改法（`v12/c08-eprj3-20261102/build_sch_eprj3.js`） |
|---|---|---|
| NETOBJECTONGRID | 管脚、导线端点、电源符号、端口不在 5 的倍数上 | 管脚按绝对位置吸到 5，再减去吸过的器件原点；导线端点同样吸，所以连接不变。脚本还会查吸完有没有两脚重合 |
| ATTRMATCHCODE | 填了「Supplier Part」，嘉立创拿立创库里那颗器件的封装去比，和板子转来的封装不同就报 | C 号放进自定义属性「LCSC」，不填 Supplier Part |
| CHECKFLOATPIN | 没连线的脚没标「不连接」 | 给 PCB 上没网的脚（空网或 `unconnected-…`）的 PIN 加属性 `NO_CONNECT = yes` |

- **原理图 DRC 的「0」要能和「没跑」分开**：`sch_drc.js` 保留 check 的原始返回，构建里每次拿已知有警告的旧工程副本（R3.3）跑同一脚本，应照旧报 547 / 5 / 1。
- **PCB 有、原理图无的件**（安装孔这类没网的机械件）：生成脚本自动补成无脚符号；带网的件漏画就直接报错，不许悄悄补。导出两份网表（`sch_Netlist` / `pcb_Net.getNetlist('Protel2')`）逐件逐网比，能定位「网表不一致」到底差在哪：C08B 是 PCB 多 4 个安装孔。补完后 167 件、110 个网都一致，PCB DRC 那条 Netlist Error 仍在（同 6e）。

## 6e 原理图和 PCB 分别生成后配板（2026-11-03 C08B 主控 thru3）

| 情形 | 做法 | 证据 |
|---|---|---|
| 原理图 DRC 每件报致命「缺少封装」 | 原理图器件挂 PCB 上同位号元件那一份封装。每次导入封装 uuid 都变，只能导入后再挂：读 PCB 元件下的 `ATTR Footprint`（没 LCSC 号的件 attrs 里没有 `DeviceName`，只走那条会漏），按位号改原理图 DEVICE 和实例属性，删掉嵌入的旧封装。按位号改，不按 uuid 全局替换：上次导入两件共用的封装可能这次拆成两份。原力手环 `v12/c08-eprj3-20261102/pcb_footprints.py`、`relink_sch_fp.py` | 致命 113 → 0；工程里封装 226 份 → 113 份 |
| 嘉立创命令行 `open` 卡死超时 | 下一步打开的是 init 空工程，读到「飞线 0、DRC 空」= 假通过。以合工程那步的退出码和读回元件数为准 | thru3 第一次导入 |
| PCB DRC 1 条「Netlist Error（Import Changes）」 | 分别生成后配板就会有。封装同一份、Unique ID 同步、器件引用两处对齐、悬空网改无网都试过仍在（thru3、采集板 R3.3/R3.4），当已知局限；交付说明写「别点 Import Changes / 更新 PCB」，连接另用原生网表逐脚核 | 两份网表逐件比只剩属性差（3D、LCSC、层） |
| 原理图标签由期望网表生成 | 阳性对照改坏图（画错一个标签、漏打一个叉），不改期望网表：改真源图跟着变，检查永远绿 | 改真源 0 报错；改图报「标签与网不符」「空网脚未打叉」 |

## 7 验收

- 独立子代理只读复核，实现者不自验。C08B 这一套复核共 5 轮，查出的问题：
  - 笔画门槛用错。
  - 铜比对有盲区。
  - 过孔字段读反。
  - 4 处「铜与 D4 相同」的过时说法。
- 改了板就重跑整条流程：D5 → 嘉立创 → 参考包 → SHA256SUMS；文档里的板哈希同步改。
