# 密板丝印：印哪些、印在哪、用什么字（2026-11-03，C08B 采集板 D5 实测）

适用：板子很密（本板 43×36 mm、167 件、0201/0402 为主），丝印乱、溢出板框、压焊盘，或用户要「换一个标准的方式」「学这个丝印效果」。脚本在原力手环仓 `v12/c08b-afe-relayout-20261102/silk.py`（KiCad 10 python，只改丝印层和装配层）。

[查清字在哪层] → 定印哪些（白名单）→ 选字体（逐字符验笔画）→ 找位（离本件最近）→ 1 脚点、四角框、板名 → 装配层清理 + 装配图 PDF → DRC 丝印检查 + 阳性对照 → 铜逐项比对不变

## 1 先查清「乱的字」在哪层

- **情形**：别的 EDA（嘉立创）里看到字溢出板框、压焊盘。
- **规则**：先数源板每类字段的层、可见性、字高。导出到别的 EDA 时，装配层（Fab）上可见的长字（型号、阻值）会照样显示；丝印层上的位号可能全是隐藏的。两件事分开治。
- **证据**：D4 丝印层可见位号 0 个；溢出的 `FH34SRJ-20S-0.5SH(50) (LCSC C2802370)`、R80x 阻值、TP 名都在 F.Fab，嘉立创导入后落在装配层（第 9/10 层），不会印出来。
- **置信**：低（单板）。

## 2 印哪些：白名单，不硬塞

- **规则**：密板只给人会去找的件印位号——芯片、座子、晶振、电荷泵/电源芯片、测试点；阻容、ESD 不印，靠装配图 PDF 对位号（贴片按坐标文件走，不靠丝印）。逐个硬塞的结果是零散几个，读者对不上件；成组范围标签在编号不连续时会误导（5 个件标成「C90-C121」）。
- **证据**：逐件硬塞 0.8 mm 字高印上 45/167，ESD 阵列只印上 D927、D911、D910；改白名单后 19 个要印的印上 8 个，其余 11 个（U3–U10 等）四周被别的件包住。
- **置信**：低。

## 3 印在哪：离本件比离任何别的件都近

- **规则**：候选位置在件外框（courtyard）四周、由近到远；合法条件：离焊盘和过孔 ≥ 0.15（嘉立创要求丝印离焊盘 ≥ 0.15）、不压别的件外框和禁布区、离板边 ≥ 0.3、不压已放的丝印，**并且文字离本件外框要比离任何别的件近 0.1 以上**，否则隐藏。大件（≥ 3 mm）外面放不下可以印在本体中间（不压焊盘）。
- **证据**：不加最后一条时 V4_U10 离本件 1.0、离别的件 0.04，V4_U6 1.0 对 0.53，读的人会认错；加了以后这 3 个改为隐藏。
- **置信**：低。

## 4 字体：照参考图选，但先逐字符验笔画

- **规则**：参考图那种方正粗体是 TrueType，不是 KiCad 单线笔画字。选字要过三关：
  1. 每个用到的字符单独做一段文字跑 `kicad-cli pcb drc`，`text_thickness` 报「TrueType 字体字符的笔画线宽不足」的字符就是交接处太细，印出来会断。**门槛要设成工厂的数**：工程里 `min_text_thickness` 默认 0.08，过了也证明不了 0.15；把它改成 0.15（安全值）或 0.10（高精度）再跑，二分出最细笔画。KiCad 的 `SetBold` 对没有粗体字面的 TrueType 不起作用。
  2. 量真实字形高：导出 SVG 解析路径坐标。KiCad 的字高是名义值，Kanit 设 1.0 实际字形 0.90（嘉立创安全值字高 1.0、线宽 0.15；高精度下限 0.8 / 0.1）。字高和最细笔画成正比，两个都要满足：Kanit Medium 1.15 时字形 1.04 够、最细笔画 0.14–0.15 不够，要 1.25；句点「.」到 1.3 都不够，板名别带句点。
  3. 授权：要嵌进板文件或随参考包发出去，只用 OFL 等可分发字体；macOS 自带字体（Krungthep 等）嵌进文件等于分发苹果字体。
- **证据**：Krungthep 最像参考图，但 6/8/9/B/Q/R 细于 0.08 mm；DIN Alternate 只有「_」细，而位号都带下划线；Kanit Medium（OFL）在 0.08 门槛下全部字符通过（这个门槛太低，见第 1 条）；竖笔约 0.21 × 字高，但最细处（弧线交接）只有约 0.12 × 字高。
- **KiCad 10 python 的坑**：pcbnew 不暴露字体类，`SetFont` 拿不到新字体。先在文件层给 `(property "Reference" …)` 的 `(font` 插 `(face "Kanit Medium")`，载入后新文字用 `t.SetFont(某个位号.GetFont())` 拷贝；只给要印的字段设字体，隐藏字段 `SetFont(None)` 清回默认，否则每段都存字形缓存（本板 505 段、文件 1.4 → 6.5 MB）。嵌字体：文件层把板级 `(embedded_fonts no)` 改 yes，存盘前 `b.EmbedFonts()`（Kanit 160 KB）。
- **置信**：低（字体结论限本机这几种）。

## 5 标记、装配层、验收

- 多脚件 1 脚圆点先于位号放（否则位号占了位，ADS 这种大芯片反而没点）；芯片在焊盘外沿外 0.25 画四角折线，不到 3 个角就不画（零星一两段像线头）。这批导入封装的装配层没有本体外形线，按焊盘外沿算。四角折线每段要按线宽外扩后再判，并且也要避开已放的丝印（只判焊盘时会压到 1 脚点）；KiCad 的 silk_overlap 不查同一封装内部的图形互压，DRC 0 也不等于没压。
- **长说明（座子脚序）别印**：密板上整句脚序（36 个字符、21 mm 长）在座子 3 mm 内放不下；拆短段要「离本座子比离别的件近」也放不下；退成带位号的整句贴板边，用户看图嫌太大（C08B D5，Mako 11-03「明显太大，不合适」）。脚序写进装配图和交付说明，板上只留 1 脚标记。
- **字号先给用户看图**：笔画安全值（嘉立创 0.15）要字高 1.25，印出来在 43 mm 板上像标题；用户选 0.8 字形（高精度下限，笔画 0.10）。字号是外观决定，出效果图让用户定，不只按工厂安全值推。
- 装配层：每件一个居中 `${REFERENCE}`，字号按外框缩，强制 `SetVisible(True)`（原本隐藏的不会自己显出来）；Value、LCSC、MPN 等全隐藏，原本放在丝印层的隐藏字段挪到装配层。装配图 `kicad-cli pcb export pdf -l F.Fab,F.Courtyard,Edge.Cuts --mode-single --scale 0 --black-and-white`（背面换 B 层加 `--mirror`）：不叠丝印层（位号重影），也不加 `--sketch-pads-on-fab-layers`（每个焊盘画轮廓和脚号，小件位号全被压住）。导入封装自带的极性条（ESD 阴极条）会压住位号首字，放大可读。
- 验收：DRC 直跑和 `--refill-zones` 都 0/0、丝印类警告 0；先确认工程里 `silk_over_copper`、`text_height` 等没被设成 ignore，再做阳性对照（位号挪到焊盘上、字高 0.5 → 报 5 条压铜 + 1 条字高）。只改丝印也要逐项比对铜：走线/过孔、焊盘网和位置、铺铜区与原板 hash 一致（原力手环仓 `v12/c08b-afe-relayout-20261102/copper_hash.py`，退出码判；反例改一根线宽 0.01 必须报不同）。
- 效果图用 `kicad-cli pcb render --side top|bottom --quality basic`（单层 SVG 导出全是黑色，看不清）。
