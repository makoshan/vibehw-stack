# 清晰原理图与保电路重画

适用：新图、已有图整理、多来源合图。沿用用户指定的EDA、格式、位号和库；以下方法不授权改PCB或电路。只读PCB逐脚核对在用户要求时照常执行。

## A 先确定本轮改变什么

[新设计] → 从需求、手册和参考电路建立连接。
[只重画] → 冻结原生图/网表/库与对应PCB，变动仅限页面、符号显示、坐标和导线表达。
[电气变更] → 单列批准的位号/脚网/料值差异，变更之外保持一致。

相似型号、旧参考图和PCB反推网表不自动成为真源。多文档工程先按文档ID和版本选定对象，再提取器件；不能把原理图、PCB和历史页的同名位号累计为BOM。若原图与板已经不一致，保存冲突并明确本轮参照，别静默选一侧。

## B 先排局部回路，再决定页数

- 先画一个代表页：主芯片、真实去耦/参考/偏置或反馈回路、接口和长字段都应出现。用户已批准样张时直接沿用，不重复要求确认。
- 信号通常左入右出，供电上、地下；外围贴近对应引脚。先把能一眼沿线追踪的电源回路、输入滤波、反馈、复位等画完整，再划功能区。
- 模块内用真正电气导线；跨功能区/跨页接口用网名。电源和地可重复符号，不能把内部每个脚都变成标签而省掉回路。
- 相关模块可以同页；复杂多模块设计可加带实际接口的层次总览。小设计不强制空白目录页，不固定七页、三模块或一芯片一页。
- 分区框是非电气图形，以内容决定边界，留出图签；不靠装饰框把器件拉散，也不靠缩小字号或整体缩放符号挤进少页。大幅面图需要交付可缩放矢量PDF，说明实际阅读尺度。
- 位号、数值、型号、极性、引脚编号与用途可读；中文说明用统一可读字号（常用100mil），不据此强改符号库本身的字段。

## C 引线与文字：按实际渲染判断

1. 从目标EDA/API取得真实引脚连接点、方向、实例旋转及镜像。沿引脚向外引出短线；不要用相对芯片中心的位置猜方向，更不能所有脚都向同一方向横拉。
2. 区分器件本地坐标、页面坐标和工具的Y轴方向。本地 eprj3 文件按每条记录的 `yAxisDirection` 解析，不带这个字段就按Y向下（4.1.93 实测，见 [原生重画与交付](easyeda-native-redraw.md) §5）；编辑器 API（3.2.186）读写坐标的Y向未单独核，用前先在副本读回一个已知点。KiCad渲染的坐标/旋转须按其规则转换。两套角度定义不能直接互抄。
3. 网标文字及外框放在导线外侧，导线止于连接点。位号/值避开整个线段、符号、相邻字段和图签；只检查文字锚点不足以发现压字。
4. 闭环内部网需要标签时，从已确认同网线路分出短支线到留白；不得把标签放到邻网或盖住原线路。分支、T接和无连接交叉按原生EDA语义处理，不能把图形接近当作连接。
5. 旋转阻容后检查字段是否仍竖写或压在本体。KiCad实例与属性角度可能叠加，修改坐标后必须重新导出并查看，不能仅凭源文件的`angle=0`判断水平。
6. 图形移动会改连接：先统一连接网格，再导原生网表复核。对旧枝杈只清理本轮产生或确认已无用途的部分；重连/删线后重算，不以删警告代替修图。

## D 两条独立验收线

| 电气一致性 | 可读性 |
|---|---|
| 原生导出前后全网表；按位号/脚号比网络，核值、封装、MPN、DNP、电气脚类型和电源旗 | 全页渲染，不仅看截图局部；密集引脚、重复通道、旋转件、长字段、边角与图签放大检查 |
| 对板核全部电气脚；重复焊盘实例与机械孔分别统计；相同网名不证明铜已通 | 实线回路可追踪；无字段压线、文字互盖、内容越界；缩略图整齐不等于放大后正确 |
| 原生ERC，保留启用规则与报告；检查器先用故意改一脚网名的副本证明会失败 | 修改后重新渲染；单页修复可能挤到相邻回路，必须检查受影响区域 |

显示脚名或库关键词改变可单列为非电气变化，不能泛称所有字段逐字不变。原生网表可能不列电源旗或NC；需要从原生对象补核，不能因导出节点数一致就漏掉。

嘉立创原生导入/API排版及打包的版本限定经验见 [原生重画与交付](easyeda-native-redraw.md)。

## E 用脚本生成整套图时

适用：页面由脚本画出（SVG/PDF 预览再转原生），或多页并行生成。

- **情形**：用户发来参考图，说「原理图要规范」。**规则**：先只重排一页当样张，按参考图的分框、标题和图框写法画，用户定了样式再铺开。连接没改的话，样张的网表也要逐脚核对。**证据**：C08A 第 3 页样张定稿后铺开 5 页，没有返工样式。**置信**：低。
- **情形**：要把几页分给子代理并行画。**规则**：先把第一页的画法抽成公共库（符号、导线、标签、自检、输出），每页只写版面；每页的位号清单先定死，子代理不改库，需要新符号就在自己那页里定义并登记脚坐标。最后另跑一次跨页汇总。**证据**：4 个子代理各画一页，合并后五页 255 件、878 脚 0 差异。**置信**：低。
- **情形**：要判断生成的图连得对不对。**规则**：按连线几何重建网表，与真源逐脚比对。每页的检查项：漏画或多画的脚、一个连通组混了两个网、同一个网断成多段且有段没标签、悬空标签、空网脚被接上。跨页再查：每个件只出现一次；同名网出现在多页时，每一段都带名字。**证据**：C08A R1 各页自检 0 错误，独立复核另写脚本得到同样结果。**置信**：低（单工程一轮；两套脚本结果一致）。
- **情形**：说「原理图逐脚对板 0 不符」之前，尤其是从别的板派生、拆页或删页之后。**规则**：对板用**画出来的几何重建网表**比 PCB 焊盘网，不拿真源比 PCB（真源和 PCB 一致不代表图画全了）；另外列出「PCB 上有网、各页位号并集里没有」的件，必须为空。**证据**：C08B 采集板从 C08A 去掉主控页后报「565 脚 0 不符」，比的是真源对 PCB；独立复核从图几何重建才发现漏画 R801–R808 八颗上下拉。**置信**：低（单次）。
- **情形**：文字检查报 0，图上仍有字压在线上。**规则**：字和字的重叠、字和导线的相交分两项查，按估算的字宽给外框；T 接点、线中途经过脚尖的地方画连接点。检查绿了也要渲染出来看，标签框宽度这类估算会偏窄。**证据**：独立复核发现「字压线」和「60 处 T 接没画点」，原检查只查了字压字。**置信**：低（单次复核发现）。
- **情形**：一个变体不贴一部分件（比如只贴 8 路）。**规则**：不贴的件标灰，还要写明「不贴」字样（写在料值后，或写进框的说明）。只标灰，打印成黑白就看不出来。**证据**：复核发现第 2 页 46 件只有灰字。**置信**：低。
- **情形**：独立复核。**规则**：复核者不调用生成器的代码，自己重建网表；先用故意改错的副本证明脚本会报错（阳性对照）；再对着图抽查易错处，比如插座脚序、电感链、USB 差分对。**证据**：C08A R1 复核做了阳性对照（改 2 脚报 3 处），抽查 16 个脚全对。**置信**：低（单工程一轮）。

## F 交付闭环

最终可编辑工程带可解析的项目符号/封装库；PDF从同一版导出。技术文档替换对应附录，明确当前实现与需求的差异，不把旧参考图上的接口当成现板接口。

压缩包解到新目录后实际打开/导出、跑适用ERC与逐脚比较，核清单和哈希。未授权改的板、旧产品或已下单文件逐字节比较不变。电气一致、可读性、手册正确性、制造和实物结论分别写。
