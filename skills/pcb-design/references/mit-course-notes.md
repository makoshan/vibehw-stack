## 讲义（IAP 2026）
- **L01 系统设计导论 / L11 系统设计回顾**：需求列表除性能外含成本、尺寸、重量、采购周期、制造/装配约束、COTS 还是自制、出口限制；layout 流程 = 机械（板形、禁布区、叠层）→ 摆放（房间/块）→ 布线（铺铜）→ 验证（DRC、仿真）。L11 还讲 UART/SPI/I2C 选型维度。
- **L02 基础元件**：R/L/C 典型值范围；电容介质稳定性 C0G/NP0 > X7R > X5R > Y5V。
- **L03/L04 电路拓扑**：BJT/运放放大器带宽、线性度；LDO 压差 0.1–2V，低噪声、无电感，宜优先；Buck/Boost 原理（PSS 下 <v_L> = 0、<i_C> = 0）；反馈分压设定 V_OUT；模块外围（晶振、SPI Flash、射频匹配、屏蔽壳）。
- **L05 Layout 1/2**：PCB 结构（光刻、过孔、阻焊、表面处理 ENIG/HASL/ENEPIG/ImAg/ImSn/OSP、丝印、多层 2–20 层）；被动件尺寸码公英制对照；封装类型（SOP/QFN/BGA…）；pin1 点、二极管阴极缺口；封装要素（焊盘、方向、散热焊盘/过孔、位号、钢网）；DRC 检查间距、线宽上下限。
- **L06 Layout 2/2**：线宽按 IPC-2152 温升 < 10°C；大电流用铺铜；走线短、长线不成环、不留无端接长线；高频线保持阻抗、差分对对称等长；拐角形状；去耦大小电容组合（100nF + 200pF）；热焊盘利弊；电源平面；整层地、铺地、无孤岛、过孔缝合；必要时弱连接的分割地（高速数字 + 高频模拟）；10h 规则；金属屏蔽罩四周充分接地；测试点放在关键网络；评估板实例（28GHz 放大器、135MHz ADC、70A Buck：宽线跨层 + 过孔缝合、无热焊盘、大电流压接端子）。
- **L07 高功率 Layout（Amanda Jackson）**：击穿强度（空气 3、FR4 20、阻焊 >20、Kapton 300 kV/mm）；电气间隙与爬电、污染等级、碳化/电晕；开槽、圆角、三防漆、灌封；热阻模型；线宽例题（10A/20°C → 250 sq mil → 1oz 200mil / 2oz 100mil，内层要更宽）；超厚铜、铜排；趋肤效应；并联过孔；晶体管热设计（手册电流常假设不现实的散热，选大一号）；导热界面材料；10mil 散热过孔约 180°C/W，需要很多；寄生电感（环路面积，回流放第 2 层）、寄生电容（高 dv/dt 节点铜皮小）；大功率连接器的电流/电压/线规；免手扶测试点（环形钩/同轴）。
- **L08 高速 Layout**：微带阻抗因素；HFSS 仿真；平行线耦合随距离减弱，垂直交叉更好；地线/铺地/过孔墙隔离（2mm 间距下改善 > 20dB）；锐角弯造成反射和辐射，用平滑宽弯；阻焊和 ENIG 镍层增加高频损耗；微带滤波器、耦合器、贴片天线。
- **L10 制造/装配/调试**：叠层（芯板、半固化片、铜箔约 15–30µm）、板材（FR4、RO4003C、RO4350B）；贴片流程；调试工具（万用表、示波器、飞针、针床）；从测试点注入电压分段测试；常见装配错误与修补方法。
- **R05（布局 recitation）**：叠层 → 设计规则 → 粗分房间 → 摆放（全部摆完再布线）→ 布线（先关键线，电源树形，宽线，插件连线加粗，2 层板底层留地，过孔不要钱）。
- **Lab 06**：DRC 错误类型（间距、线宽、环宽、孔径、孔间距、阻焊桥、丝印间距）；BOM 每项有可下单料号；Gerber X2 + 钻孔 + BOM + 原理图 PDF；上传 JLCPCB 预览。
- **Lab 07**：钢网刷锡、热风回流（预热 150°C、热风 280°C、喷嘴距板 3–4 英寸）；DNP 器件；按键等易熔件手焊；上电前 GND 对电源通断检查；5V/0.5A 限流上电，LED 不亮立即断电。
- **元件选型指南**：电阻精度（上下拉 5%，分压 1%）；电容按用途分（高压/中压储能、滤波、旁路、交流耦合）；MOSFET V_DSS ≥ 1.2× 最高电压、I_D 留足余量、看 Q_G；运放 GBW、输入/输出摆幅、压摆率；连接器（DC 插座 5.5/2.1mm 中心正，接线端子 2.54/3.96/5.08mm 间距，Mini-Fit 10A+，BNC ~4GHz，SMA ~14GHz，2.92mm 40GHz+）；保险丝 I–t 特性。
- **板厂下单指南**：Gerber 只描述每层图形，过孔/通孔另需钻孔文件；可选阻焊颜色、表面处理、成品铜厚、过孔盖油。
