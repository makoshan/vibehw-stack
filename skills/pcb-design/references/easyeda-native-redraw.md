# 嘉立创原生重画、逐脚核对与交付

适用：用户指定嘉立创专业版，要求整理既有原理图、核对现有PCB且不改电路。先读 schematic-authoring.md；这里仅补原生导入、密集标注和交付中的实证经验。用户未要求改板时，不触碰PCB、规则或远端布线任务。

## 1. 冻结与冲突

[明确真源] → 固定提交、文件哈希、工具版本 → [独立工程重画] → 原生导出比对 → [视觉复核] → 同版打包。

- **情形**：旧参考图与现板针序不同。**规则**：参考图用于阅读方式；电气真源依本次任务确定，差异逐脚列出。仅当用户明确指定当前PCB为本轮连接真源，或明确授权按板同步时，才据此修正原理图表达并披露差异；只要求“核对”不等于授权选边，冲突时先列差异并确认，不把旧图写回PCB。**证据**：C08A旧接口16脚反序，最终按冻结板恢复表达。**置信**：低，单工程。
- **情形**：从PCB建立脚表。**规则**：按位号/脚号记录网络；重复编号焊盘分别核实例，空编号机械pad和安装孔另列。保留原有空网，不把空网或机械pad自动接地。比较料值、MPN、封装、DNP；未核字段明确未核。**证据**：C08A原880项含2个空号机械pad，实际878个定义引脚，另34空网脚。**置信**：低，单工程统计口径验证。

## 2. 把密集处真正画清楚

- **情形**：大芯片一条边挤满脚名。**规则**：可按功能把显示脚排到两侧，保留脚号与网络映射；别复制物理封装四边挤法。外围回路仍用实线，不把每个元件拆成孤立标签。**证据**：C08A 74脚主控改为左右两列后独立视觉复核通过。**置信**：低；两列和37脚都不是通用定值。
- **情形**：同点多脚的脚名重叠。**规则**：先查实际原生网表；确为同网才可隐藏重复显示，并在留白标“网络名 [完整脚号列表]”。不同网同点属于待解决错误，不能靠隐藏掩盖；隐藏文字不能删除电气引脚。**证据**：9组同点脚逐组核网；电平转换器地脚清单首次漏1脚，二次核表纠正。**置信**：低，单工程。
- **情形**：缩略图清楚但局部压线。**规则**：逐页看全图，再放大主控、测试点、晶振、三极管保持回路、电平转换和长字段；改文字后重导图并重导网表。**证据**：C08A独立复核追加发现测试点、Q2和U3压线；修复后脚网零差异。**置信**：低，单次完整工程。
- 页数按回路密度决定；该案例5页只是结果，不硬套五页模板，不靠缩小字体塞页。

## 3. 原生库与API：版本限定的坑

以下仅实测嘉立创专业版 **3.2.186**（2026-10-28）；升级后先在独立小工程探针验证。API用法先查当前工具/类型定义，示例不是跨版本保证。连接沿用已授权的 easyeda-api；断线重查窗口清单和工程身份，不能复用旧窗口ID盲写。具体窗口ID、主机路径不写死到可复用脚本。

| 情形 | 动作 | 本次证据 | 置信 |
|---|---|---|---|
| 新库导入后紫色叉，schema却通过 | 检查DOCHEAD的version/updateTime及库关联，再实际导入查看 | 补齐两字段后符号显示；未证明每字段单独因果 | 低 |
| modify返回成功但文字没动 | 传primitiveId字符串，修改后读回坐标并看原生导出图 | 本次传对象假成功，传ID后生效 | 低 |
| 需要移动/转向网络端口 | 不套用只支持part的Component.modify；查对应原生API，在副本测试 | netport走该接口失败 | 低 |
| 修改引脚电气类型 | 先快照脚坐标/网络/类型，在副本试单脚并读回；异常就恢复并验证，不批量推广 | Pin.modify试写Passive时Y坐标翻转，已撤销；Attribute写Passive后运行时类型仍Undefined | 低 |
| 检查器返回类型汇总 | 同时导出详细报告，区分批数、对象数和历史日志 | 本次10批警告含8批标准化和2批NC；NC涉及34脚 | 低 |

不要运行自动供应商标准化来消掉提示：可能换器件/MPN。需要替换时按用户授权的电气变更另行处理。原生电气类型映射不完整时，自定义字段保存原类型只算留档，不能宣称ERC等价；也不靠禁用规则取得零错误。

## 4. 同一最终版本交付

- **情形**：导入后又通过API排版。**规则**：以编辑器最终导出的可编辑工程为交付真源；初始生成包单独标“初稿”。脚本添加图元应幂等（查询自有ID或标记后更新），旧一次性脚本注明不可重跑。**证据**：C08A初始包不含最终23项文字调整和9组脚号清单。**置信**：低。
- **情形**：PDF导出参数不明。**规则**：核当前签名；3.2.186本次实测 `getExportDocumentFile(name, 'PDF', {}, 'Current Schematic', {range:'All', outputMethod:'Merged sheet'})` 可得合并矢量PDF；不把超时说成成功。**证据**：实际5页PDF，与同版逐页SVG人工核对。**置信**：低。
- **情形**：自制网表显示零差。**规则**：必须改用编辑器实际导出网表核全部脚，再比较料值等声明核过的字段；故意改一脚的隔离副本应能让检查失败。电气比较与视觉检查各自记录输入哈希、结论和未覆盖项。**证据**：C08A最终255件/878脚原生网表独立核对零差，视觉复核另存；该数字不是通用通过门槛。**置信**：低。
- 最小交付：原生终稿、同版PDF、逐脚差异报告、原生检查详情、基线清单和SHA256。压缩包检查CRC/哈希；重开导入与导出属于另一项验收，只有实际执行才勾选。
- 最后打开实际工程和可读PDF。图已完成、连接一致、ERC完整、制造合格、实物可用是不同结论；不能用其中一项替代其余。

## 5. 不经编辑器窗口：生成 eprj3 文件夹工程，用官方 CLI 验收

适用：页面由脚本生成，要交嘉立创原生工程。以下实测嘉立创专业版 **4.1.93**（2026-11-01）。客户端自带命令行 `LCEDA-Pro`：`open --path x.eprj3 --headless true` 返回会话号 → `invoke --session … --code …` → `session close --session … --destroy`，不碰用户开着的窗口。记录格式用 easyeda-eprj3 skill 的库函数拼装（元件、器件、电源符号、网络端口、导线、文字、图形）。注意：那个库写出的记录不带 `yAxisDirection`，它的文档却说坐标是 Y 向上，照用会整页上下翻转，必须后处理补标记（见下表第一行）；该 skill 文档待改。坐标单位按 easyeda-pro-format-skill 的字段说明取 1 单位 = 0.01 inch（eprj3 skill 文档写 mil，与此不符）；本轮 1680×1188 单位渲染出来正好约 A3，单位以此为准。

| 情形 | 动作 | 本次证据 | 置信 |
|---|---|---|---|
| 渲染出来整页上下翻转 | 本地 eprj3 里不带 `yAxisDirection` 的记录按 Y 朝下解析；自己写的每条图元记录都加 `"yAxisDirection":"up"`，从旧工程搬来的封装文档保持原样 | 第一次整页翻转；加标记后方向正确 | 低 |
| 网表里大量脚是空网 | 嘉立创只认「线端碰脚尖或线端」。导出前把线在途经的脚尖、交点处断开；电源符号、网络端口不直接压脚尖，先引一小段线再放 | 修之前 148 个网断开或漏接，修之后 878 脚 0 差异；两处一起改的，没分开验证各自贡献 | 低 |
| 要核原生网表 | `openDocument` 打开第一页后调 `sch_Netlist.getNetlist()`，按「网 → 脚集合」比对，不比自动网名；先跑改坏的副本，确认脚本会报错 | 阳性对照：改 2 脚报 3 处 | 低 |
| 刚打开会话，页面列表是空的 | 轮询 `getAllSchematicPagesInfo()`，等到非空再操作 | 固定等 8 s 偶尔还是空的 | 低 |
| 原生检查报 255 条「缺封装」致命错误 | 器件挂上封装文档；封装从旧原生工程按位号取，文档头改成 eprj3 写法（否则校验器把它当成上一文档的续行） | 挂上后 0 致命 | 低 |
| 想导出 PNG 目检 | 多页 PNG 打成一个 zip，超过 CLI 单次返回上限 8 MB；改用 `getSvgFile`，取回后自己截图。`saveFileToFileSystem` 要开「外部交互权限」，这是用户的安全设置，不替用户开 | 五页 PNG zip 9.4 MB 被拒，SVG zip 1.6 MB 可以 | 低 |
| 页序乱了 | 页序按工程索引里 sheet 的 `zIndex` 排，生成时直接写 1–N 的整数 | 库给的小数被客户端回写后排乱 | 低 |
| init 自带的 A4 图框压在图上 | 图上自带图框和标题栏时，删掉那个图框元件和它的属性 | 删掉后正常 | 低 |
| 导线上冒出网名小字 | 写进导线的 NET 属性，即使 `valueVisible:false` 也会显示；原工程留下的自动网名（`$` 开头那类）不写，手写的同名说明删掉 | 实测 | 低 |
| 原生检查报 875 条「不在格点」 | 嘉立创格点是 0.05 inch，即 5 单位（1 单位 = 0.01 inch）；脚坐标要从画图时就落在 5 单位格点上，事后取整可能并点、改连接 | 本轮只观测到警告，没做修正前后对照；只影响编辑时的吸附 | 低 |

- 客户端打开 eprj3 后会按自己的格式回写文件（双向同步）。入库那份要在最后一次打开、关闭之后再复制。
- 交付证据：生成脚本、eprj3 工程、原生网表比对结果、原生检查按「级别 | 规则」统计的结果、嘉立创自己渲染的各页图。示例在原力手环仓 `v12/c08a-sch-style-sample-20261101/`（`build_eprj3.js`、`native_netlist.sh`、`compare_native.py`、`native_drc.sh`、`native_svg.sh`），提交 `91238821`；过程数字见该目录 README，提交 `01b19a50`。

## 6. KiCad 板 + 脚本原理图合成一个嘉立创工程（带 3D），交付包换版

适用：板子在 KiCad 里布，原理图是脚本生成的 eprj3，要交一个原理图、PCB、3D 都能看的嘉立创工程（eprj3 + epro2）。实测 **4.1.93**（2026-11-02）。流程和脚本在原力手环仓 `v12/c08-eprj3-20261102/`（`combine.py`、`verify.py`、`native_check.py`、`rebuild.py`、`export_epro2.py`，README 有 R2/R3 两轮数字），R3 提交 `f1a751de`。
