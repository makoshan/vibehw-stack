# 装饰面板：设计包与询价稿

一句话：**图案是脚本生成的、文字必须转曲、裁切线单独一个文件、出血交给商家、公差没对齐之前不下单。**

## 0. 先判断做哪一种

| 方案 | 结构 | 什么时候选 |
|---|---|---|
| 薄膜装饰面板（默认） | 中间**物理挖空**给屏幕，贴进壳体凹台 | 壳体凹台已经定了、屏幕自带玻璃、想要最薄 |
| 整片透明硬质亚克力镜片 | 中间是**透明窗口**不是挖空，背面印刷 + 白墨遮光 | 要一整片盖住、要镜面质感 |

两者的生产文件不通用：亚克力方案要另做刀线，并重设壳体承托/凹槽高度。别拿薄膜的 cut SVG 去问亚克力。

## 1. 产出物（一个包，缺一样商家就要来回问）

```
<project>/face_<name>_v<N>/
├── <name>_front.svg          正面图案，名义成品尺寸，文字全转路径
├── <name>_front_1to1.pdf     同图 1:1 矢量 PDF（打印时选「实际大小」，不要「适应页面」）
├── <name>_preview.png        放大预览，只看样式，不许按像素量尺寸
├── face_cut_1to1.svg         面板外形 + 挖空刀线（独立文件）
├── screen_film_cut_1to1.svg  屏幕膜刀线（另一个零件，别和面板连成一片）
├── make_art.py               生成器
├── 给商家的询价说明.md
└── <name>_设计包.zip
```

## 2. 生成器怎么写（make_art.py 模式）

参数化 + 自检，不要手画。关键几点：

- **文字转路径**：`matplotlib.textpath.TextPath` 把字变成多边形，再自己拼 `<path>`。结尾断言 `assert '<text' not in art` —— 只要还有一个 `<text>` 标签，商家那边就可能换字体。
- **几何断言**：挖空必须横纵居中就写死 `assert (W-hole_w)/2 == hole_x`，别靠眼睛。
- **刀线从 CAD 版本目录复制**，不要在这里重画：`shutil.copy2(r.parent/'v26_strap_alignment'/n, r/n)`。面板刀线和壳体凹台是同一个来源，复制才不会走样。
- 圆角矩形用一个 `rr(x,y,w,h,a)` 函数生成 path，挖空靠 `fill-rule="evenodd"` 和外形放同一个 `<path>` 里。

MAKO V26 的实际参数（可作起点）：外形 32.6×30.6 R5.3；挖空 23.6×12.8 R0.6，左上 (4.5, 8.9)；最细装饰线 0.30 mm；黑底 `#111820`、冰蓝 `#32c6f3`、白 `#ffffff`。

## 3. 厂家工艺能力（立创名片 szlcmb.com/craftDisplay.html，2026-09-13 查）

| 项 | 数 |
|---|---|
| 切割公差 | **±0.3 mm**（外形走负公差、孔走正公差） |
| 最小文字 / 图案线宽 | ≥ 0.25 mm |
| 描边距切割边 | ≥ 0.7 mm |
| 窗口距外形边 | ≥ 3.5 mm |
| 出血 | **商家按套准和切割偏差自己做**，设计稿不自带 |

**下单前必做的一次相减**：`(壳体凹台 − 面板名义外形) / 2` 是每边余量，拿它和切割公差比。
MAKO V26 是每边 0.2 mm 余量 vs ±0.3 mm 公差 —— **装不进去的概率很高**，正确动作是先要样片拿实物凹台配，不是改一下刀线直接下单。再加上 3D 打印件本身的收缩，这个差只会更大。

## 4. 询价说明里必须逼商家回答的六件事

1. 材料与表面处理
2. **基材 / 印刷 / 胶的分项厚度，以及含胶总厚公差**
3. 最小可做文字（把最小字号的笔画和字腔单独点出来让他们确认）
4. 外形与开孔公差的**定义**（成品最大外形是多少）
5. 建议出血
6. 交期及费用（少量打样）

## 5. 三个反复踩的坑

- **颜色 HEX 是屏幕参考，不是 CMYK / 专色标准**，更不是实物色差验收依据。写进说明里，别让商家拿去当标准。
- **基材厚度 ≠ 含胶总厚**。壳体凹台深 0.30 mm、设计含胶总厚 0.20 mm，这两个数必须分开谈。
- **裁切线绝不能印到成品上**。所以它单独一个 SVG，并在说明里写死这句。

## 6. 稿子的定性要写在第一行

`本包是 V26 现有凹台的图案和名义几何参考，尚不是量产下单批准稿。`

设计包和批准稿是两个东西。没写这句，商家可能直接开机。
