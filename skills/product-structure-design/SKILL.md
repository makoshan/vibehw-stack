## 何时使用
- 新做或改版肌电手环、手表类穿戴外壳，或者一个电极模组
- 拿到 ID 外观或 PCB 后做堆叠、分件和结构细节
- 3D 打印样机准备转开模，或者评审别人的结构图
- 装不上、断柱、松动、进水、接触不良时，先用本 skill 定位原因，再按 `mako-cad-fit` 小改

## Mako 的闸门（每阶段结束都过一遍）
好看（Braun/Bauhaus：少即是多，面和线干净，没有多余的分模线和螺丝外露）/ 会用到 / 可交付复刻（图纸是正交投影、尺寸可测量、BOM 和装配顺序齐全）/ 成本可控。

## 流程

### 1. 需求与尺寸链
- 先定 ID、CMF 和需求，再搭骨架模型（skeleton），所有零件都从骨架上引用 [V3 P01]
- 导入 ID、PCB 文件时先量一个已知尺寸核对单位，比如 25 mm 的边就该量出 25 mm [V3 P02]
- 列尺寸链：皮肤 → 电极 → 底壳 → PCB → 电池 → 面壳 → 表带。每一环写名义值和公差，累加后留余量 [通用]
- 手环目标（[通用]，实测后更新）：腕围 140–200 mm 可调；主体厚度 ≤ 12 mm；8 个电极均匀分布在前臂近端，或者沿腕周排布

### 2. 堆叠 / Placement / ID 可行性
- 做 PCB 堆叠和布局（placement），放好电池、连接器、按键、指示灯，查清它们和壳体的关系 [V3 P02]
- ID 的侧面如果是 90° 直身，不做拔模就得走滑块，滑块交界处会留合模线。要提前反馈给 ID 和客户确认能不能接受，开模后再改基本就来不及了 [V3 P01]
- PCB 不要和走线、外部元件干涉；空间不够时先算一下能不能避让 [V1 P19]
- PCB 边缘到壳体内壁至少留 0.75 mm，外框壁厚至少 0.8 mm [V1 P06/P12，转写较可信]
  - 书上：外观面胶厚 ≥ 0.8 ✅；PCB 间隙书里没找到对应数值，保留视频值
- ADS1299 的 AFE 区要靠近电极，离电池、BLE 天线和 DC-DC 越远越好；天线上方不能有金属 [通用]

### 3. 壳体分件、拔模、壁厚
- 用 Top-down 设计：在总装里从骨架拆出面壳、底壳、电极座和装饰件，改动通过父子关系传递 [V3 P03/P05]
- 胶厚：小产品取 0.8–1.2，普通电子产品取 1.2–1.5。PMMA 0.8–1.5 [V1 P01]
  - 书上一致：小型件（L<80）ABS 1.0–1.4、PC 0.8–1.2、PMMA 0.8–1.5，最小 0.6 [B1 §4.2 表4-1] ✅
- 胶厚尽量均匀，同一件上最厚处 ÷ 最薄处 < 2，超过就有缩水、变形的风险（例子：2.8/1.3 偏危险）[V1 P01]
  - 书上一致：由薄变厚不超过 2 倍，由厚变薄不少于 0.5 倍，并且要逐渐过渡 [B1 §4.2] ✅
- 移动电源案例的抽壳取 2.0 mm [V3 P03]；手环取 1.2–1.5，打印件取 1.5–2.0 [通用]
- 骨位（加强筋）厚度 = 壁厚 × 0.5–0.6，太厚背面会缩水 [V1 P01]
  - 书上是 0.4–0.6t，常取 0.5t；筋高 ≤ 3t，筋间距 ≥ 4t，筋顶离外观面 ≥ 1.0 [B1 §4.5] ✅（下限修正为 0.4t）
  - 螺柱加强筋：顶宽 ≥ 0.5，底宽取柱高的 0.2–0.5 倍，离柱顶 ≥ 1.0 [B1 §4.5]
- 拔模：外观面 2–3°，内部 1–2° [V1 P01]
  - ⚠️ 冲突：B1 建议外观面不少于 3°，防止拉伤 [B1 §4.3]。材料表给出的一般值是 ABS 40′–1°30′、PC 40′–1°50′、PP 30′–1° [表4-2]。手环外观面取 3°，内部取 1°
  - ⚠️ 冲突：B1 写的是"外观要求高、表面光亮 → 拔模小"，"表面粗糙、咬花 → 拔模大"；视频转写的这一句含糊。以书为准：咬花面要加大拔模
  - 拔模方向：外形以大端为基准，内孔以小端为基准，都用减胶方式；重要配合面一定要做出拔模 [B1 §4.3]
- 高柱子不要按角度拔模，按上下尺寸差算，约 0.15 mm [V1 P01]
- 精度要求高的部位拔模取小 [V1 P01]
- 尖角都倒圆角，内 R ≥ 0.5 × 壁厚，外 R = 内 R + 壁厚 [通用]

### 4. 卡扣 / 螺柱 / BOSS / 止口
- 自攻螺丝柱（ABS/PC）[V1 P03] 对照 [B1 §4.11 表4-4]：
  - 2.3 mm 螺丝 → 底孔 Ø1.9、外径 ≥ Ø4.5 ✅ 与书一致
  - M2：视频说底孔 Ø1.7，书上是 Ø1.6、外径 ≥ Ø4.0 ⚠️ 以书为准，ABS 取 Ø1.6；材料偏硬时适当放大，偏软时缩小
  - 单边咬胶量：视频 0.15–0.2；按书上的表换算是 0.2（≤M2.6）、0.25（M3），⚠️ 取 0.2
  - 外径约 2× 螺丝直径：书上 M2 是 2.0×，M3 是 1.8× ✅。通用经验 2–2.5× 在打印件上更稳 [通用]
  - 柱深 ≥ 2.5；螺丝头过孔比螺丝头大 0.2；两壳螺柱之间 Z 向间隙 0.1；螺丝头下的支撑胶厚 ≥ 1.0（M2）[B1 表4-4]
  - 整机不少于 4 颗螺丝，四个角落必须有 [B1 §10.5]
- 螺柱根部要倒圆角、加筋，有效啮合 ≥ 2 × 螺丝直径；打印件优先用热熔铜螺母，比如 M2 3.5×4 [通用；嵌件另见 V1 P09]
- 卡扣 [V1 P04–P06] 对照 [B1 §10.6]：
  - 扣合量：视频说 0.2–0.3，书上是 0.35–0.60，常取 0.5，最少不要低于 0.4；反扣先做 0.35，试模后再调 ⚠️ 冲突。手环开模件按书取 0.4–0.5；打印件先用 0.3 试，脆的话缩小
  - 侧向间隙：视频 0.1，书上 0.2；Z 向间隙 0.05 ⚠️ 以书为准
  - 尺寸：公扣宽 2–6（常用 4）；公扣、母扣厚 1.0（最少 0.8）；导入倒角 0.4×45°；公扣顶面比分模面低 0.1 [B1 §10.6]
  - 变形空间要大于扣合量，再加 0.2 以上；扣要在整圈均匀分布，强度弱的地方多布 [B1 §10.6]
  - 母扣布在公止口所在的壳上；做反扣时，公止口两侧各切掉 ≥ 8 mm [B1 §10.6]
  - 悬臂扣应变公式：ε ≈ 1.5·y·t / L²（y 为扣合量，t 为根部厚，L 为臂长）。ABS 一次装配许用约 2–2.5%，反复拆装按 60% 取 [通用，Tres/Bayer 手册类方法]
- 止口（唇边）：视频说单边间隙约 0.1–0.2 [V1 P04/P05]，书上细化为 [B1 §10.4]：
  - 配合面间隙 0.05；纵向避让 0.1–0.2（推荐 0.2）✅
  - 公止口做在薄的壳上；根宽 0.6–0.8，拔模后顶宽 ≥ 0.5；两侧拔模 2–3°；倒角 0.25–0.3
  - 外观面胶厚 ≥ 0.8
  - 公止口高度：正文印作"0.60～0.10"，是排版错误。图10-4 的示例值是 a=0.80、b=0.70、拔模 2°（88°）、倒角 0.25×45°，所以按 0.6–1.0 取，手环用 0.8 [B1 §10.4 图10-4]
  - 止口整圈完整还能挡 ESD（"静电墙"）
- 移动电源的卡勾：钩高约 0.5，导向斜面 45°，配合预留 0.1 [V3 P07/P09]
- 五金件和塑胶件的配合 [V2 P04–P06]：
  - 压入、热铆的干涉 0.1–0.2
  - 槽宽要比片厚留出余量，例如 1.5 mm 的片配 2.0–2.2 mm 的槽
- 最后做全局干涉检查，再做结构优化 [V3 P12]

### 5. 防水密封
- 防水等级按 IPX 分 8 级；低级别是滴水、淋水测试，有规定的喷口和时长 [V1 P14]
- 常用做法 [V1 P14]：
  - 双止口加超声焊。视频说防水焊线约 0.3–0.4；书上的焊线角 60°，线高随壁厚取：壁厚 1.2–1.5 → 0.25，1.5–2.0 → 0.30，2.0–2.5 → 0.35 [B1 §15.3 表15-7] ✅ 量级一致，手环 1.5 壁取 0.30
  - 超声焊不可拆，最好同种塑料；焊接面不能喷漆、电镀；不需要防水的地方可以用虚线焊线防溢胶 [B1 §15.3]。注意：手环如果要换电池或维修，就别焊，改用密封圈加螺丝
  - 硅胶或 O 型圈
- 密封圈一定要有压缩空间，不是贴在一起就防水。视频例子里的压缩量 0.5–0.7 [V1 P14]；按截面算，压缩率取 15–25% [通用]
- 手环建议：汗水级 IP54–IP67。电极柱穿壳的地方用灌胶，或者硅胶套加压缩；充电口用 pogo 触点，不开 USB 口 [通用]

### 6. 电极与皮肤接触结构（EMG 专用，[通用]）
- 电极：干电极用镀金（铜或不锈钢镀金，金厚 ≥ 0.5 µm），湿电极用 Ag/AgCl 卡扣片
- 接触压力：目标 5–20 kPa，既要稳定接触又不能勒得难受。表带用弹性材料，或者在电极下方加弹簧
- 浮动电极：
  - 每个电极独立浮动，行程 1–2 mm
  - 可选方案：硅胶衬垫、pogo pin 或者波形弹片
  - 球面或圆顶接触面 Ø8–10 mm，边缘倒圆角
- 布局：差分电极对的中心距 15–20 mm，沿肌纤维方向排列；参考电极（Bias/DRL）放在骨性位置
- 屏蔽与走线：
  - 电极到 AFE 的线越短越好，差分对走线等长，就近放 RC 保护
  - 壳体内侧可以喷导电漆或贴铜箔接地；防 ESD 见 [V1 P12]
  - 不让电极走线和充电、天线走线平行
- 电极座必须可拆、可清洁、可替换，干湿两种电极共用同一个卡扣接口，满足"可交付复刻"

### 7. 表带 / 连接
- 表耳留在上壳，不和底座做成一体，沿用 `mako-cad-fit` 的约束
- 快速样机也可以先套现成的防水腕表外壳（例：Serpac BW4，厂家提供 STEP 和推荐板形，约 5.3 USD），传感器放在 PCB 底面，透过壳上开窗接触皮肤 [B2 第7章]。适合在 Mako 的 ID 定型前先验证电极
- 优先用标准快拆杆（20/22 mm）或者硅胶一体带。电极串联在带上时用 FPC 或柔性导线，弯折半径 ≥ 10 × 线厚 [通用]
- 多模块的环可以用铰链或者 TPU 链节；转轴和卡簧参考 [V1 P13]

### 8. 公差与装配顺序
- 主板装在哪个壳：装在厚壳上 / 装在有侧键的壳上 / 两边都行时优先装前壳；目标是"傻瓜式装配" [B1 §10.3]
- 固定方式怎么选：经常拆装选螺丝；需要密封、不拆选超声焊；金属件少用卡扣 [B1 §10.5.1]
- 写清装配顺序：电极座 → 底壳 → PCB（定位柱先定位，再固定 [V1 P19]）→ 电池 → 面壳 → 螺丝或卡扣 → 表带
- 每一步都要能单手操作，并且有防呆设计 [通用 DFA]
- 打印件公差（[通用]，FDM 0.4 嘴，实测后更新）：
  - 孔要放大 0.2–0.3
  - 滑配间隙 0.2，紧配 0.1
  - 卡扣干涉 0.2–0.3，和视频值相近，但打印件更脆，要加长悬臂
- 开模件：一般配合间隙 0.05–0.1，按模厂能力定 [通用]
  - 公差按 GB/T 塑料件公差等级标注：重要尺寸用一级，其余用二级；最终用实物装配来验证和修模 [B1 §4.12]
  - 尺寸链：先用最坏情况算（Σ 公差），零件多（≥ 4 个）时用 RSS = √Σtᵢ² 估算，关键间隙两种都要算 [通用]

### 9. 3D 打印 vs 开模 DFM
- 结构和模具是绑在一起考虑的：分型面、滑块、斜顶、入水、顶针位置都会影响外观和成本 [V1 P20；V3 P01]
- 嵌件注塑（模内金属）适合螺母、电极柱 [V1 P09]
  - 嵌件外包胶厚按直径 D 取：D<4 → 侧 1.5、底 1.0；D 4–8 → 侧 2.0、底 1.5 [B1 §4.10 表4-3]
  - 嵌件优先做圆柱形，外圆滚花增强结合；片状嵌件要做挂台和切口 [B1 §4.10]
- 打印件要注意：
  - 首层打印的基准面和装配基准不是一回事
  - 悬垂 ≤ 45°
  - 薄壁 ≥ 2 条线宽
  - 卡扣沿层方向会断，要竖着打
  [通用，见 `mako-cad-fit`]
- 小批量路线：FDM → SLA/MJF → 硅胶复模（10–50 套）→ 铝模 [通用]

### 10. 验证清单
- [ ] 胶厚比 < 2，筋 0.5–0.6×，拔模外 2–3° / 内 1–2°
- [ ] 螺柱底孔、外径、咬胶量核对；热熔螺母型号已写进 BOM
- [ ] 卡扣扣合量和导入角满足要求，装拆 10 次以上不断
- [ ] PCB 到内壁 ≥ 0.75，全局干涉检查为 0
- [ ] 防水圈压缩量已算过；淋水或浸水测试通过
- [ ] 8 个电极在 3 种腕围下都接触良好：阻抗记录 < 目标值，静息噪声 RMS 已记录，握拳和放松动作的 SNR 可接受
- [ ] 浮动电极的行程和压力实测过；佩戴 30 分钟无压痕和不适
- [ ] 屏蔽和接地连续性已测
- [ ] DFMA / FMEA 装配检查表逐项过一遍：装配步骤、干涉、限位、固定、防呆、间隙（是否考虑公差）、外观、线缆和 FPC [B1 §13.12 表13-1，见 references]
- [ ] DFMA 减件三问：这个零件相对其他件要运动吗？必须用不同材料吗？必须分开才能装配或维修吗？三个都是"否"就该合并 [通用，Boothroyd-Dewhurst]
- [ ] DFMA 零件检查表：筋厚约 50% t、筋高 ≤ 3t；柱壁和柱根厚 ≤ 0.6t、柱高 ≤ 5t；倒扣、尖钢、厚胶要处理 [B1 表13-2]
- [ ] 手环可靠性测试，按 [B1 §14] 改写，改写的部分是 [通用]，完整条件见 `references/book-tables.md`：
  - 跌落：书上是 1.0 m 混凝土地面跌 6 面 4 角；手环按 1.0–1.5 m 跌，并且要戴在模拟手腕上测一次
  - 汗液：书上用 pH 4.7 人工汗 40 °C / 93–95% RH 放 24 h；手环要泡电极和表带接触面，查镀金电极变色、Ag/AgCl 腐蚀，以及汗液是否渗进电极柱
  - 盐雾：5% NaCl、35 °C、24 h，用来测电极和金属件
  - 湿热和高低温：40 °C / 95% RH 48 h；工作温度 −20 到 55 °C；温度冲击 −40 ↔ 70 °C 循环 10 次
  - 振动：0.38 mm、10–30 Hz 加 0.19 mm、30–55 Hz，三轴各 1 h
  - ESD：空气放电 ±8 kV、接触放电 ±4 kV，重点打电极、合缝和充电触点
  - 按键：180 gf 按 10 万次，侧键 5 万次；充电口插拔 3000 次，pogo 触点同样做 3000 次
  - 表带拉力：表耳和快拆杆加 ≥ 50 N 静拉，表带扣开合 5000 次
  - 防水：按 IP67 或目标等级（IEC 60529）做浸水测试
  - 贴肤温度：最高贴肤温度 ≤ 41–43 °C（IEC 60601-1 和 IEC 62368-1 的经验值）；静息噪声和佩戴舒适度要在 4 h 连续佩戴后再测一次
- [ ] 图纸：正交投影、关键尺寸带公差、装配顺序、BOM、STEP/STL 版本号

## 平底主机接电极表带（C08B 2026-11）

- **靠盒电极的位置先跑佩戴账。**
  - **情形**：平底主机连电极表带，要定第一颗电极离盒多远、表带从哪个高度出盒。
  - **规则**：先用腕围模型算每颗电极离皮肤的距离，再定软板长度。主机边到皮肤切点这段是空的，出带点越高空得越长，优先低位出带。按固定步长扫腕围（这次 5 mm），支持范围由用户定，范围外的结果留着，不删。
  - **证据**：C08B 170 mm 腕，低位出带时首颗离壁 4 mm 悬空约 3 mm，12 mm 约 0.35 mm，见 `v12/c08b-d16-3d-r7-20261106/checks.json`；D3 的 `wear.py` 改出带高度可重算。
  - **置信**：中。两轮模型结果同向，未实戴。
- **软板朝向先看触点投影。**
  - **情形**：软板有串阻和针焊点，哪面朝皮肤还没定。
  - **规则**：查器件和金属触点投影是否重叠。器件和焊点放外侧，皮肤侧只留触点；换面时接口要接受翻面，比如上下双接触的座，再核方向件。
  - **证据**：C08B R3 的 34 颗串阻全在触点投影内且朝皮肤，R4 镜像后转到外侧，见 `v12/c08b-d16-fpc34-r4-20261106/REVIEW.md`。
  - **置信**：低。一次，结构未打样。
