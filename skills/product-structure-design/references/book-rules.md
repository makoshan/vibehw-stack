# 书里的结构设计数值规则

来源：黎恢来《产品结构设计实例教程》（Mako 本机 epub，`~/Downloads/`，2026-10-21 读文字）。条目后的 `[书 x.x]` 是章节号。以下是摘要与数值，不是原文。

适用边界：书的语境是消费电子（GPS 手持机）塑胶注塑量产。手环 demo 阶段用 3D 打印 / CNC 时，把这里当“设计意图”，不要当成打印件规格。epub 里的表格（表 4-1 料厚、4-2 拔模、4-4 螺丝柱配合、15-7 超声线、15-1 电池型号）是图片，文字读不到，这些具体数没有，不要补写。书内个别数值有排版错误或前后不一，已在条目里标出，取保守值。

## 壳体基础

| 项 | 规则 | 来源 |
|---|---|---|
| 料厚 | 范围 0.6–6.0 mm，常用 1.5–3.0；小型件（最大边 <80 mm）取偏薄；尽量均匀 | 书 4.2 |
| 料厚过渡 | 薄→厚 ≤2.0 倍；厚→薄 ≥0.5 倍原厚 | 书 4.2 |
| 拔模 | 外观面不少于 3°；非外观的重要配合面（电池仓、止口）约 2°；筋位可不画，交给模厂 | 书 4.3、13.7 |
| 圆角 | 内圆角 R = 0.5–1.5 倍料厚，最小 0.3；外圆角 = 内圆角 + 料厚；分型面不要圆角；手能碰到的外观面不留尖角（≥R0.3） | 书 4.4 |
| 加强筋 | 根厚 0.4–0.6 倍料厚，高 ≤3 倍料厚，两筋间距 ≥4 倍（书 15.5 写 ≥3 倍，取 4 倍），离表面 ≥1.0，拔模 0.5–1.5° | 书 4.5、15.5 |
| 螺丝柱加强筋 | 筋顶宽 ≥0.5，底宽 = 柱高的 0.2–0.5 倍，离柱顶 ≥1.0；筋低于支撑面 | 书 4.5 |
| 支撑面 | 用凸边/凸台/凸点，高 0.3–2.0 | 书 4.6 |
| 孔 | 孔距：孔径 <3 时 ≥孔径，>3 时可取 0.7 倍；孔边距 ≥孔径；盲孔深 ≤5 倍孔径，通孔 ≤10 倍 | 书 4.7 |
| 塑胶螺纹 | 外螺纹 ≥3 mm，内螺纹 ≥2 mm，螺距 ≥0.5，配合长 ≤2 倍直径，首尾留 ≥0.5 无螺纹段 | 书 4.9 |
| 嵌件 | 尺寸精度要高、强度要够、要防松脱（圆柱件滚花、片件加挂台切口）、外形最好圆柱、别过大过薄 | 书 4.10 |
| 缩水控制 | 胶柱外壁厚 ≤0.6 倍料厚，内孔底厚约 0.7 倍；过厚处掏“火山口”约 40°，底厚取料厚 2/3；或正面补胶反面掏胶 | 书 15.5 |
| 尺寸精度 | 国标公差只作参考，以实物装配为准；重要尺寸标一级，次要标二级 | 书 4.12 |

## 连接方式选择 [书 10.5.1]

金属件别用卡扣；常移动、常拆装的用螺丝；要密封的可超声焊；外形大的不宜只靠卡扣。整机不少于 4 颗螺丝，四角必有，中间用卡扣辅助。自攻螺丝装配简单便宜但不宜反复拆（滑牙），机牙螺丝可反复拆但要螺母。

## 自攻螺丝与螺丝柱 [书 4.11]

- 命名例：PB2.6×5 = 圆头平尾，直径 2.6，长 5。
- 螺丝柱深度不小于 2.5；螺丝头过孔 = 头径 + 0.2；硬塑料柱内径可放大，软塑料可缩小（数据按 ABS）。
- 螺丝柱靠近壳内壁，容易出薄钢、厚胶，见下文 DFM。

## 止口 [书 10.4]

- 公止口做在薄壳，母止口做在厚壳。止口防错位，也叫“静电墙”，尽量整圈保留。
- 公止口：根宽 0.6–0.8，拔模后顶宽 ≥0.5，两侧拔模 2–3°，装配倒角 0.25–0.30；高度书里印成“0.60～0.10”，疑为 0.6–1.0，用前核。
- 配合：配合面 0.05；纵向避让 0.10–0.20（建议 0.20）；外观面胶厚 ≥0.8。

## 卡扣 [书 10.6]

- 公扣宽 2–6，常用 4；母扣壁厚常 1.0、最少 0.8；公母侧向间隙 0.2；母扣封胶 0.3。
- 扣合量 0.35–0.60，常用 0.5；公扣上表面低于分型面 ≥0.05（常 0.10）；Z 向间隙 0.05；避让 ≥0.2；公扣倒角 0.4×45°。
- 母扣变形空间要大于扣合量，最好 >0.2；空间紧时扣合量不少于 0.40，或把配合间隙做到 0.15。
- 数量：6 颗螺丝配 8 个扣；4 颗螺丝配 8–10 个；扣距约 30，超过 35 加扣。
- 反扣（母扣在母止口一侧）：公扣两侧公止口各切掉 ≥8，否则成死扣；首版扣合量先做 0.35；拆装更难，空间够就用正常布扣。

## 反止口 [书 13.1]

与母止口夹住公止口，两个方向限位。距公扣 8（至少 6）；配合面 0.10（≤0.15）；高 ≥0.6（建议 0.8），长 ≥1.0；成对做，间距约 1.5；空间不够用工字骨（长 ≥2，建议 3）；整圈间距约 30。

## 限位主 PCB [书 13.2–13.4]

- 只让一个壳限位，避免重复限位（公差叠加会装不进）。
- 主限位：壳上长柱插入 PCB 限位孔，间隙 0.10，两处对角；辅助限位（螺丝柱、反止口）与 PCB 间隙 0.15–0.25，常 0.20；限位柱高出 PCB 约 1.0，装配边倒 0.25。
- Z 向：主板装底壳时，底壳顶板骨位零间隙，前壳顶板骨位间隙 0.10；螺丝柱四周长骨位最有效，其次反止口处、电池限位骨。
- 主板扣位（只防装配掉落，可不做）：扣合量 0.30，Z 向间隙 0.05–0.10，侧向间隙 ≥0.10，倒角 0.5，厚 ≥0.8。
- 装配顺序先定 [书 10.3]：PCB 一般装在厚壳；有侧键的壳；前后壳都能装就先装前壳。

## 内置电池 [书 12.1、15.1]

四周间隙 0.20；仓拔模 1–2°；限位筋与电池间隙 0.10，每面不少于 3 条，筋厚不超过壳厚一半；仓四周胶厚 0.9；Z 向间隙 0.10，壳 Z 向胶 ≥0.8。要防反装；防小孩吞电池。

## 连接器 [书 12.5]

壳开孔避让多数连接器 0.25；限位骨距连接器 ≥0.20，离贴片焊盘 ≥0.80；经常插拔的口必须有限位，防止拔松焊盘。

## 超声焊 [书 15.3]

不可拆、只适用热塑性塑料、焊接面不能喷漆电镀、同种塑料最好；超声线放在公止口，不要求防水时用虚线式防溢胶；有密封作用。电池要换的产品不适用。

## 注塑 DFM 检查顺序 [书 13.6–13.12]

倒扣（斜顶行程留 7）→ 拔模 → 薄钢 → 厚胶/薄胶 → 小断差面 → 干涉 → FMEA 装配与零件检查。

- 薄钢：两个胶位间距 <0.5。处理：加胶（总厚 ≤附近平均胶厚的 1.4 倍）、减胶（外观面仍 ≥0.8）、正面补反面掏。
- 厚胶 >平均胶厚 1.4 倍；薄胶 <0.45。最易出在螺丝柱、扣位（尤其母扣）、两筋叠加、电池仓四周。各模厂标准不同，以模厂为准。
- 评审：内部同级 + 上级，外部模厂（倒扣、薄钢）和方案公司（结构与电子协调）[书 13.13]。

## ESD [书 10.4、14.6]

止口整圈保留当静电墙。消费电子测试条件：±8 kV 空气放电、±4 kV 接触放电；测点为所有合缝、孔、按键、接口；功能故障算不合格。手环触点本来接触人体，ESD 路径和接地要单独评估，书里没写。

## 可靠性测试口径 [书 14.4]

恒温恒湿 40℃/95%/48 h；高温储存 70℃/48 h；高温运行 55℃/4 h；低温储存 −40℃/12 h；温度冲击 −40↔70℃ 各 30 min 循环 10 次；盐雾 5% NaCl/35℃/24 h；样机常用 4–5 台；判定为功能正常、外观无变形。手环汗液腐蚀可参考恒温恒湿与盐雾，这是推断，书里没写。
