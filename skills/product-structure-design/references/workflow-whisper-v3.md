## 流程

### 1. 需求与尺寸链
- 先定 ID、CMF 和需求，再搭骨架模型（skeleton），所有零件都从骨架上引用 [V3 P01]
- 导入 ID、PCB 文件时先量一个已知尺寸核对单位，比如 25 mm 的边就该量出 25 mm [V3 P02]
- 列尺寸链：皮肤 → 电极 → 底壳 → PCB → 电池 → 面壳 → 表带。每一环写名义值和公差，累加后留余量 [通用]
- 手环目标（[通用]，实测后更新）：腕围 140–200 mm 可调；主体厚度 ≤ 12 mm；8 个电极均匀分布在前臂近端，或者沿腕周排布

### 2. 堆叠 / Placement / ID 可行性
- 做 PCB 堆叠和布局（placement），放好电池、连接器、按键、指示灯，查清它们和壳体的关系 [V3 P02]
- ID 的侧面如果是 90° 直身，不做拔模就得走滑块，滑块交界处会留合模线。要提前反馈给 ID 和客户确认能不能接受，开模后再改基本就来不及了 [V3 P01]
- PCB 不要和走线、外部元件干涉；空间不够时先算一下能不能避让 [V1 P19]
- PCB 边缘到壳体内壁至少留 0.75 mm，外框壁厚至少 0.8 mm [V1 P06/P12，转写较可信]
- ADS1299 的 AFE 区要靠近电极，离电池、BLE 天线和 DC-DC 越远越好；天线上方不能有金属 [通用]

### 3. 壳体分件、拔模、壁厚
- 用 Top-down 设计：在总装里从骨架拆出面壳、底壳、电极座和装饰件，改动通过父子关系传递 [V3 P03/P05]
- 胶厚：小产品取 0.8–1.2，普通电子产品取 1.2–1.5。PMMA 0.8–1.5 [V1 P01]
- 胶厚尽量均匀，同一件上最厚处 ÷ 最薄处 < 2，超过就有缩水、变形的风险（例子：2.8/1.3 偏危险）[V1 P01]
- 移动电源案例的抽壳取 2.0 mm [V3 P03]；手环取 1.2–1.5，打印件取 1.5–2.0 [通用]
- 骨位（加强筋）厚度 = 壁厚 × 0.5–0.6，太厚背面会缩水 [V1 P01]
- 拔模：外观面 2–3°，内部 1–2°；外观要求高或者咬花的面拔模要更大 [V1 P01]
- 高柱子不要按角度拔模，按上下尺寸差算，约 0.15 mm [V1 P01]
- 精度要求高的部位拔模取小 [V1 P01]
- 尖角都倒圆角，内 R ≥ 0.5 × 壁厚，外 R = 内 R + 壁厚 [通用]

### 4. 卡扣 / 螺柱 / BOSS / 止口
- 自攻螺丝柱（ABS/PC）[V1 P03]：
  - 单边咬胶量 0.15–0.2；M2.5、M3 取 0.2
  - M2 → 底孔约 Ø1.7，柱外径 Ø4.0–4.5（外径约为螺丝直径 × 2，取整）
  - 2.3 mm 螺丝 → 底孔约 Ø1.9
- 螺柱根部要倒圆角、加筋，有效啮合 ≥ 2 × 螺丝直径；打印件优先用热熔铜螺母，比如 M2 3.5×4 [通用；嵌件另见 V1 P09]
- 卡扣 [V1 P04–P06]：
  - 扣合量（干涉）0.2–0.3，入口做导入斜角
  - 壳体做到 1.2 mm 左右时可以做整体扣
  - 死扣（不拆）干涉约 0.2
  - 配合间隙约 0.1
- 止口（唇边）：两件之间单边间隙约 0.1–0.2，止口高、宽和胶厚协调，常见值见 [V1 P04/P05]（转写数字不全，量你自己的 3D 图核对）
- 移动电源的卡勾：钩高约 0.5，导向斜面 45°，配合预留 0.1 [V3 P07/P09]
- 五金件和塑胶件的配合 [V2 P04–P06]：
  - 压入、热铆的干涉 0.1–0.2
  - 槽宽要比片厚留出余量，例如 1.5 mm 的片配 2.0–2.2 mm 的槽
- 最后做全局干涉检查，再做结构优化 [V3 P12]

### 5. 防水密封
- 防水等级按 IPX 分 8 级；低级别是滴水、淋水测试，有规定的喷口和时长 [V1 P14]
- 常用做法 [V1 P14]：
  - 双止口加超声焊。防水用的焊线比普通的高，约 0.3–0.4
  - 硅胶或 O 型圈
- 密封圈一定要有压缩空间，不是贴在一起就防水。视频例子里的压缩量 0.5–0.7 [V1 P14]；按截面算，压缩率取 15–25% [通用]
- 手环建议：汗水级 IP54–IP67。电极柱穿壳的地方用灌胶，或者硅胶套加压缩；充电口用 pogo 触点，不开 USB 口 [通用]

### 6. 电极与皮肤接触结构（EMG 专用，[通用]）
- 电极：干电极用镀金（铜或不锈钢镀金，金厚 ≥ 0.5 µm），湿电极用 Ag/AgCl 卡扣片
- 接触压力：目标 5–20 kPa，既要稳定接触又不能勒得难受。表带用弹性材料，或者在电极下方加弹簧
- 浮动电极：
  - 每个电极独立浮动，行程 1–2 mm
  - 可选方案：硅胶衬垫、pogo pin 或者波形弹片
  - 球面或圆顶接触面 Ø8–10 mm，边缘倒圆角
- 布局：差分电极对的中心距 15–20 mm，沿肌纤维方向排列；参考电极（Bias/DRL）放在骨性位置
- 屏蔽与走线：
  - 电极到 AFE 的线越短越好，差分对走线等长，就近放 RC 保护
  - 壳体内侧可以喷导电漆或贴铜箔接地；防 ESD 见 [V1 P12]
  - 不让电极走线和充电、天线走线平行
- 电极座必须可拆、可清洁、可替换，干湿两种电极共用同一个卡扣接口，满足"可交付复刻"

### 7. 表带 / 连接
- 表耳留在上壳，不和底座做成一体，沿用 `mako-cad-fit` 的约束
- 优先用标准快拆杆（20/22 mm）或者硅胶一体带。电极串联在带上时用 FPC 或柔性导线，弯折半径 ≥ 10 × 线厚 [通用]
- 多模块的环可以用铰链或者 TPU 链节；转轴和卡簧参考 [V1 P13]

### 8. 公差与装配顺序
- 写清装配顺序：电极座 → 底壳 → PCB（定位柱先定位，再固定 [V1 P19]）→ 电池 → 面壳 → 螺丝或卡扣 → 表带
- 每一步都要能单手操作，并且有防呆设计 [通用 DFA]
- 打印件公差（[通用]，FDM 0.4 嘴，实测后更新）：
  - 孔要放大 0.2–0.3
  - 滑配间隙 0.2，紧配 0.1
  - 卡扣干涉 0.2–0.3，和视频值相近，但打印件更脆，要加长悬臂
- 开模件：一般配合间隙 0.05–0.1，按模厂能力定 [通用]

### 9. 3D 打印 vs 开模 DFM
- 结构和模具是绑在一起考虑的：分型面、滑块、斜顶、入水、顶针位置都会影响外观和成本 [V1 P20；V3 P01]
- 嵌件注塑（模内金属）适合螺母、电极柱 [V1 P09]
- 打印件要注意：
  - 首层打印的基准面和装配基准不是一回事
  - 悬垂 ≤ 45°
  - 薄壁 ≥ 2 条线宽
  - 卡扣沿层方向会断，要竖着打
  [通用，见 `mako-cad-fit`]
- 小批量路线：FDM → SLA/MJF → 硅胶复模（10–50 套）→ 铝模 [通用]

### 10. 验证清单
- [ ] 胶厚比 < 2，筋 0.5–0.6×，拔模外 2–3° / 内 1–2°
- [ ] 螺柱底孔、外径、咬胶量核对；热熔螺母型号已写进 BOM
- [ ] 卡扣扣合量和导入角满足要求，装拆 10 次以上不断
- [ ] PCB 到内壁 ≥ 0.75，全局干涉检查为 0
- [ ] 防水圈压缩量已算过；淋水或浸水测试通过
- [ ] 8 个电极在 3 种腕围下都接触良好：阻抗记录 < 目标值，静息噪声 RMS 已记录，握拳和放松动作的 SNR 可接受
- [ ] 浮动电极的行程和压力实测过；佩戴 30 分钟无压痕和不适
- [ ] 屏蔽和接地连续性已测
- [ ] 图纸：正交投影、关键尺寸带公差、装配顺序、BOM、STEP/STL 版本号
- [ ] 四道闸门都过了：好看 / 会用到 / 可交付复刻 / 成本可控
