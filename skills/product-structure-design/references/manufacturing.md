# 制造方式与公差链

## 同一模型不能跨工艺直接放行

| 工艺 | 本轮要核实 | 不能据此证明 |
|---|---|---|
| FDM | 机器/喷嘴/材料/层高/方向、支撑接触、孔与卡扣试片、层间弱向、蠕变和表面 | 不代表注塑各向性能、表面接触安全或防汗密封 |
| SLA/DLP | 树脂确切牌号、清洗后固化、收缩翘曲、支撑疤、脆性和残留 | 外观精细不证明皮肤接触或卡扣寿命 |
| SLS/MJF | 材料与方向、粉末清理、粗糙度/孔隙、薄壁和后处理尺寸 | 打印间隙不直接用作模具尺寸 |
| 注塑 | 分型与拔模、均匀胶厚、筋/柱根部、熔接线、浇口/顶出、倒扣、收缩翘曲及模具装配 | 打印试装不证明充模、缩水或量产能力 |
| 弹性体/包胶 | 硬度、压缩/蠕变、粘接或机械锁合、分型飞边、接触面与清洁 | 硬度标称不等于接触压力；包胶不自动密封 |
| CNC/钣金冲压 | 刀具可达/圆角、基准与夹持；板厚、折弯半径、回弹、毛刺与表面处理 | 五金外观工艺不证明电极电化学、耐汗或皮肤适用性 |

所有数值从当前材料、供应商能力、原厂要求和试片获得。不要硬编码通用壁厚、筋比、拔模角、卡扣过盈或打印补偿。询价与采购不由本技能自动触发。

## 公差链操作

1. 定义功能量及方向：如壳内可用高度减去 PCB+最高器件+固定件+线束占用；不要把接触预压、设计间隙和制造公差混为一个参数。
2. 记录每项上下限、测量基准、来源、温湿/载荷状态。含表面处理、胶层、板翘、装配偏心和变形；未知项明确待测。
3. 对线性独立尺寸区间，间隙最小值 = 可用空间最小值 − 占用最大值；最大值反向组合。按真实正负方向列链，不把标称差当最坏差。涉及旋转或柔性时采用几何/变形分析或台架检查。
4. 设计余量与误差预算分开。统计/RSS 只有在分布、相关性和过程能力证据成立时使用；安全或装配关键界面先看最坏组合。
5. 对孔距、柱高、电极突出量、连接器开窗、扣具与绑带锚点分别算链，再检查全装配。给出最小裕量、敏感项及超界后果。
6. 用对应工艺试片/实件闭环：记录样本数、仪器、分辨率与测量误差、工艺设置和版号。新工艺/新供应商重新验证，不宣称少量样机证明量产过程能力。

没有完整尺寸时输出符号链和测量任务，保持尺寸未知，不造一个“保守间隙”并盖章通过。
