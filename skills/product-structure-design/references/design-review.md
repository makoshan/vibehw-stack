# 可执行设计审核清单

每项记录：适用性、输入证据/版本、方法、指标来源、结果、责任人。缺输入标待测；不能以勾选代替检查。以下是独立工程审核框架，不是三段视频的逐字结论。

| 范围 | 检查动作 | 需要留下的证据与待测边界 |
|---|---|---|
| 使用与人体工学 | 用目标围度/截面假体检查松紧调节、单手操作、屈伸与旋转；分别看左右手、衣物和汗液场景 | 围度范围、姿态、滑移与旋转指标来源；真人适配仍需批准方案 |
| 重复佩戴 | 定义解剖/外观基准、方向防呆、绑带刻度或机械索引；设计脱下再戴的重复定位试验 | 每次位置/角度偏差与重复次数；数量、容许偏差由项目定义 |
| 干电极 | 核实材料/涂层与接触面积、突出量、顺应行程、限位、边缘；检查是否局部压痛、翘起或短接 | 压力分布与行程台架记录；接触阻抗/运动伪迹由合格团队验证，不规定通用压力或间距 |
| 湿电极 | 核对一次性贴片/凝胶的厚度、膨胀、固定接口与更换空间；检查凝胶迁移、相邻电极桥连、汗液路径 | 电极厂家资料、清洁/耗材方案；不可照搬干电极预压方案 |
| 定位与信号 | 确认目标肌群、肌纤维方向、参考电极位置及通道配置，由信号负责人确认接口需求 | 结构保证位置可复现，不宣称几何定位保证信号；不复制某肌群间距到全臂环 |
| 绑带与接触载荷 | 检查锚点、缝线/粘接、扣具、夹肤、边缘卷曲、湿态伸长和蠕变；让载荷经结构传递 | 拉伸、循环、松脱及清洁后记录；紧度不由主观“牢固”放行 |
| PCB与连接器 | 核对板框/孔位/板厚、双面器件、焊点、板翘、屏蔽罩、排针与真实配对件 | 最新板号、实测样本/工具、原厂最大包络；插座 STEP 不能代表整套线缆 |
| 堆叠与碰撞 | 查静态最坏尺寸、装入/取出路径、螺钉伸出、线束弯折、按键行程、绑带受力变形 | 相关视图/剖面、检查工具和版本、间隙表；无实体交集不等于有裕量 |
| 线缆应力释放 | 检查出口圆滑、护套、夹持区、拉力旁路、活动余量；核对厂家最小弯曲半径 | 弯折/拉扯台架方法与项目指标；不把拉力传给焊盘、电极或电池极耳 |
| 电池 | 核对确切电芯、保护板、导线与插头完整包络，防反装、刺穿、挤压、锐边和紧固件侵入 | 厂商膨胀/装配要求、固定及拆卸路径；未知膨胀空间保留待确认，不猜百分比 |
| 充电与外部接口 | 查插拔包络、充电线弯折、侧向载荷、端口支撑、防汗及误接路径；明确佩戴与充电使用状态 | 机械方案和独立电气安全评审入口；USB/隔离说明不能放行带电人体连接 |
| 皮肤/清洁/环境 | 列出所有接触材料、涂层、粘接剂与清洁剂；查积汗、毛细缝、腐蚀、异种金属、毛刺 | 材料和清洁流程资料、表面状态检查；树脂或“医用级”名称不证明最终接触安全，密封需测试 |
| 装配拆修 | 按工序演练电极、板、电池、绑带与外壳装配；检查防呆、工具可达、扭矩来源及拆坏风险 | 编号爆炸图/工序、返修可达性与更换耗材；卡扣循环和螺柱寿命待实测 |
| 热/射频 | 标识电芯、充电与发热源靠皮肤距离，天线周围金属和人体遮挡 | 专业分析/测试待办；CAD 空间足够不推导热或射频通过 |

优先级按后果与阻塞性分：阻塞放行、需样机验证、可后续优化。审查变更时沿载荷、尺寸和装配依赖复核，不强制重做无关项。
