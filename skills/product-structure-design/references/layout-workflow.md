# 产品结构设计

把“外观小、零件放得下”推进到“能装进去、接得上、固定住、能操作和拆修”。优先修改现成稿；读取项目现状与本次授权，按用户已选方案推进。一次小改动不必展开整套流程。

## 从整机骨架开始

先用一句话明确本轮尺寸目标和交付判据，随后读取已有CAD、PCB、器件清单、接口和机械约束。建立一个共同基准：壳体外形、贴肤面、PCB安装面、电池边界、接口轴线和表带受力点。后续零件引用这些基准，避免各自偏移后再靠平移凑齐。

尺寸记录来源与状态：厂家图纸 / 实测 / CAD读回 / 设计假设。记录器件完整安装包络，包括已插合连接器、线缆弯折、焊点、胶层和工具空间；区分壳体本体与含表耳/端块的总尺寸。图片仅提供外观参考，不能据透视估算精密间隙。

## 布局与堆叠

- 先安排电池、接口、天线、芯片等限制尺寸的大件，再安排外围器件和固定结构。电池不能缩放，接口不能只画插座而漏掉插头接近空间。
- 多板先按功能分配，给每个器件保留原始位号和去向。分板后的电源、时钟、地、信号与电极要有接口预算；未经核对不删保护、去耦或滤波以获得面积收益。
- 重排使用真实封装与装配禁布框。几何填充只能给候选：AFE输入、去耦、射频和电源回路需电气复核；空白比例不能直接换算成可缩小比例。
- 比较外侧高件、内侧矮件及局部错位的高度收益。薄板要同时核层叠、刚性、固定、沉板接口适用板厚；不能把原厚板模型整体压扁。
- 对翻面的板，显式记录绕哪个轴旋转、平移多少，并核对连接器中心、插合方向和电极顺序。检查STEP安装基准，避免自定义模型埋入PCB。
- 用参数扫描形成有限候选，记录失败项与限制件。报告“本轮已检查候选中最小”，除非有证明，不称绝对最小。

需要计算高度、间隙和公差时，读[尺寸链与检查](fit-and-stack.md)。开发手环时，再读[肌电手环应用](emg-wearable.md)。

## 拆件、固定与使用动作

依据装配顺序决定分件线与开口。列出电池、PCB、连接器、线束、盖板的进入路径和连接时机；核对侧插USB能否从顶面装入、板间连接能否在盒内压合、螺钉工具是否可达。

固定结构按材料、工艺、受力与拆修次数选择：螺柱、支撑台、卡扣、胶接或金属件不是通用答案。PCB固定需限制预期自由度并把插拔/按键/表带载荷传给壳体；板间连接器不默认兼任抗弯支柱。为电池留安装及膨胀余量，避免锐边和刚性挤压。

注塑的胶厚、加强筋、拔模和缩水规则不能直接套给树脂/FFF打印；金属折弯、冲压和塑胶配合尺寸应按选定材料及供应商能力确定。课程示例数字只属于原示例。

## 建模与验证

复用环境已有CAD工具。若有 `hardware-structure-design`，用它落实机械配合与制造边界；若有 `cad`，按其流程生成、读回STEP和检查视图。这些技能不存在时，使用已可用的CAD工具完成同样证据，不强制安装新工具。

验证随改动范围展开：
1. **布局**：器件数、真实尺寸、安装面、接口预留；同面装配框不重叠。
2. **装配**：尺寸链、局部间隙、壳壁/电池/插头/线束碰撞，以及进入和拆卸路径。
3. **固定与操作**：支撑/紧固点、按键行程、插拔方向、工具可达、排线是否能接到全部触点。
4. **制造/实物**：只在本轮有相应证据时报告材料工艺、试装、功能或佩戴结论。

碰撞检查加入一个应当失败的尺寸或位置作对照；包围盒相交只表示需细查，分离只证明该包络关系。检查未完成时明确范围，不把CAD导出成功、DRC通过或漂亮渲染写成整机验收。

涉及几何变更时，交付一张有尺寸、分层和接口方向的装配图，必要时补剖面/爆炸图，以及参数源、STEP和短检查记录。图中区分实际模型、替代包络和未设计区域；结论先报尺寸变化、已验证内容和下一处限制。不要因图好看而隐藏固定、端块或线束未完成的事实。
