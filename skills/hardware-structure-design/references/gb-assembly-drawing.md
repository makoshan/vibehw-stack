# 国标（GB/T）机械总装配工程图规范与双路线出图

用于将多零件硬件结构（STEP 套件或原生装配体）输出为符合国家标准的机械总装配工程图（矢量 PDF / `.SLDDRW`），供打样评审、试装防呆、外协交接与归档使用。单零件加工工程图用 `engineering-drawing`，苹果风变量化单页尺寸总览图用 `dimensional-drawing`。

---

## 1. 一张完整国标装配图的 5+1 要素

1. **一组视图（`GB/T 14692` 第一角正投影）**：
   - **主视图**：按部件的**工作位置**放置，且剖切面优先通过**主装配干线**（如双板叠层中心面、传动轴线），采用全剖、半剖或阶梯剖把内部叠层、连接器插接与限位止口一次表达清楚。
   - **其他基本视图与辅助视图**：俯视图（置于主视图正下方）、左视图（置于主视图正右方）补充横向装配干线（如侧键对微动开关、密封压盖、安装孔距）并标注剖切位置符号（粗短画 + 投射方向细实线箭头 + 大写字母 `A—A`）；右上角可配**立体爆炸轴测图**辅助快速识图（不标尺寸）。
2. **必要的五类尺寸（严禁把零件级细碎加工尺寸照搬上装配图）**：
   - ① **性能（规格）尺寸**：表征产品规格与核心能力的设计依据（如通径、接口标准宽 `25.0`、行程范围）。
   - ② **装配尺寸**：含配合代号尺寸（如基孔制 `H7/f6`、`H11/d11`）及关键相对位置尺寸（如上下 PCB 净空层距、敞口落板槽宽）。
   - ③ **安装尺寸**：将本部件安装到外部基座或佩戴界面所需的孔距、槽宽与接口尺寸。
   - ④ **外形总体尺寸**：整机在总长、总宽、总高三个方向上的最大包络尺寸。
   - ⑤ **其他重要尺寸**：设计计算确定或影响运动状态的关键尺寸（如按键凸出量、活动件极限位移）。
   - **铁律**：所有标注值必须由真实 3D 模型几何直接测量得出，禁止手填未经核对的名义数。
3. **技术要求**：置于明细栏左方或视图下方空白处，分条写清：① 装配工艺顺序与防呆禁令（如“先桌面明视锁紧排线翻盖，再经敞口槽垂直落壳”）；② 活动件间隙与手感要求（无卡阻、电极凸出齐平）；③ 通电前断电导通/绝缘/气密检验与未注公差等级（如 `GB/T 1804—m`）。
4. **零部件序号与指引线（`GB/T 4458.2`）**：
   - 相同零部件只编一个序号，一般只标一次；紧固件组允许共用一条公共指引线（阶梯横排或竖排）。
   - **引出端**：从所指零件可见剖面内画**实心小黑圆点**引出细实线；对很薄的零件（如 `0.11 mm` 柔性软板、薄垫片）或涂黑剖面不便画圆点时，改用**末端箭头指向外轮廓**。
   - **排布硬约束**：指引线**严禁相互交叉**；穿过有剖面线的区域时**严禁与剖面线平行**；必要时最多只允许弯折一次；序号字高比尺寸数字大一号或两号，在视图外围沿水平或铅垂方向按顺/逆时针顺序整齐列队。
5. **国标图框、标题栏与自下而上明细栏（`GB/T 14689` / `GB/T 10609.1` / `GB/T 10609.2`）**：
   - **图框边距（`GB/T 14689—2008` 表 1）**：留装订边时左装订边统一 `a = 25 mm`，其余三边对 **A0/A1/A2 取 `c = 10 mm`**、对 **A3/A4 取 `c = 5 mm`**（不留装订边时对 A0/A1 取 `e = 20 mm`、对 A2/A3/A4 取 `e = 10 mm`）；内框 `0.7 mm` 粗实线，周边设数字/字母分区格网。
   - **标题栏**：右下角标准宽 `180 mm`（`GB/T 10609.1` 标准高 `56 mm`）；标注**第一角画法识别符号**时，左侧锥台必须为**左小头、右大头**，右侧为两实线同心圆（严禁把锥台画成左大右小导致虚实逻辑颠倒）。
   - **明细栏**：紧贴标题栏顶边正上方，标准总宽 `180 mm = 8(序号) + 40(代号) + 44(名称) + 8(数量) + 38(材料) + 22(单件/总计质量) + 20(备注) mm`；**序号 `1 → N` 必须自下而上顺序填写**（方便后续向上增补新件，上方空间不足时紧靠标题栏左侧自下而上延续）；分界线与外框竖线用粗实线，内格横竖线用细实线。
6. **（工艺强化）装配单元系统图**：
   - 对多工步易装反产品，在图纸左下角附绘装配单元系统图：左端放**基准件**（如中框托盘）长方格，画一条粗横线向右指向总成；按装配先后顺序从左向右依次汇入——**独立散件方格画在横线上方，预装合件/PCBA 组件方格画在横线下方**，每格注明「名称 / 序号 / 件数」。

## 2. 装配图规定画法、特殊画法与结构合理性核查

### 规定画法与特殊画法（`GB/T 4458.1` / `GB/T 4458.6`）
- **接触面单线、非接触面双线**：相邻两零件的接触面与配合面只画一条共有粗实线；非接触面与非配合面无论间隙多小（哪怕 `0.15 mm` 装配间隙）均须画出两条线。
- **剖面线异向变距**：相邻两零件剖面线倾斜方向相反（`+45°` 对 `-45°`）；三个及以上零件相邻时再错开剖面线间距（如 `0.95 / 1.5 / 2.3 mm`）；**同一零件在所有剖视图中的剖面线方向和间隔必须严格一致**。
- **实心件与紧固件纵剖不剖**：剖切平面通过螺钉、螺栓、螺母、垫圈、实心轴、销、生耳杆的轴线时，一律按**不剖**绘制（仅横切垂直于轴线时画剖面线）。
- **薄片涂黑与夸大画法**：剖面厚度 `< 2 mm` 的薄片（垫片、簧片、FPC 软板）允许**涂黑代替剖面线**，微小间隙或极薄层可适度夸大线宽以保证打印可读（在技术要求中注明）。
- **拆卸 / 沿结合面剖切 / 假想画法**：遮挡内部结构的零件可假想拆去并在视图上方注“拆去 ×× 等”；沿上下壳结合面剖切时结合面不画剖面线；运动件极限位或相邻外部关联件用**细双点画线**绘出轮廓。

### 出图顺带必做的 4 项装配结构合理性审查
1. **单向唯一接触面**：同一轴向上两零件只允许**一对**平面接触（`a1 > a2`），严禁要求两对平行台阶面同时贴死（超静定无法加工到位）。
2. **清根让位**：轴肩与孔端面贴合处，必须在轴肩设退刀槽或在孔口设倒角，否则圆角干涉导致端面靠不紧。
3. **自顶向下 vs 自底向上选路**：外壳分型关联强的消费电子件（上盖/中框/按键曲面连续）宜用主控骨架分型面**自顶向下**拆件；标准模块与既有 PCB 装盒采用**基准件固定（Fix）+ 配合（Mate：重合/同轴心/平行/距离）**自底向上装配。
4. **工具与拆装通路**：螺钉通孔直径必须大于螺纹大径，沉孔/扳手空间、拔销通孔（盲孔销须留逸气孔）及 FPC 后翻盖开合弧度（如桌面先锁再落壳）必须在全剖视图中一眼可证。

## 3. 双路线自动化实现与踩坑护栏

| 场景 | 推荐路线与脚本 | 验证状态 |
| :--- | :--- | :--- |
| 从现有 `.step` 套件快速出标准国标装配图矢量 PDF，或远端桌面不可用 | **路线 B（首选快路）：本机无头 FreeCAD `TechDraw.projectEx` + 布尔薄片全剖（`scripts/freecad_gb_assembly_drawing.py`）** | **已实测通过**（通用脚本 3 件 STEP 出 A3 约 `1.4s`，同源引擎 936 实体出 A2 约 `11s`，均经截图目检） |
| 需要 `.SLDPRT/.SLDASM/.SLDDRW` 原生特征树、配合关系与联动明细栏 | **路线 A：远端桌面 SOLIDWORKS + `scripts/sw_gb_assembly_drawing.py`** | **已实现并通过离线 Mock 自测，待远端许可服务在线时做真机首跑核验** |

### 已实测踩坑与硬护栏（四栏式）

- **情形**：用 FreeCAD `TechDraw.projectEx` 渲染多零件俯视图或爆炸轴测图时，逐个零件单独投影再按顺序画到同一张 SVG 上。
  - **规则**：外露消隐视图必须先把该视图内全部可见实体拼成**单一 `Part.makeCompound`**，只调一次 `TechDraw.projectEx(compound, view_dir)` 让三维消隐引擎自动裁掉下层被遮挡棱边；严禁逐件投影直接叠画。
  - **证据**：936 实体整机总装图初版逐件投影俯视图时，中框内部的 4 个方孔轮廓穿透显示在实心上盖表面；改为整机外壳 `Compound` 单次全局 HLR 后伪穿透线全部消失。
  - **置信**：高（三维消隐几何必然规律）。

- **情形**：将 `TechDraw.projectEx(exploded_comp, iso_dir)` 输出的 2D 坐标映射到屏幕向下为 `+Y` 的 SVG 画布。
  - **规则**：严禁凭直觉硬写 `-y` 或 `+y`；必须在代码里单独取已知最顶层件（如上盖 `+Z`）与最底层件（如底盖 `-Z`）的投影顶点均值，用**硬断言 `assert y_svg_top < y_svg_bottom`** 自动校准 `y_sign`，并在导出 PNG 后人工/多模态目检爆炸层序。
  - **证据**：总装图第二版误将 `TechDraw` 已朝下的等轴测 Y 坐标二次取反，脚本零报错退出，但成图里六孔底盖飞到最顶、上盖沉到最底；加 `y_svg_top < y_svg_bottom` 断言后当场捕获并根治。
  - **置信**：高（坐标系符号翻转高频坑，断言可 100% 拦截）。

- **情形**：经 SSH 调 `solidworks_remote.py` 连接远端 Windows 上的 SOLIDWORKS，任务卡在 `connect_solidworks` 直至 120s 报 `swConnectionError (100)`，且在 SSH 会话（Session 0）直接跑 `EnumWindows` 查不到任何弹窗。
  - **规则**：① 派发建模/出图请求前先跑 `scripts/sw_gb_assembly_drawing.py --preflight-only`，同时核查 `.solidworks-cad-writer.lock` 空闲且 Windows 许可服务（`SolidWorks Flexnet Server`）状态为 `Running`；② 因 Session 0 隔离，排查桌面模态弹窗（`#32770`）必须经 `LogonType Interactive` 计划任务在 Session 1 内枚举窗口；③ 许可服务停止时向用户如实报告阻塞原因，**严禁**脚本擅自触碰或修改许可服务二进制文件。
  - **证据**：2026-11-23 远端 SOLIDWORKS 2025 因 `SolidWorks Flexnet Server` 处于 `Stopped` 状态，启动后静默停在 Session 1 的 `#32770` `[确定]` 对话框，两个并发会话各白等 120s 超时；加预检门禁后 `0.8s` 即精确报红拦截。
  - **置信**：高（Windows Session 0 隔离机制与实测复现）。

- **情形**：在 `execute_python` 内遍历 SOLIDWORKS COM 对象（如 `GetFirstDocument`、`Extension`、`GetNext`）或选中固定装配体组件。
  - **规则**：① 严禁裸用 `callable(val)` 判断属性/方法——`pywin32` 返回的 `CDispatch` 实现了 `__call__`（`callable(val)` 为真），统一用 `callable(val) and not hasattr(val, "_oleobj_")` 安全取值；② 选中组件改用 `comp.Select4(False, None, False)` 并断言 `IsFixed` 生效，避免 `SelectByID2` 因漏带 `@装配体名` 后缀而静默选空；③ 生成工程图后必须显式断言第一角投影标志、`CreateSectionViewAt5` 与 `InsertBomTable4` 返回非空（明细栏右下锚点 `y` 须高于 `c + 56 mm` 标题栏顶边防重叠）。
  - **证据**：历史远端装配脚本实测 + `sw_gb_assembly_drawing.py --self-test` 模拟宿主正反例测试通过（真机 `.SLDDRW` 版面细调仍待远端许可服务恢复后首跑确认，置信：中）。
