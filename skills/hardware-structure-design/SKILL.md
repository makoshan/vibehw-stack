# 硬件结构设计

把真实使用需求转成可制造、可装配、可验证的结构。复用已有模型和生成器；小改动只做必要修改，完整方案则覆盖装配、制造与验证，不以效果图代替工程交付。

## 明确设计边界

先从用户请求和现有文件提取使用动作、安装环境、需保留的接口、制造方式及交付目标。把“无需拆壳使用”“更薄”“可以装入”等表述转成具体检查：接近方向、连接状态、尺寸上限、安装顺序。不能用几何容易实现的替代方案悄悄改变产品用法。

查看现有 CAD、生成器与上一版验证证据，确认本轮变化。保留原版及已验证的配合界面。缺失尺寸若只影响可逆候选，可声明假设后推进；若决定接口或装配能否成立，先完成独立工作并索取关键实测，不声称已定稿。

## 尺寸与部件证据

- 对关键参数记录数值、单位、来源及状态：实测、厂家标注、原模型推导、设计假设。来源冲突时指出矛盾，不拼凑互不相容的尺寸。
- 记录完整安装包络：材料本体、胶、膜、焊点、连接器、线束及活动范围。照片只能支持可见形态，不能凭透视估计精密配合尺寸。
- 能取得确切型号的原厂 CAD 时优先使用，并核对版本。替代包络保留会影响配合的角、突出物与缺口；不能用不完整的槽位反推件代表完整实物。
- 壁厚、余量与制造公差分别建参数。不要把一次项目的数值变成所有材料、工艺和设备的统一标准。

## 布局与结构迭代

1. 建立坐标、安装基准和关键尺寸链；同时检查平面布局与高度叠层。无体积交集不代表有公差、变形或装配余量。
2. 干涉出现时，比较调整布局、局部让位、局部加厚和整体尺寸变化。移动部件须复核固定点、线长、弯折、插拔和操作空间；减薄须找到真正限制厚度的部件。
3. 检查完整装配路径与顺序，必要时检查拆卸、维护和工具空间。最终姿态能放下，不代表能穿过入口；先装时能放入，不代表其他部件装好后仍能放入。
4. 结构变化后复查用户使用动作及制造条件：接近面、贴靠、支撑、悬空、螺钉或卡扣可达性、紧固/粘接方式。按任务相关性处理散热、射频或防护，不凭几何通过推导功能通过。

## 建模与工具选择

使用当前环境已有的 CAD 工具和适用的 cad Skill。用户指定 Fusion 或需要原生特征编辑时，实际创建原生设计并验证导出；其他任务可以使用现有 CAD 或参数化生成器，无需强制换工具。

保持生成器、参数和实际装配位置一致。区分原生特征、导入实体、装配约束、静态爆炸快照；明确哪些可以编辑，哪些文件不会自动联动。网格转实体不等于恢复原始参数化历史。

需要通过 Fusion MCP 工作，或把建模放到 Windows Fusion 执行以减轻本机负载时，读 [Fusion 工作流](references/fusion-workflow.md)；其中含已实测的 Windows 脚本入口、测试件和结果读取步骤。只复用与当前版本及文档结构相符的部分。

要把装配做成可播放的高度收回动画（FreeCAD 出壳 STEP、Blender 无头打点导 glb、three.js 拖时间轴），读 [FreeCAD / Blender 无头跑](references/blender-freecad-headless.md)：freecadcmd 传参、glTF 动画名、paused action 不动这三处都踩过。

用户指定 SOLIDWORKS、要求 SLDPRT/SLDASM 原生交付或需要修改现有原生模型时，读 [SOLIDWORKS 工作流](references/solidworks-workflow.md)。按零件声明编辑真源与可编辑程度；STEP 用于交换和独立验算，不代表原生特征历史已恢复。一般生成任务继续复用现有工具，不为格式转换重建整机。

## 验证与质量门槛

按修改范围选择检查，避免每次重跑无关的完整套件：

- 几何：有效实体、预期零件数、尺寸/单位、关键壁厚、实体连通、零件间隙或干涉。
- 配合：安装路径、顺序、保持方式和公差；运动件检查所需行程，不只检查一个静止位置。
- 变更：确认应保留的接口未变化。对于报告的干涉，旧版或一个已知坏样本应能触发检查，修正版再通过。
- 交换：跨 CAD 重建时比对导出几何；双向体积差可检实体一致性，但不能证明参数关系或装配约束一致。STL检查闭合性与单位。
- 视觉：查看与本次变化有关的内外面、剖面或爆炸快照，不能用漂亮视图替代尺寸检查。

每轮明确区分“参考模型通过”“实物试装通过”“功能测试通过”。发现不足，说明失败点和下一次改动；缺实测时交付候选与未验证项，不宣称可量产。任何射频、强度、热或密封结论都需要相应分析或测试证据。

## 交付

按用户需要提供可编辑源文件与参数、STEP、装配/爆炸图、按需打印或加工文件，以及简短装配说明。只修改一个零件时不强制新建整套资料。

交付中列出版本、实测/假设边界、实际跑过的检查、制造注意项和下一步实物验证。需要完整方案时补齐零件清单、装配顺序、固定方式和验收动作；文件导出成功不等于设备或产品已验收。
