# 采购与最终订单复核

适用：嘉立创 PCB + 标准型双面 SMT，原工程带立创料号，但缺料、替代、寄料或制造提示尚未闭环。可沿用既有授权完成查询、加购和可逆草稿编辑；付款、地址及已提交订单的变更边界沿用主技能和用户指令。只保存去隐私的经验，订单号、联系人、地址、交易截图和私有物料放项目本地。

## A 采购与入库分别确认

| 情形 | 规则 | 证据 | 置信 |

## C 已提交订单的最终回读

1. 按订单号与PCB关联定位，不能按列表第一行或旧草稿认单；列表重排后重新定位。进入详情，等型号、数量、费用等真实字段加载完。空表先排除加载中，并用已知订单作对照，不立即判为无单。
2. 核贴片数量、顶底层、剩余裸板处理、坐标是单片/拼板、DFM和是否自动确认、极性来源、钢网服务、寄料数量、烘烤及其他付费服务。**“确认钢网否”不等于“钢网制作费为零”**，确认服务和制作费用分开看。
3. 下载订单最终用料清单，与原BOM按位号集合核本次选中C号、厂家订货号、每板用量×贴片数、正反面和供料方式；对不贴件核最终贴装数量或DNP标记。“已贴装”列在此类订单表里是装配配置，不是实物已经生产。原始BOM的旧型号不能覆盖工厂最终选料。
4. 对账元件小计、换料、工程、焊点、钢网、邮寄、X-ray、包装、DFM、烘烤及PCB费；加外购件与运费，注明未计费用和审核后可能变化。区分“下单/待审核/未支付/排产/到库”，不能把订单创建成功当作付款或生产开始。
5. 保存选项或发现差异后，先记录当前服务端状态。只读复核没有自动取消重下授权；需改极性/供料/已提交文件时，先说明具体影响，再沿用已有授权或请求对应操作，不为查看详情重复索要截图。

| 情形 | 规则 | 证据 | 置信 |
|---|---|---|---|
| 标准型费用高于草稿或经济型经验 | 用最终清单逐行求和、与订单详情逐项对账。基础库/免换料标签不能跨产品类型推导换料费；有疑问保留逐行收费依据。 | 同日标准双面单：45行每行换料费8元，合计360元；元件小计315.6284元与详情四舍五入315.63元、焊点8.04元一致。 | 低，本单计费，不能作为标准型固定价目。 |
| 选过推荐烘烤，详情仍写“无要求”，却列烘烤费 | 区分个性化服务总开关、器件级烘烤选择与费用；确认收费对象、数量、时长/温度及包装处理依据。没有器件级回执，写“已列费，对象未核实”，不能猜成漏选、默认烘烤或已完成。 | 同日详情“烘烤器件：无要求”与“器件烘烤-对内费48元”并存；待寄单可证明型号数量，不能证明烘烤对象。 | 低，对象未核实，原因未知。 |
| 极性来源保存为库，先前希望人工核 | 以订单详情“订单备注”、极性费用及最终生产稿为准；缺少人工核极性项时明确未购买该服务，保留DFM不自动确认，交工厂逐脚对方向。不把库模型预览或BOM勾选视为人工核极性。 | 同日最终详情为“嘉立创封装库”，无极性费；DFM确认已购且不允许自动确认。这两项是不同服务。 | 低，仅本次订单回读；历史极性选项未生效案例见主技能4a。 |
| 沉板连接器、拼板与治具提示 | 单独核板内缺口、最终工艺边/连接桥与壳体占用，确认工厂治具及费用。PCB审核通过不代替拼板工序完成；订单尺寸与工程备注不一致时，等最终拼板图确认，不自行宣布已修正。 | 同日连接器仍在最终清单中装配2颗；订单仍拼板中，尺寸字段与备注不一致，无单列治具回执。 | 低，未获最终拼板/治具确认，不推断能否直接生产。 |

**收尾最少交付**：订单身份与当前状态、已验证选项、完整费用与未计项、未解决差异及一句可转发工厂的确认语；私有证据留项目，通用经验只留上述形状与方法。
